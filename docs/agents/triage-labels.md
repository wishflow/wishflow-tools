# Triage 标签

Triage skills 使用以下五个标准角色和同名 GitHub 标签：

| 角色 / 标签 | 含义 |
| --- | --- |
| `needs-triage` | 等待维护者评估和分流 |
| `needs-info` | 等待报告者补充信息 |
| `ready-for-agent` | 信息完整，可交给异步 Agent 处理 |
| `ready-for-human` | 需要由人工实现或决策 |
| `wontfix` | 不计划处理 |

配置时仓库已存在 `wontfix`，因此保留原标签；只补齐缺少的四个标签。若 GitHub 标签名称发生变化，需同步更新本表。
