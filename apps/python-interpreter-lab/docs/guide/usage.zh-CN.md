# 使用指南

[English](usage.en.md) · [返回应用说明](../../README.md)

本指南适用于当前教学指令集 `mini-vm-v5`。页面顶部的语言选择可切换中英文。

## 快速开始

1. 页面默认进入「教学 VM」；把下方算术示例粘贴到「Python 源码」，点击「编译教学程序」。编译不会运行代码。
2. 点击「单步执行一条指令」，观察当前执行位置、活动帧、操作数栈、变量绑定和对象堆。
3. 点击「运行教学程序」执行到结束；「教学输出」应显示 `7`。

```python
x = 1 + 2 * 3
print(x)
```

观察：乘法先得到 `6`，加法再得到 `7`，随后名字 `x` 才绑定到结果。
一行源码可以对应多条教学指令；教学指令与真实 CPython 字节码都不是 CPU 机器码。
想连续观看这些已记录的动作，可用「讲解播放」；它逐句 Step Over，等当前步的 Worker 响应和演示完成后才推进下一步。

## 读懂运行状态

| 页面区域 | 怎么看 |
| --- | --- |
| 当前执行位置 | 显示快照中的实际下一条、最近执行或失败指令及源码位置；不会根据源码补造教学指令 |
| 活动帧 | 当前执行中的模块或函数帧；操作数栈与变量区都属于此帧，不能把栈当成变量列表 |
| 操作数栈 | 当前活动帧计算时临时保存的操作数和结果；标记为 `栈顶` 的槽位是下一次出栈位置 |
| 变量绑定 | 名字与值的绑定。列表、字典显示对象编号；两个名字编号相同，表示共享同一对象 |
| 调用帧栈 | 尚未返回的模块/函数调用。展开非活动帧可检查其变量和操作数栈，不会切换活动帧或推进执行 |
| 对象堆 | 当前步骤可达的列表、字典及其内容。点击变量中的对象编号可定位对应对象 |
| AST / 教学指令 | 默认折叠以突出运行现场；展开后可查看完整 AST、指令和设置断点 |

### 按源码步进观察

「源码步进历史」滑块以源码行的动态执行步进为单位。选中某组时，源码、当前动作、调用帧、操作数栈、变量、堆和输出都会显示该组最后一个已记录位置；循环再次执行同一源码行时，会形成新的历史组。展开「已记录指令」可查看组内快照，选择指令后所有运行现场切换到该指令执行后的状态。源码会同步选中对应范围，但焦点仍留在滑块或指令按钮上。

变化说明比较本组可用的前态与当前选中位置，显示绑定、列表/字典内容、调用帧及新增输出的差异。选中组内的中间指令时，摘要只描述「截至此记录位置」的状态；不会展示后续指令的结果。断点停在指令执行前，失败、部分步进和程序结束会分别显示实际状态。没有可用前态或历史存在间断时，会明确说明无法比较，不把缺少数据说成「没有变化」。

这些是教学 VM 的状态。对象编号不是内存地址；这里也不展示 CPython 的完整内存布局。
对象不再出现在当前堆视图中，不表示已经观察到真实内存释放。

## 试试别名与函数

替换源码后重新编译。这个示例既能观察共享对象，也能练习函数步进。

```python
def change(items):
    items[0] = 9
    return items[0]

a = [1]
b = a
result = change(b)
print(a)
print(result)
b = [2]
print(a)
print(b)
```

完整输出依次为 `[9]`、`9`、`[9]`、`[2]`。

- 执行 `b = a` 后，`a`、`b` 指向同一对象，并没有复制列表。
- 进入 `change` 后，参数 `items` 也指向该对象；修改元素会影响 `a` 看到的内容。
- 返回后，函数帧退出，返回值 `9` 随后绑定到 `result`。
- 执行 `b = [2]` 后，`b` 改为绑定新对象，`a` 仍保留原对象。

使用「讲解播放」检查前三个对象动作：`b = a` 保留对象编号，`b[0] = 9` 高亮同一对象的条目，`b = [2]` 显示新对象再绑定。函数调用还会显示调用方实参进入新帧并绑定到形参；返回时显示函数帧退出、真实返回值进入调用方值栈，之后再由独立的 `STORE_NAME` 指令绑定变量。递归的同名调用保留不同帧编号。每个源码步最多播放 12 条可识别过渡；达到上限时会优先保留调用和返回边界，并在最终状态注明省略数。控制流仍显示静态快照。减少动态效果时，动作文字和最终状态保持不变。

## 控制执行

| 控件 | 用途 |
| --- | --- |
| 单步执行一条指令 | 执行一条教学指令，适合看值栈变化 |
| 步入函数（Step Into） | 按源码位置推进；遇到调用时进入被调函数，返回时回到调用者 |
| 越过当前行（Step Over） | 推进当前行及其中的函数调用，停在下一个源码步进位置；循环可能再次停在同一行 |
| 跳出当前函数（Step Out） | 运行到当前函数返回；模块帧不能使用 |
| 讲解播放／暂停讲解 | 串行逐句 Step Over，并播放基于已记录快照的数据动作；Worker 正在步进时，暂停会等待 Worker 确认 |
| 运行／继续教学程序 | 从当前真实执行位置向前运行 |
| 暂停教学程序 | 在完整指令边界暂停 |
| 自动运行速度 | 选择慢、标准、快；只影响运行／继续，不改变单步规则或讲解播放时长 |

展开「教学指令」后，可在表格的「行」或「指令」按钮设置断点，运行会在对应指令执行前暂停。
源码步进也可能因断点、错误或资源限制提前停止。
可在上例 `result = change(b)` 所在行设置行断点，再用 Step Into 观察参数绑定。
点击指令的源码位置可定位原文；「下一条指令」表示尚未执行的指令。

## 历史、重置与修改源码

- 「源码步进历史」只改变观察位置，不会重新执行代码或恢复旧状态；滑块按源码步进组浏览，展开组后可选择具体的已记录指令快照。
- 「回到执行头」返回最新状态。查看历史时，单步不可用；运行／继续会先回到执行头再执行。
- 历史裁剪后仍可查看保留的快照，但首个保留位置可能没有可比较的前态，变化说明会标为不可用。
- 运行完成或运行出错后，先「重置教学 VM」再运行；重置清空运行状态和历史，保留当前编译结果及断点，并回到初始观察位置。
- 修改源码或重新编译会清除教学断点；修改源码或切换执行视图会清除旧结果，需重新编译或分析。

## 用真实 CPython 验证

在顶部「执行视图」中选择「真实 CPython」，等待运行时就绪。首次加载需要网络。

也可以先在教学模式中选中一段源码，再点击「在真实 CPython 中检查所选范围」。应用会保留完整源码、切换引擎并自动分析整份源码；选区仅用于联动 Tokens、AST 和字节码，不会把选区单独编译，也不会自动运行。要生成输出和执行轨迹，请再点击「运行 Python」。

1. 点击「分析源码」查看 Tokens、AST、代码对象和真实字节码；这一步不执行程序。
2. 点击「运行 Python」实际执行源码，记录输出、调用、行、返回、异常及变量快照。
3. 运行停止后，使用「播放回放」、事件位置和「相邻变化」检查记录；回放不会再次执行程序。

「行 · 执行前」事件中的变量是该行执行前的状态。异常事件可能被代码捕获，应结合最终结果判断。
此视图不提供 CPython 内部值栈或实时逐指令单步；教学与真实视图的指令不能逐条对应。

真实 CPython 可能在编译时折叠常量，因此源码表达式和字节码不保证一一对应；页面只展示实际反汇编及实际报告的位置。运行轨迹按调用、行、异常和返回等 trace 事件记录，不是逐 opcode 轨迹；回放只浏览已记录事件。

Python 字节码不是 CPU 机器码。此处的 Pyodide 在 WebAssembly 环境运行 CPython；页面不显示每条字节码对应的 Wasm 或 CPU 指令。

## 遇到提示时

- **不支持的语法或值类型**：教学 VM 仅支持限定子集，例如不支持列表方法、切片、导入和默认参数。简化示例，或切换真实 CPython 验证。
- **历史／轨迹／输出已截断**：只展示保留下来的部分。教学历史最多保留 500 个快照，并受容器记录预算限制；缩短程序后重跑可更容易观察完整过程。
- **指令或资源预算耗尽**：教学运行最多执行 5,000 条指令；减少循环次数或递归深度，再重置或修改后重新编译。
- **真实运行停止／超时**：只保留已收到的记录；点击「重试运行时」后重新运行，不会从中断处继续。
- **教学 VM 无法使用**：若显示「重试教学 VM」，点击重试并重新编译。

更多支持范围与限制见[应用说明](../../README.md)。
