对应规格：[P8 列表、字典与对象引用](../specs/p08-mutable-containers.md)，能力拆分见[能力地图](../../P8-CAPABILITY-MAP.md)。本阶段沿用 `mini-vm-v3` 的独立 Worker、P5–P7 语义和前端契约；发布后指令集标记升为 `mini-vm-v4`。

## T01：列表字面量和引用堆

- **用户结果**：创建列表值；快照以对象 ID 引用表示列表，且不同字面量产生不同对象。
- **范围**：新增列表 token/AST/编译指令；在 VM 引入有界对象堆、ID 分配和每步可序列化的 heap 快照；版本切换为 `mini-vm-v4`。
- **验收**：支持空、单项、多项、嵌套列表和尾逗号；构造顺序正确；列表值不通过原生 JS 循环结构传 Worker；编译仍遵守 2,000 指令上限。
- **验证**：parser/compiler 单测核对 AST、源码范围和 `BUILD_LIST`；runtime 单测核对新对象 ID、元素顺序、不可变快照；既有 P5–P7 用例不回归。
- **依赖**：P5 VM；P7 作为后续兼容验收。

## T02：下标读写、赋值目标和别名

- **用户结果**：通过下标读取和修改列表，能看见变量别名共享修改以及历史快照保持旧值。
- **范围**：下标 AST/编译；列表 `BINARY_SUBSCR` / `STORE_SUBSCR`；负索引、布尔索引、嵌套下标、栈顺序和列表资源限制。
- **验收**：计划中的 `a=[1,2]; b=a; b[0]=9` 后两者引用相同 ID 且内容为 `[9,2]`；旧快照仍为 `[1,2]`；越界和非法索引给出正确诊断；赋值 RHS 先于目标求值。
- **验证**：parser/compiler 单测覆盖读写和错误位置；VM 每步核对栈/heap；测试负索引、布尔索引、嵌套、自引用和预算边界。
- **依赖**：T01。

## T03：字典字面量和键语义

- **用户结果**：创建有序字典并通过标量键读写，观察重复键更新、别名和缺失键错误。
- **范围**：字典 AST/编译/VM heap 记录；`BUILD_MAP`、映射下标读取和写入；标量键相等与插入顺序。
- **验收**：支持空/嵌套字典和尾逗号；键限 int/bool/string/None；`True`/`1` 与 `False`/`0` 冲突；更新不改变首个插入位置；unhashable 和 KeyError 行为可定位。
- **验证**：覆盖重复键、字符串/None/数值键、键和值按左到右求值、更新/插入计数、别名更新及非法键。
- **依赖**：T02 的通用下标目标与引用堆。

## T04：对象快照和对象图

- **用户结果**：从任何保留的执行步查看对象 ID、变量根、列表项和字典键值引用；历史对象图互不污染。
- **范围**：heap snapshot DTO、可达对象裁剪、对象记录 UI、引用定位控件和中英文词条；快照预算与历史截断通知。
- **验收**：对象图按选中快照更新；环边以 ID 引用表示，不递归展开；键盘可定位对象；快照只含从模块/活动帧变量和栈可达的对象；500 快照及 50,000 对象/条目历史预算共同生效。
- **验证**：组件测试或 Playwright 验证重复引用、高亮/定位、旧快照内容和截断提示；320/768/1024/1440px 无页面横向溢出，键盘焦点可见。
- **依赖**：T02、T03。

## T05：循环、打印、比较、预算和 P7 集成

- **用户结果**：循环引用可打印、比较、浏览；列表/字典引用在函数实参、局部变量、返回值和控制流中保持一致。
- **范围**：容器真值、结构相等、cycle-safe 格式化、对象/条目/输出上限、P7 引用传递回归。
- **验收**：自引用列表/字典不会递归溢出；重复结构对象比较终止；容器引用穿越函数调用/返回保持对象 ID；资源越限有错误或历史淘汰提示；重新运行/复位清除旧 heap/history。
- **验证**：VM 单测覆盖各预算边界、循环对象、结构相等、错误快照和历史截断；以 Pyodide CPython 3.14.2 对照共同子集的输出与错误类别。
- **依赖**：T04。

## T06：完整回归、文档与发布

- **用户结果**：`mini-vm-v4` 能在正式页面中展示列表/字典构造、别名、对象图及有界历史。
- **范围**：README、应用 `AGENTS.md`、P8 spec/tasks、整体计划发布证据；不增加新引擎或共享服务。
- **验收**：应用 CI、catalog、共享站点构建和所有现有 P5–P7 回归通过；Workflow 部署成功；线上真实 CPython 视图无回归且教学样例满足规格。
- **验证**：记录本地 CI、catalog/整站构建、workflow、正式页手工验证和 Markdown 副本。P8 的 `pi` 加载规则沿用应用 `AGENTS.md`，单独记录可验证状态。
- **依赖**：T01–T05。
