# P5 任务：最小教学 VM

对应规格：[P5 最小教学 VM](../specs/p05-minimal-teaching-vm.md)。此任务拆分以 P5 v1 实施基线为依据。M1/M2 的真实编译和运行能力已发布；P5 使用独立教学解析器和 VM，不读取或执行 CPython 编译结果。

## 任务顺序与检查点

```text
按 P5 v1 规格实施
  └── T01 Tokenizer / Parser / AST
        └── T02 教学 Compiler / 指令映射
              └── T03 VM 步进 / 值栈 / 有界历史
                    └── T04 独立 Worker / 会话与运行控制
                          └── T05 教学 UI 完整链路
                                └── T06 回归、发布与线上验收
```

每项任务需保持应用可构建、可运行；发现需要新依赖、改变共享壳/语言契约或扩展 P5 语言时先更新规格并请求确认。

## T01：Tokenizer、Parser 与教学 AST

- **目标**：仅按已确认语法识别 Token、构造教学 AST，并在编译前给出精确源码位置诊断。
- **验收**：覆盖多行赋值/print、空行、注释、引号和转义、括号、乘法优先级、左结合、非法字符、未闭合字符串/括号、嵌套深度和 Token 上限；诊断范围和列号使用规格约定的 UTF-16 坐标；不支持语法不被悄悄接受。
- **验证**：`pnpm run test:unit` 中新增 lexer/parser 独立预期；检查类型和相对源码位置转换。
- **依赖**：P5 v1 实施基线（本阶段已具备）。
- **文件范围**：`src/teaching-vm/types.ts`、`tokenizer.ts`、`parser.ts` 与对应测试。

## T02：Compiler 与教学指令 DTO

- **目标**：将 P5 AST 编译为 `mini-vm-v1` 指令、常量池和源码范围映射。
- **验收**：`x = 1 + 2 * 3` 的指令顺序符合规格；名字、打印参数顺序和 `HALT` 正确；指令上限产生诊断；指令编号始终标作教学索引。
- **验证**：纯单测逐条比对独立的期望指令、常量和源码位置；运行 `pnpm run test:unit`。
- **依赖**：T01。
- **文件范围**：`src/teaching-vm/compiler.ts`、相关测试及需要的小型指令 formatter。

## T03：VM 指令步进、值栈和快照

- **目标**：实现纯 TypeScript VM，逐条解释已编译指令并生成只读的有界执行快照。
- **验收**：单步恰好执行一条；验证整数/字符串运算、名字读取/写入、打印结果、操作数顺序、运行期错误位置、数值边界和不可变历史；回看历史不会改写真实 VM 状态。
- **验证**：单测对照每条指令后的 `pc`、栈、变量、输出和阶段；复位后从初始指令与空状态开始。
- **依赖**：T02。
- **文件范围**：`src/teaching-vm/vm.ts`、快照/值类型扩展和对应测试。

### 检查点 A：编译器和 VM 核心

- Tokenizer/Parser/Compiler/VM 单测均通过。
- 基础样例的指令和逐步状态与规格手算结果完全一致。
- 单测不以实现代码自身生成的结果作为唯一预期。

## T04：教学 Worker、消息协议与控制状态

- **目标**：在独立 module Worker 中托管编译结果、VM 状态和运行调度，以会话身份隔离响应。
- **验收**：逐步、运行、暂停、复位消息状态可验证；运行分批让出事件循环，暂停只在确认后报告；旧 `sessionId/sourceRevision` 的响应被丢弃；编译/指令预算失败不阻塞 Worker 新会话。
- **验证**：Worker 集成测试覆盖控制消息交错、暂停延迟、连续 session、错误清理和复位；运行 `pnpm run build`。
- **依赖**：T03。
- **文件范围**：`src/worker/teaching-vm.worker.ts`、明确的 Worker DTO/Controller 与协议测试。

## T05：教学模式界面端到端切片

- **目标**：在单页中加入引擎选择及 Teaching VM 编译、运行和状态观察面板，保留现有 CPython 面板。
- **验收**：用户可看教学 AST/指令及源码行，单步和连续运行可观察当前指令、值栈、绑定、输出与有界历史；切换引擎、编辑源码、复位后旧状态不串入；不新增 UI 依赖、路由或第二套语言状态。
- **验证**：Playwright 真实页面及 Worker 完成基础算术、print、语法错误、运行错误、暂停、复位和回到执行头用例。
- **依赖**：T04。
- **文件范围**：现有 App/结果组件、教学 VM 专属视图、共享 locale 注册及必要样式；实现前再次按文件职责拆分，避免单个任务跨越两个独立 UI 子系统。

### 检查点 B：完整输入到结果链路

- 两个引擎各自显示准确名称和观察范围，切换后状态互不混用。
- 基础程序从输入到教学指令、逐步栈变化和输出可在浏览器中复核。
- 键盘操作和窄视口布局通过。

## T06：边界回归、文档与发布验收

- **目标**：验证支持子集、错误边界、资源预算及现有真实 CPython 能力不回归。
- **验收**：小应用全部单测/E2E、catalog、共享站点构建通过；320/768/1024/1440px 布局无页面横向溢出；双语文案与键盘焦点齐全；应用保留原 Pyodide 314.0.7 路线。
- **验证**：应用 `pnpm run test:ci`；根 `pnpm run test:catalog` 和 `pnpm run build:site`；`git diff --check` 与相对 Markdown 链接检查。按仓库规则提交、合并、推送后等待现有 workflow，并线上核对真实模式与教学模式。
- **依赖**：T01–T05。
- **文件范围**：规格/任务执行记录及针对发现问题的修复；发布配置不变。
