## T01：增加从教学源码范围进入 CPython 的入口

- 在教学源码区增加明确命名的入口；只有存在非空、可靠范围、源码有效且 Pyodide 可分析时才可操作。
- 点击后沿用 `App.tsx` 会话清理规则，取消教学讲解，保留完整源码与源码范围，切换到 CPython 并自动分析。
- 按钮附近明确提示：选区用于 AST/字节码联动；分析整份源码且不运行；运行需另行点击。
- 常规顶部引擎切换语义不变，不保留旧链接或自动分析。
- **验收**：切换后实际 CPython 结果对同一选区高亮；分析没有执行事件、输出或教学状态混入。

## T02：增加真实 CPython 编译与轨迹说明

- 在真实结果区加入中英文概念说明和可读的编译/运行时关系图。
- 说明常量折叠与多对多位置映射，只呈现 Worker 实际生成/记录的数据。
- 说明 `sys.settrace()` 的调用/行/异常/返回事件粒度及只读回放；强调不显示 CPython 内部值栈。
- 说明 Pyodide/Wasm 与宿主 CPU 的环境关系，不能把字节码解释成逐条机器码或 Wasm 映射。
- **验收**：说明与 V6 spec 一致，键盘可达，320px 下不造成整页横向滚动。

## T03：用真实 Pyodide 验证选区、优化和执行边界

- 增加 Playwright 覆盖：教学不支持但 CPython 合法的语法；选区切换且仅分析；中文/emoji 偏移；选择范围匹配 AST 和真实字节码。
- 用固定 Pyodide 对 `1 + 2` 优化结果做断言，不要求固定以外的本机 Python 版本行为。
- 覆盖真实嵌套 code object、运行最终输出和 trace 回放不重复执行；复用现有 P1–P4 测试能覆盖的前提，但需新增端到端闭环断言。
- 回归常规引擎切换仍清除旧链接、旧轨迹和教学状态；修复时不共享两种引擎的执行快照。
- **验收**：目标浏览器实际加载固定 Pyodide 并通过；失败、诊断和 Retry 路径不显示伪造的真实结果。
