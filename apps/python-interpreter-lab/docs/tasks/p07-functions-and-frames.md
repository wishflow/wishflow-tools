## T01：`None` 值端到端

- **用户结果**：教学 VM 支持 `None` 字面量、赋值、打印、假值判断和规格规定的相等比较。
- **改动范围**：tokenizer、AST/parser、常量/compiler、VM 值运算与快照格式、教学面板格式化及中英文消息。
- **验收**：`print(None)` 输出 `None`；`not None` 为真；`None == None` 为真；与其他标量相等为假；大小比较报类型诊断；既有 P5/P6 运算结果不变。
- **验证**：先增加失败的 tokenizer/parser/compiler/runtime 单测；聚焦运行教学 VM 测试；确认 `None` 的 UI 文本不会通过任意对象格式化生成。
- **依赖**：P6 已发布。

## T02：零参数函数与显式帧

- **用户结果**：定义、调用一个零参数函数，观察进入函数帧、返回值和返回到模块帧。
- **改动范围**：函数/返回 AST、语法 token 与 parser，编译函数代码区间和定义/调用/返回教学指令，Teaching VM 显式帧栈，帧快照的最小展示。
- **验收**：支持函数的值返回、裸 `return` 和隐式 `None` 返回；一个单步只执行一条教学指令；返回清除函数帧并将一个值压回调用者；模块顶层 `return` 拒绝；调用前未运行的定义不能被调用。
- **验证**：先写零参数函数的解析/指令/逐步快照失败用例；测试函数正常返回、提前返回、自然结束、函数错误和模块 `HALT`；运行完整 P5/P6 单测防回归。
- **依赖**：T01。

## T03：位置参数与表达式调用

- **用户结果**：函数接收必需位置参数，调用表达式可参与赋值、打印和其他调用的实参。
- **改动范围**：参数 AST/parser、编译函数元数据和调用参数数目、帧初始化及调用指令，调用帧的中英文呈现。
- **验收**：实参数从左至右求值；正确数量绑定到函数局部槽位；嵌套调用的结果与调用方表达式栈顺序一致；重复形参编译失败；缺少/多余实参在调用位置诊断且不留半初始化帧；不接受关键字或任意表达式调用。
- **验证**：先写参数绑定、嵌套调用和参数错误的失败测试；断言每步调用前后 caller/callee 的栈、pc 和帧 ID；Worker 浏览器用例确认输出及错误位置。
- **依赖**：T02。

## T04：函数体控制流与名字作用域

- **用户结果**：函数体运行 P5/P6 赋值、打印、分支和循环；观察局部变量与模块全局的区别，以及嵌套块中的提前返回。
- **改动范围**：编译期局部绑定收集、函数帧本地 LOAD/STORE 与全局回退，for 目标局部绑定，诊断码和帧变量展示。
- **验收**：形参、任何层赋值目标和 `for` 目标静态归为局部；局部写入不污染模块；非局部名字查全局；赋值前读取归类为 UnboundLocalError，缺失全局归类为 NameError；嵌套 if/循环的 return 正确弹出函数帧。
- **验证**：用独立案例检查同名遮蔽、全局回退、分支/循环内后续赋值、局部未绑定、模块名称不存在和循环体返回；用 Pyodide CPython 3.14.2 对照终态输出与错误类别。
- **依赖**：T03。

## T05：递归、预算、帧栈 UI 与完整回归

- **用户结果**：可以观察递归逐层入帧/退帧，浏览完整有界历史，并在中英文和窄屏下操作帧栈。
- **改动范围**：帧 ID/调用点/续行恢复、64 帧上限、5000 动态指令总预算、跨帧名称槽位预算、深度冻结历史、TeachingVmPanel 帧列表/局部状态/源码联动及样式。
- **验收**：递归和互递归结果正确；第 64 个活动帧（含模块帧）阻止继续调用；不超过 5000 条执行上限；帧、局部变量、求值栈和历史快照准确且不可变；暂停/复位/Worker 请求身份继续有效；320/768/1024/1440px 无页面横向溢出，键盘焦点清晰，尊重减少动态效果。
- **验证**：单测覆盖递归返回、帧和名称预算边界、错误快照、历史不可变性、源码范围；Playwright 通过生产构建的真实 Worker 覆盖定义/调用/递归/作用域/暂停/复位/历史和双语；运行应用完整 CI、catalog 和共享站点构建。
- **依赖**：T04。

## T06：约束文档、发布与线上验证

- **用户结果**：公开版本和应用协作契约准确说明 `mini-vm-v3` 的函数、作用域及帧栈能力。
- **改动范围**：应用 `AGENTS.md`、README、P7 spec/tasks 执行记录和整体计划发布状态；不扩大功能范围。
- **验收**：文档中的版本、已支持语法、测试数量和上线证据与实际一致；Markdown 链接有效；按仓库规则检查、提交、合并 `master`、推送；相关 workflow 成功；Codex 内置浏览器确认真实 Pyodide 模式不变且 `mini-vm-v3` 完成函数示例。
- **验证**：记录应用 CI、根 catalog 与共享站点构建结果、pi agent-context 加载实测、workflow 链接、正式页面和 `/tmp/var/wishflow-tools/` 文档副本。
- **依赖**：T01–T05。
