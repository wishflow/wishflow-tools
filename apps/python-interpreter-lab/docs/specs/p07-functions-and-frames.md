# P7 候选规格：函数与帧栈

对应整体计划：[P7 函数与帧栈](../implementation-plan.md)。本文是实施前候选规格，以下语义仍待用户确认；确认前不创建实施 tasks、不改运行时代码。P5/P6 已发布能力和应用[前端契约](../../AGENTS.md)继续有效。

## 1. 目标

在教学 VM 中增加函数定义、调用、局部名字解析、返回和递归。用户应能通过指令和帧栈观察：参数怎样进入新帧，局部变量怎样与模块变量区分，调用怎样暂停调用方、推进被调函数，以及返回值怎样回到调用表达式。

本阶段继续使用纯前端 Teaching VM Worker；不改变真实 CPython/Pyodide 的分析和执行语义，不把教学帧称为 CPython 帧。建议指令集版本从 `mini-vm-v2` 升为 `mini-vm-v3`。

## 2. 候选范围

| 类别 | 建议支持 | 建议暂不支持 |
| --- | --- | --- |
| 定义位置 | 模块顶层 `def name(params):`；运行到定义语句时绑定函数名 | 嵌套 `def`、条件/循环块内定义、闭包和捕获外层局部变量 |
| 参数与调用 | 必需的位置参数；`name(arg, ...)` 命名调用；嵌套调用与递归 | 默认参数、关键字参数、位置/关键字展开、可变参数、函数作为普通值传递或返回 |
| 函数体 | P5/P6 已支持的赋值、`print`、条件、循环，以及函数内的 `return` | `yield`、`raise`、异常处理、生成器、异步函数 |
| 返回 | `return expression`、裸 `return`、执行到函数末尾默认返回；后三者均产生可观察的结果 | `yield`/生成器返回值、调用方修改帧内状态 |
| `None` | 增加 `None` 字面量和教学运行时值；可安全打印、比较相等及参与真值判断 | 用户定义的 `None` 类型或对象协议 |
| 名字解析 | 参数和函数内任何赋值目标按 Python 规则成为局部名；其他读取回退到模块全局名 | `global`、`nonlocal`、闭包、动态 `locals()`/`globals()` |
| 帧与资源 | 显示模块帧、活动函数帧、每帧局部变量和求值栈；建议活动帧上限 64（含模块帧） | 帧快照分叉、从旧历史恢复执行、超过上限后继续运行 |

函数内的 `for` 循环目标也属于该函数的局部名。若函数体中任意位置为某名字赋值，那么在该函数帧中读取该名字时不再回退到全局；它尚未绑定时报告 `UnboundLocalError` 类诊断。没有局部绑定的名字先查模块全局；找不到时报告 `NameError` 类诊断。

`None` 按假值处理；`None == None` 为真，与当前其他标量的 `==` 为假、`!=` 为真；大小比较报告类型错误。`return` 的显式表达式、裸 `return` 和自然结束分别返回表达式值或 `None`。模块顶层出现 `return` 在执行前报语法/编译错误。

参数必须与形参数量完全一致；重复形参、重复实参绑定或实参数量不符均产生带源码位置的诊断。函数定义和调用使用正常的教学名字空间；建议只通过函数名调用，不让函数对象流入普通表达式或容器。

## 3. 候选语法

```ebnf
moduleStatement ::= functionDefinition | p5OrP6Statement
functionDefinition ::= "def" NAME "(" [parameters] ")" ":"
                       NEWLINE INDENT functionSuite DEDENT
parameters       ::= NAME ("," NAME)*
functionSuite    ::= (p5OrP6Statement | returnStatement) NEWLINE*
returnStatement  ::= "return" [expression]
callExpression   ::= NAME "(" [arguments] ")"
arguments        ::= expression ("," expression)*

primary ::= INTEGER | STRING | "True" | "False" | "None"
          | NAME | callExpression | "(" expression ")"
```

`functionDefinition` 只允许出现在模块层级；`returnStatement` 只允许出现在函数体（包括嵌套的 P6 条件/循环块）中。调用只支持名字形式，不支持 `(factory())()` 或 `object.method()`。参数和实参表达式按从左到右的顺序求值。

## 4. 调用与帧状态

建议 VM 使用显式教学帧栈，不使用 TypeScript 递归调用来模拟 Python 调用。每个帧至少保存：

| 字段 | 用途 |
| --- | --- |
| 帧身份和函数名 | 区分递归中的同一函数实例 |
| 调用点源码范围 | 定位调用指令及返回位置 |
| 函数指令区间与当前指令位置 | 暂停、单步和返回到调用方 |
| 形参/局部名字与当前绑定 | 与模块全局名字空间分开显示 |
| 当前帧求值栈 | 说明表达式如何逐指令计算 |
| 调用方续行位置 | 返回时恢复调用方并压入返回值 |

模块级执行保留独立模块帧。`CALL_FUNCTION` 创建新帧并初始化形参；函数体每条指令只推进一个活动帧。`RETURN_VALUE` 结束当前帧，把返回值压到调用方栈顶；返回到模块帧以外时程序结束。帧栈面板默认突出当前帧，也可查看其他活动帧；历史快照中的帧和局部变量不可变。

建议保留 P6 的每次 VM 动态指令 5,000 条上限；调用、返回及函数体内跳转都计入该上限。活动帧数建议最多 64（包括模块帧）；超限在尚未建立新帧的调用指令处停止并报告原因。历史仍使用 P6 的有界快照策略。每个活动帧的变量数预算和所有活动帧共享的总变量数预算沿用 P5/P6 现有上限，具体映射在实现任务中验证，不能因递归造成无界快照。

函数内发生未捕获的运行错误时，VM 停止整个程序并保留错误帧、调用位置及活动帧摘要；P7 不实现 `try/except` 或跨调用恢复，异常传播教学留给 P10。

## 5. 编译与可观察结果

- 教学 AST 区分函数定义、形参、调用和返回语句，全部节点保留准确源码范围。
- `mini-vm-v3` 使用独立教学指令表示函数绑定、带参数数量的调用和返回；跳转、调用位置和函数代码区间以教学指令索引标识，不伪装成 CPython offset。
- 指令视图能定位调用、参数传递和返回；帧栈视图显示调用前后当前帧变化、局部绑定、活动求值栈及返回值。
- 单步恰执行一条教学指令；运行、暂停、复位、历史回看及源码版本隔离沿用 P6 行为。回看历史不推进或恢复实时 VM。
- `None` 以明确的值类型和安全文本形式显示；错误信息不得包含任意 JavaScript 对象格式化或用户代码求值。

本阶段只允许改变 Teaching VM 内部类型、编译结果和面板快照；不改变 Pyodide Worker 消息协议、共享站点壳、路由、依赖或公共语言状态。若实现需要跨越这些边界，应先更新候选规格并重新确认。

## 6. 前端与测试约束

- 沿用 React、TypeScript、Vite、共享 `@wishflow/site-shell` 和独立 Teaching VM Worker；不新增依赖或服务。
- 所有新增状态和错误提供中英文词条。帧栈、参数、局部变量及历史可键盘操作并有清晰焦点；窄屏在面板内部滚动，不引发页面横向溢出；动画遵守 `prefers-reduced-motion`。
- 单测独立核对函数 AST、位置参数编译、调用/返回的逐条栈帧变化、局部/全局解析、未绑定局部、递归结果及帧/指令预算边界。
- Playwright 使用真实 Worker 验证定义、调用、嵌套调用、递归、返回到调用方、调用错误、暂停/重置和历史不可变性；覆盖 320/768/1024/1440px 与中英文。
- 与固定 Pyodide CPython 3.14.2 对照共同子集的最终输出和错误类别；差分结果不能替代对每一步帧状态的独立预期。

## 7. 验收建议

| 样例 | 建议预期 |
| --- | --- |
| `def add(a, b): return a + b` 后 `print(add(2, 3))` | 进入新帧、绑定两个形参、返回到调用方并打印 `5` |
| `def empty(): return` 后 `print(empty())` | 返回和输出 `None` |
| 函数无显式 `return` | 执行至函数末尾后返回 `None` |
| 局部名覆盖同名全局名 | 函数内读取/写入局部；模块绑定保持不变 |
| 名字在函数内后续赋值、但赋值前先读取 | `UnboundLocalError` 类诊断，不错误回退到模块全局 |
| 简单递归函数 | 每次调用拥有不同帧身份，基例返回后逐层恢复调用方 |
| 参数数量不符 | 在调用位置产生参数数量诊断，不创建半初始化的函数帧 |
| 无限递归 | 到达已确认帧上限时停止；复位可重新运行 |
| 函数定义块中包含 `if` 或循环与提前返回 | 只执行被选路径；返回正确清理该帧剩余循环/求值状态 |

## 8. 待用户确认

以下项目是本候选规格的决策边界。推荐值是实现建议，不代表已获授权：

| 决策 | 推荐值 | 对实现和用户可见行为的影响 |
| --- | --- | --- |
| 函数定义与调用形式 | 仅模块顶层 `def`；必需位置参数；只按名字调用；不支持嵌套定义、闭包、默认/关键字/可变参数及函数值 | 限制语法和编译器复杂度，仍可展示直接/互递归和独立帧 |
| 函数体及名字作用域 | 函数体支持 P5/P6 语句；遵循按赋值静态确定局部名、读取时回退模块全局；不支持 `global/nonlocal` | 需在编译期收集局部绑定，并区分 `NameError` 与 `UnboundLocalError` |
| 返回与 `None` | 支持值返回、裸返回、默认 `None`；加入 `None` 字面量、打印、真值及相等比较 | 用户能观察函数自然结束和显式空返回的结果 |
| 递归与资源预算 | 活动帧最多 64（含模块帧）；动态指令沿用 5,000 | 决定递归教学深度和内存/历史预算 |

确认后再把本文从“候选规格”转为实施基线，并创建 P7 tasks；任何新增的闭包、参数形式或作用域规则应在实现前单独评估。
