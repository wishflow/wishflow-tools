# P7 规格：函数、作用域与帧栈

对应整体计划：[P7 函数、作用域与帧栈](../implementation-plan.md)，实施任务见 [P7 tasks](../tasks/p07-functions-and-frames.md)。本文是已确认的实施基线。P5/P6 已发布能力和应用[前端契约](../../AGENTS.md)继续有效。

## 1. 目标与边界

在教学 VM 中增加模块级函数定义、必需位置参数、函数调用、返回、局部名字解析和递归。用户能逐步观察参数进入新帧、每帧独立的变量与值栈、调用方暂停、被调函数执行、返回值恢复到调用方，以及递归帧逐层退出。

本阶段继续使用纯前端 Teaching VM Worker；教学帧和教学指令仅描述本应用自定义 VM，不声称是 CPython 的真实帧、求值栈或 opcode。真实 CPython/Pyodide 分析和执行不变。教学指令集版本从 `mini-vm-v2` 升为 `mini-vm-v3`。

不新增依赖、服务、路由或 Worker 消息协议，不改变共享站点壳和语言状态，不实现完整 Python 兼容。

## 2. 已确认语义

| 能力 | 本阶段支持 | 明确不支持 |
| --- | --- | --- |
| 函数定义 | 仅模块顶层 `def name(params):`；定义语句执行时将函数绑定到模块名字空间 | 嵌套定义、条件或循环块中的定义、闭包及捕获外层局部变量 |
| 参数与调用 | 必需位置参数；调用形如 `name(arg, ...)`；实参从左到右求值；允许嵌套调用、递归及互递归 | 默认值、关键字参数、展开参数、可变参数、方法调用，以及函数作为普通值传递或返回 |
| 函数体 | P5/P6 已支持的赋值、`print`、条件、`while`、`for-in-range`；这些块中允许 `return` | `yield`、异步函数、异常语法、`break`/`continue`、循环 `else` |
| 返回 | `return expression`、裸 `return`、执行至函数末尾；裸返回和自然结束都产生 `None` | 生成器返回值、函数外 `return` |
| 名字作用域 | 形参、函数体内任意层赋值目标和 `for` 目标静态确定为局部；其余名称运行时查模块全局 | `global`、`nonlocal`、闭包、动态 `locals()`/`globals()` |
| `None` | 新增字面量和值；可赋值、打印、返回、按假值判断和比较相等 | 用户自定义对象协议 |
| 运行状态 | 显示模块帧和活动函数帧、每帧的求值栈/变量/源码位置；历史帧快照不可变 | 历史分叉、从历史恢复执行、超过资源上限后继续运行 |

### 2.1 函数绑定与调用

- `def` 只允许出现在模块语句层。执行到定义语句时才把可调用函数绑定到模块名字空间；定义之前调用该名称会得到 `NameError` 类诊断，且在求值调用实参前报告。
- 调用只接受直接名称形式 `name(...)`。函数不能作为一般表达式值传递、赋值别名、打印或返回；不支持 `(factory())()`、`object.method()` 等形式。
- 所有形参都是必需的位置参数。重复形参在编译阶段给出定位诊断；实参数量不符在调用位置报告运行诊断，且不创建半初始化帧。
- 编译调用时先解析直接调用目标，再从左向右计算实参；因此未定义名称先产生 `NameError`，不会先执行实参中的副作用。目标名称已绑定时，非函数错误和实参数量错误仍在实参求值后报告；嵌套调用遵循表达式从左到右的求值顺序。
- 函数名在运行时绑定。递归可以在函数定义执行后发生；互递归要求两个定义都已执行后再开始调用。

### 2.2 `None` 与返回

- `None` 是保留字面量，不可作为赋值目标或普通变量名。
- `None` 的真值为假；`None == None` 为真，与当前支持的其他标量进行 `==` 为假、`!=` 为真；任何大小比较均产生类型错误。
- `return expr` 先计算表达式再退出当前函数帧；裸 `return` 和执行至函数代码末尾都返回 `None`。
- 模块层出现 `return` 在执行前作为语法/编译错误拒绝。
- 返回后立即销毁被调活动帧，把一个返回值压入调用方的求值栈并恢复调用方续行位置。函数中的运行错误停止整个教学程序，不支持跨函数捕获或恢复。

### 2.3 局部名与全局名

- 编译函数时递归扫描其语句块，收集形参、所有 `Assign` 目标和所有 `for` 目标；条件与循环的内层语句仍属于同一函数作用域。
- 若名称属于该集合，所有读取都访问当前帧局部槽位。即使赋值语句尚未执行，也不得回退到同名全局；读取未绑定局部报告 `UnboundLocalError` 类诊断。
- 其余名称只查模块全局名字空间；查无此名报告 `NameError` 类诊断。VM 不模拟内建名字空间。
- 上述错误类别按教学 VM 诊断码表达（`unbound-local-error`、`name-error`），不承诺复现 CPython 版本相关的完整异常文本。
- 局部变量按 Python 的“整段函数块静态决定局部名”规则处理。该规则依据 Python 3.14 执行模型；教学 VM 只实现本规格列出的绑定形式。[Python 3.14 执行模型](https://docs.python.org/3.14/reference/executionmodel.html#resolution-of-names)

## 3. 语法子集

```ebnf
moduleStatement ::= functionDefinition | p5OrP6Statement
functionDefinition ::= "def" NAME "(" [parameters] ")" ":"
                       NEWLINE INDENT functionSuite DEDENT
parameters       ::= NAME ("," NAME)*
functionSuite    ::= (p5OrP6Statement | returnStatement) NEWLINE*
returnStatement  ::= "return" [expression]
callExpression   ::= NAME "(" [arguments] ")"
arguments         ::= expression ("," expression)*

primary ::= INTEGER | STRING | "True" | "False" | "None"
          | NAME | callExpression | "(" expression ")"
```

`functionDefinition` 只允许模块层级；`returnStatement` 只允许函数体内，包含 P6 条件和循环的嵌套块。调用仅支持名称直接调用，不能调用任意表达式结果。参数和实参均不支持尾逗号。除单个比较之外的比较链仍不支持。

函数和返回语句的基本规则与固定对照运行时 CPython 3.14.2 一致；Python 3.14 语言参考说明函数定义的复合语句结构、返回离开当前函数调用并产生返回值。[复合语句](https://docs.python.org/3.14/reference/compound_stmts.html#function-definitions) · [return 语句](https://docs.python.org/3.14/reference/simple_stmts.html#the-return-statement)

## 4. 调用模型与可观察状态

教学 VM 使用显式帧栈，不用 TypeScript 递归调用模拟 Python 函数。每帧至少包含：

| 状态 | 内容 |
| --- | --- |
| 身份 | 单调递增的帧 ID、函数名；递归中的各次调用 ID 不同 |
| 位置 | 当前函数代码区间、当前教学指令索引、最近执行指令、调用点源码范围、返回续行位置 |
| 局部区 | 静态局部名字集合、已绑定局部值；未绑定槽位以显式状态展示 |
| 求值栈 | 仅属于本帧的教学运行时值 |
| 调用关系 | 调用方帧 ID 和直接调用的源码位置；模块帧没有调用方 |

模块帧保留模块全局变量、模块求值栈和模块指令位置。`CALL_FUNCTION` 先从调用方栈取出实参、验证调用目标和参数数量，然后创建并压入初始化完成的新帧；一次教学单步最多执行一条指令。`RETURN_VALUE` 或 `RETURN_NONE` 弹出当前函数帧，将结果压入调用方栈并恢复续行；模块帧由 `HALT` 结束，不执行 `return`。

每个历史快照都包含完整的有界活动帧视图，并深度冻结帧、变量、值栈和嵌套快照数据。浏览历史只改变观察位置，不改变实时 VM。为兼容现有面板，单帧值栈/变量摘要指向快照中的当前活动帧；同时提供完整帧栈列表和模块全局区域。函数局部变量列表区分已绑定与未绑定状态。

教学 AST、函数代码区间、跳转、调用位置和返回续行都使用源码范围或教学指令索引，不展示或伪造 CPython bytecode offset。

## 5. 资源预算与错误

- 动态教学指令总数沿用 P6 的 5,000 条；调用、返回、模块定义、跳转和函数体指令都计入同一总预算。
- 同时活动帧最多 64 个，包含模块帧，即最多 63 个活动函数调用。超限在新帧创建前于调用指令位置停止。
- 编译指令、常量、单帧名称槽位、整数位数、字符串、输出、历史快照数量与批次大小沿用现有 P5/P6 上限。名称槽位的上限应用于所有活动帧及模块帧的总和，且未绑定局部槽位也计数。
- 历史最多 500 个快照；每个快照中的帧栈仅记录有界的教学值摘要，不保存任意对象引用。超限诊断保留出错指令、调用点及当时活动帧摘要；复位可从初始模块帧重新运行。
- 函数定义、调用、返回和 `None` 节点均有准确源码范围。语法、编译、参数数量、未绑定局部、未定义名称、类型和资源诊断均定位到对应源码。

## 6. 前端与测试约束

- 沿用 React、TypeScript、Vite、共享 `@wishflow/site-shell` 和独立 Teaching VM Worker；不新增依赖或服务，Worker 请求/响应协议不变。
- 教学指令集版本显示为 `mini-vm-v3`。中英文文案由共享语言状态驱动，不新建语言按钮或存储键。
- 帧栈可以键盘操作，当前帧和调用关系可辨认，未绑定局部有文本状态；窄屏面板内部滚动、不造成页面横向溢出；动画遵循 `prefers-reduced-motion`。
- 单测覆盖 None 的真值/显示/比较、函数 AST 和源码范围、调用/返回逐步状态、参数数量、局部变量收集与 UnboundLocalError、全局回退、递归、帧/指令/名称预算和历史不可变性。
- Playwright 通过生产构建的真实 Worker 验证正常调用、嵌套调用、递归、控制流内提前返回、函数结果、错误、暂停/重置/历史与中英文视图。
- 在固定 Pyodide / CPython 3.14.2 对照已支持语法子集的最终输出和错误类别。差分一致不代替教学 VM 每个执行步的独立预期。

## 7. 验收样例

| 输入特征 | 预期结果 |
| --- | --- |
| `def add(a, b): return a + b`，随后 `print(add(2, 3))` | 参数绑定到独立帧，返回值回到调用方并输出 `5` |
| `def empty(): return`；随后 `print(empty())` | 返回和输出 `None` |
| 函数自然结束 | 压入并返回 `None` |
| 函数内读取只在模块定义的名称 | 回退读取当前模块全局值 |
| 同一名称在函数后续任意嵌套块赋值，赋值前读取 | `UnboundLocalError` 类诊断，不读取同名全局 |
| `for` 目标与模块同名 | 目标写入函数局部帧，模块变量不变 |
| 递归函数达到基例 | 每次调用有不同帧 ID，逐层返回并恢复调用方栈 |
| 实参数量不符 | 在调用指令处诊断，不创建未完成的新帧 |
| 无限递归 | 到达 64 帧边界前的第 64 个活动帧处停止并可复位 |
| 函数体内嵌套 `if`/循环并执行提前返回 | 清理当前函数帧，循环状态不泄漏到调用方 |
