# P9 规格：教学调试控制

对应整体计划：[P9 教学调试控制](../implementation-plan.md)，任务拆分见 [P9 tasks](../tasks/p09-teaching-debugger.md)。产品语义已于 2026-10-30 确认。本阶段只控制 `mini-vm-v4` 教学 VM，不改变真实 Pyodide/CPython 视图。

## 1. 目标与边界

在现有教学 VM 的逐指令执行、暂停、复位和历史快照上增加可预测的源码级调试能力：源码行断点、教学指令断点、行步进、Step Into/Over/Out、Continue 和运行速度选择。用户能从 AST、教学指令和运行快照间定位位置，并能解释程序为什么在某个位置暂停。

沿用 React、TypeScript、Vite、共享站点壳、原生 `textarea` 和既有 Teaching VM Worker。预期扩展现有消息协议以传递调试命令和运行选项；不新增 Worker、第三方编辑器、状态库、服务或依赖。教学字节码和语言语义不变，版本继续标为 `mini-vm-v4`；P5–P8 的指令执行、对象身份、函数作用域和 5,000 条动态指令上限继续有效。

## 2. 现有代码基线

本规格对照 P8 已发布代码核过以下接口，后续实现应沿用这些状态，而不是另造并行执行模型：

- `TeachingInstruction` 已有稳定的程序内 `index`、opcode 和 `SourceSpan`；`TeachingFunction` 已有入口/结束索引及定义位置。指令索引只是教学程序位置，不是 CPython offset。
- `TeachingVmSnapshot` 已包含 `pc`、最后执行/下一条指令索引、执行计数、运行状态、帧栈、变量、值栈、堆和输出；T01 已增加断点暂停原因和命中 ID。
- Teaching VM Worker 已有 `run`、`pause`、`reset`、运行代次取消和 session/sourceRevision 隔离。运行循环每批最多执行 8 条指令，批次间等待 16ms；Pause 在指令边界检查。已确认的速度档只配置批量大小与调度间隔，不改执行语义。
- 当前运行历史最多 500 个快照，动态指令上限为 5,000，编译指令上限为 2,000；断点集合应有界，并与当前编译结果绑定。
- 页面使用原生 `textarea`，AST 和教学指令面板已有源码定位控件；不应通过新增编辑器依赖实现 gutter。断点入口可从现有 AST/指令位置建立，并提供可访问的断点概览。
- 时间轴已提供“回到执行头”操作，且在查看旧快照时禁用运行按钮。Continue 从历史位置执行时先回执行头，并保持历史只读、不分叉。

## 3. 已确认行为

| 能力 | 语义 |
| --- | --- |
| 源码行断点 | 绑定当前编译结果中该行首个可执行教学指令；空行和注释行不创建断点。命中时在执行指令前暂停；循环或递归之后再次到达仍会命中 |
| 教学指令断点 | 绑定当前编译结果中的指令索引，并在该指令执行前暂停；更换编译结果后清除 |
| 断点数量 | 源码行和教学指令断点共享 2,000 项上限；超出或不属于当前编译结果的断点拒绝写入 |
| Continue | 从当前执行头继续；断点暂停时只跳过本次当前位置的命中，循环或递归后再次到达时正常暂停 |
| 历史位置 | 时间轴位于旧快照时，Continue 先回到执行头再运行；不从旧快照分叉，不修改已有历史 |
| 复位与源码变化 | Reset 保留当前编译结果的断点；编辑源码或重新编译后清除已绑定断点 |
| 运行速度 | “慢 / 标准 / 快”只改变自动运行批次和调度间隔，不改变单步与源码步进。慢：最多 1 条/250ms；标准：最多 8 条/16ms；快：最多 32 条/16ms。数值是批次上限和调度间隔，不保证硬实时速率 |
| 执行预算 | 每次运行最多执行 5,000 条动态指令；断点暂停不消费预算，已执行的指令仍计入预算 |

断点和运行控制状态按当前源码修订与编译结果绑定。编辑源码或切换引擎后，旧编译结果失效，调试操作禁用；不会让旧 Worker 响应更新新源码状态。教学 VM 的程序输出、错误诊断和历史记录保持原语义。

## 4. 步进语义

保留单指令 Step、Step Into、Step Over 和 Step Out。Step Line 与 Step Over 合并，不提供重复入口。

| 命令 | 停止条件 |
| --- | --- |
| Step（单指令） | 执行下一条教学指令，并停在下一个指令边界 |
| Step Into | 执行当前源码位置并停在下一可执行源码位置；遇到函数调用时进入被调函数，并在其首个可执行位置暂停 |
| Step Over | 执行当前源码行；调用在当前命令中完成，随后停在当前帧下一可执行源码位置，或函数返回后的调用者续行 |
| Step Out | 在当前函数帧内运行到返回，并停在调用者续行；模块帧没有调用者，操作禁用并说明原因 |

源码级步进按教学 VM 的实际指令和帧状态判断。单行多指令、跳转、循环回边和函数进入/返回不得误判为单条字节码步进。具体状态转移以 T03 的测试和实现为准，遇到本表未规定的边界时不得默默改变语义。

## 5. 断点和暂停状态

调试状态包括：当前编译源码修订、已启用的源码行/指令断点集合、暂停原因、命中的断点 ID、执行头位置和当前步进目标。UI 显示断点位置和暂停原因；程序计数器仍指向下一条待执行指令。

- 断点判定发生在教学指令执行前。命中只把运行状态切换为 `paused` 并记录可观察原因，不增加动态指令计数，也不改变值栈、变量、帧或容器堆。
- Continue 离开当前位置时必须保证不会立即重复命中同一断点；循环或递归之后真实再次抵达该位置仍会命中。
- Pause 请求在当前原子指令完成后生效；不在运算中间暴露半更新的栈或对象堆。
- 编译错误、运行错误、指令预算耗尽和正常完成是终态；断点和步进命令不得从终态隐式恢复。
- 浏览历史只改变观察游标。除 Continue 的“先回执行头”行为外，用户不能从历史状态继续、修改变量或建立新执行分支。

## 6. 交互与无障碍

- 不引入代码编辑器依赖或自绘代码编辑器。断点可以从现有源码位置链接、AST 节点或教学指令表设置；具体入口应能显示它对应的源行/指令与启用状态。
- 当前教学指令表为源码行与指令断点提供键盘可达的添加/移除控件；每个可执行源码行只在映射到的首条指令显示源码断点入口。断点概览显示绑定位置，并可定位源码范围和对应教学指令。
- 控制区至少提供：单指令步进、Step Into/Over/Out、Continue、Pause、Reset、断点概览与运行速度选择。不可用的操作使用禁用状态和可读说明。
- 可通过键盘添加/移除断点、触发步进命令、选档和恢复执行；焦点可见；暂停原因通过 `role="status"` 等可访问方式播报。
- 当前/命中指令、对应源码位置和调用帧应可互相定位。历史浏览状态与实时运行状态明显区分。
- 中英文使用共享语言状态；视口覆盖 320、768、1024、1440px；长指令表在面板内滚动，页面不横向溢出；动画遵循 `prefers-reduced-motion`。

## 7. 验收场景

以下行为作为实现验收条件，具体断言记录在对应 tasks。

| 场景 | 需要证明 |
| --- | --- |
| 同一行编译成多条教学指令 | 行断点绑定到该行首条指令；步进按源码行和帧规则推进 |
| While/for 回到断点行 | Continue 不在当前位置立即重复暂停；后续循环命中再次暂停 |
| 递归调用 | Into/Over/Out 的活动帧、源码位置与暂停原因符合步进语义 |
| 函数返回 | Step Out 在调用者续行暂停，不停留在已弹出的帧 |
| Continue 与断点 | 从命中断点继续先执行一次；未来命中仍生效；终态不可继续 |
| 历史游标位于过去 | Continue 返回执行头并继续，不修改旧快照或产生历史分支 |
| Pause 与速度档 | Pause 在原子指令边界生效；速度档只改变自动运行节奏，不影响终态与 5,000 条预算 |
| 复位/编辑/编译/切引擎 | Reset 保留断点；编辑或重新编译清除旧断点；过期 Worker 消息不能污染新程序 |

## 8. 验证门与回滚

- VM 单元测试覆盖断点命中前状态、重复命中抑制、同源行多指令、跳转/循环、帧深度变化、步进目标、暂停原子性和预算边界。
- Worker 测试覆盖新旧 session/sourceRevision 隔离、运行批次、断点/暂停竞争、速度档切换、历史回看后 Continue 和 Reset。
- Playwright 通过生产构建和真实 Worker 验证源码行/教学指令断点、键盘操作、递归 Into/Over/Out、历史执行头恢复、终止态、双语和响应式。
- 运行应用 `pnpm run test:ci`、根 `pnpm run test:catalog`、`pnpm run build:site` 和 `git diff --check`；发布 workflow 成功后，用 Codex 内置浏览器验收正式子路径。
- P9 不改变语法、指令集和数据持久化。回滚可移除高级调试控件与 Worker 调试命令，保留 P5–P8 的单指令 Step、Continue/旧有 Run/Pause/Reset 和全部语言能力。
