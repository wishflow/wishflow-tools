# P4 规格：结构化变量与历史观察

对应整体计划：[P4 结构化变量与历史观察](../implementation-plan.md)。本阶段扩展 P3 的真实 CPython 行级执行记录，在每个已记录事件上保存有界、不可变的局部变量和全局变量快照，并能查看相邻事件间的变化；不恢复或继续执行历史，不改变 P1/P2 编译视图，也不实现 P8 的跨事件对象引用图。

## 1. 目标、前提与边界

用户可在选中的 CPython trace 事件上查看：

- 模块全局变量和当前活动用户帧中的局部变量；调用栈各帧可切换查看。
- 精确内建标量的安全摘要，以及精确 `list`、`tuple`、`dict` 的有限深度结构。
- 容器循环引用在该事件快照内的回指标记；旧事件的值不会随之后的赋值或容器修改而变化。
- 当前事件相对前一事件新增、变化或移除的变量；首次事件作为观察起点，不声称代表 Python 程序运行前的状态。

沿用固定 Pyodide 314.0.7 / CPython 3.14.2、P3 的 `sys.settrace()`、同一 module Worker、当前 React 面板和 P3 的运行/回放状态。Worker 继续通过有界 JSON DTO 分批发送，不增加 npm/Pyodide 依赖，不持有长期存活的 `PyProxy`，不改变共享站点响应头。

本阶段不查看任意自定义对象属性、不调用用户对象的 `repr()`、`str()`、迭代器或描述符、不在运行中编辑变量、不反序列化历史状态、不提供历史分叉、跨刷新保存或对象图。不声称帧级数据能说明 C 函数、库内部帧或未被 P3 记录的控制流。

## 2. 事件快照数据合同

每个 `TraceEvent` 增加一个 `snapshot`，并用它替代 P3 的扁平 `locals` / `localsTruncated` 字段；P3 当前帧摘要仍通过 `SnapshotValue.summary` 显示，不再重复序列化同一批局部变量。事件索引、事件类型、调用栈、返回值、异常和输出偏移继续沿用 P3 语义。`line` 事件快照仍是该行执行前状态。

| 字段 | 语义 |
| --- | --- |
| `globals` | 事件时模块用户命名空间中的有界变量快照；过滤 `__builtins__`、`__name__`、`__doc__`、`__annotations__` 等运行器内部名称 |
| `globalsTruncated` | 全局项或其子树因数量、深度、单事件或总预算而不完整 |
| `frames` | 从模块帧到当前用户帧的活动 `<input>` 帧，顺序与调用栈一致；每帧含 `frameId`、函数名、当前行、`locals` 和 `localsTruncated` |
| `currentFrameId` | 触发当前事件的帧身份；默认选中它，即使递归调用中多个帧函数名相同 |
| `truncated` | 本事件至少一个快照范围或子树因资源限制不完整；与 P3 的 `traceTruncated` 互相独立 |
| `budgetExhausted` | 本次运行的快照节点总预算已耗尽；当前及后续事件仍有轨迹，但不再遍历变量对象 |

快照值使用有限递归 DTO，所有 Python 数值均以文本表达，不传 JavaScript `Number`：

```ts
interface SnapshotValue {
  name: string;
  type: string;
  kind: 'scalar' | 'container' | 'object' | 'reference';
  summary: string;
  valueText?: string;
  itemCount?: number;
  referenceId?: number;
  children?: SnapshotValue[];
  truncated?: boolean;
}

interface FrameSnapshot {
  frameId: number;
  functionName: string;
  line: number;
  locals: SnapshotValue[];
  localsTruncated: boolean;
}

interface EventSnapshot {
  globals: SnapshotValue[];
  globalsTruncated: boolean;
  frames: FrameSnapshot[];
  currentFrameId: number;
  truncated: boolean;
  budgetExhausted: boolean;
}
```

- `valueText` 仅在确实保留精确、有限的标量文本时出现。整数最大 1,024 bits 时保存精确十进制字符串；更大的整数只显示位数摘要并标记值已截断，绝不转为 JS 数值。整数位数先于十进制转换检查。`float` 使用 CPython 对精确内建 float 的有限文本表示；`str` 最多保留 120 个 Unicode 码点，`bytes` 最多保留 32 个字节并使用十六进制文本；长值显示长度和有界预览，并标记值已截断。文本仅以普通文本节点呈现。
- 列表/元组的子项名为稳定索引；字典按 Python 插入顺序显示有界键值项。简单内建键以安全文本显示；其他键使用序号和类型占位，不调用键对象方法。
- 容器 `itemCount` 为实际元素数，`children` 只包含上限内的项。受深度或子项预算影响时置 `truncated: true`，UI 不能把预览误标为完整容器。
- 精确 `list`、`tuple`、`dict` 以外的迭代器、集合和自定义容器只显示不展开的安全摘要。自定义对象显示类型占位；不读取属性、槽或 `__dict__`。
- 自定义对象与标量的类型名、变量名和子项名最多 100 Unicode 码点；安全摘要最多 120 码点。仅精确内建 `None`、`bool`、`int`、`float`、`str`、`bytes` 可生成标量文本。Python 实现类型名时必须绕开自定义元类覆盖的属性访问；对未知对象只显示安全占位类型，不读取对象属性。
- 容器循环和同一事件中的重复引用生成事件局部的 `referenceId`；引用节点只标出回指编号，不递归展开。该 ID 不跨事件比较，也不表示对象身份图；P8 再定义跨事件身份和别名语义。
- `frameId` 是 Worker 为一次活动用户帧分配的、单调递增的运行内序号，在该帧的 trace 调用段内稳定；帧返回后清除身份映射，但序号不复用。生成器暂停后再次进入可视为新的调用段。若实现内部以 `id(frame)` 查找映射，只保存整数键和值，不能因此延长 frame 生命周期。它不是 Python 对象 ID。

CPython 3.14 的 `frame.f_locals` 为函数帧提供与活动局部值对应的 locals proxy。采集器应在 trace 回调内立即按映射只读遍历并复制到 DTO，不得将 proxy、frame 或任意 Python 值保存到 JS 状态。模块帧与全局命名空间语义一致；模块变量以 `globals` 为单一显示范围，不重复放入模块 `locals`。参考：[Python 3.14 数据模型：frame objects](https://docs.python.org/3.14/reference/datamodel.html#frame-objects)、[PEP 667](https://peps.python.org/pep-0667/)。

## 3. 安全序列化与历史一致性

1. trace 回调只遍历记录范围内的活动用户帧，并过滤运行器保留名称。全局变量来自当前运行使用的用户 namespace。
2. 每个变量范围最多检查映射迭代顺序中的 64 个候选名称，再对候选项按名称稳定排序并保留前 20 项；超过候选扫描上限时标记范围不完整。此限制避免每个 trace 事件都完整排序任意规模的 globals。列表和元组保留索引顺序；字典保留插入顺序。单次快照创建新的普通 JSON 数据结构，后续 Python 代码修改原对象不会改写已发出的事件。
3. 深度遍历只对精确内建类型进行。长度、迭代和键格式化不得落到用户定义的 `__len__`、`__iter__`、`__repr__`、`__str__`、property 或描述符上。
4. 每个事件独立分配容器回指编号并重置检测表。采集期间不读取用户对象属性，不在快照中执行 Python 源码。
5. Stop、timeout 或 Worker 故障只保留主线程已经收到的完整批次；不声称获取 Worker 内尚未发送的快照。源码编辑立即清除旧快照及变化视图。

相邻事件差异由前端纯 TypeScript 对两个不可变 DTO 计算，不重新运行 Python。模块全局按变量名比较；局部变量按 `(frameId, name)` 比较。深层值比较类型、值文本、摘要、元素数及有序子项；不跨事件比较 `referenceId`。对象内部状态因其不可展开而未知，不能报成“未变化”。

若前一或当前范围被截断，只对双方都可见的同名值报告已确认变化；不能仅因一侧缺项便断言变量新增或删除。某范围完整时，才可将单侧缺项标为新增/移除。差异列表本身也有显示上限并明确截断。

## 4. 资源上限

沿用 P1/P3 的源码、事件、输出和时限上限；P4 新增以下快照预算：

| 资源 | P4 上限 | 到达上限时行为 |
| --- | --- | --- |
| 每个 trace event 的快照节点总数 | 200 个，含 globals、各帧变量及容器子项 | 停止该事件剩余遍历，设置范围截断标记；事件、输出和运行继续 |
| 每次运行所有事件的快照节点数 | 50,000 个 | 后续 trace 事件仍保留 P3 时间/行/调用/异常/输出信息，快照标记总量截断；不再遍历 Python 对象 |
| 每个事件的活动用户帧 | 40 帧，与 P3 调用栈上限一致 | 保留已有调用栈截断标记，未采集帧不显示为完整 |
| 每个全局或局部范围的名称扫描 | 64 个候选名称；最多显示排序后的前 20 项 | 超过扫描上限时标记该范围不完整 |
| 每帧局部变量与全局变量 | 每个范围各 20 项，按变量名稳定排序 | 标记对应范围截断 |
| 容器展开深度 | 根节点深度 0，最多展开到深度 3 | 显示子树截断提示和已知 `itemCount` |
| 单个精确容器子项 | 最多 8 项 | 保留顺序前 8 项并标记该容器截断 |
| 单个快照名称/类型名 | 100 Unicode 码点 | 截断并附省略号 |
| 单个摘要 | 120 Unicode 码点 | 截断并明确其为摘要 |
| 精确整数值文本 | 最多 1,024 bits | 超出时保存位数和安全摘要，不生成超长十进制字符串；标注精确值不可用 |
| 相邻事件差异项 | 每次最多显示 200 项 | 明确差异列表不完整，不掩盖快照总量状态 |

总快照节点计数按实际序列化的 `SnapshotValue` 节点递增；命中总上限后本次 run 的后续事件不再尝试嵌套展开。P3 的 5 秒 Worker timer 仍是总运行兜底。

## 5. 界面与交互

- 在现有执行轨迹面板增加“变量快照”区域，跟随当前回放事件，不新增路由或面板依赖。
- 以单独区域展示 Globals；帧选择器列出当前事件中可观察的帧名称、行号和调用深度，默认选中触发该事件的帧。切换帧只改变观察范围，不执行 Python。
- 默认展示该帧所有有界局部值，并提供“全部值 / 相邻变化”视图切换。变化状态使用文字标签表达新增、变化、移除、未知或无变化，不能仅用颜色编码。
- 容器通过原生 `<details>/<summary>` 逐层展开；摘要显示类型、元素数、截断状态。循环/别名引用以可理解的事件局部回指标记呈现，不自动递归或滚动页面。
- 差异比较对象明确标注当前事件和前一已记录事件。`line` 事件是当前行执行前，因此差异描述的是两条记录之间已发生的状态变化，不是当前行执行结果。
- 事件/快照/差异各自的截断提示分开显示。快照耗尽不能伪装成 trace 截断；部分范围也不能伪装为完整。
- 键盘可操作帧选择器、视图切换和容器展开；名称、焦点和状态适配共享站点的中英文语言切换。320/768/1024/1440px 下页面无横向溢出，长名字和摘要可换行。

## 6. 验收样例

| 场景 | 输入或操作 | 独立预期 |
| --- | --- | --- |
| 全局与局部帧 | `base = 10; def add(x): return x + base; print(add(2))` | globals 中 `base` 为精确文本 `10`；`add` 帧中显示局部 `x`；模块 locals 不重复 globals |
| 帧身份 | 嵌套函数、递归并浏览进入/返回事件 | 各同时活动帧有不同 `frameId`；同帧相邻事件身份稳定；返回后该帧变量作为移除出现 |
| 标量精度 | `n = 2 ** 80; text = "🐍"; print(n)` | `n.valueText` 是精确十进制字符串，不经 JS Number；短 emoji 字符串边界完整 |
| 超大整数 | `n = 10 ** 100000` | 不触发整数转十进制限制；显示位数摘要并标记精确文本被省略；trace 仍能完成 |
| 容器冻结 | `items = [1, {"x": 2}]` 随后修改 `items[1]["x"]` | 后续事件呈现新值；更早事件仍保留旧值；变化视图定位到 `items` 的子项 |
| 列表、元组、字典 | 混合嵌套的内建容器 | 顺序、键标签、元素数量正确；逐层展开深度受限；集合/自定义容器不任意展开 |
| 循环/重复引用 | `items = []; items.append(items); alias = items` | 同一事件只展开一次，后续位置显示回指编号；浏览/序列化不递归失控 |
| 自定义对象副作用 | 对象实现会抛错的 `__repr__`、property 和 `__iter__` | 事件采集、UI 展开和差异比较均不调用这些方法 |
| 差异语义 | 相邻事件新增、重赋值、删除局部变量或修改列表 | 完整范围显示准确新增/变化/移除；值相同不报变化；不完整范围不误报移除 |
| 总量预算 | 高事件数、许多变量和大型容器组合 | 单事件/单次运行预算明确标识；之后的事件、输出、停止及回放继续可用 |
| 兼容与可访问性 | P1/P2 分析、P3 停止/回放、键盘、英文/中文和窄屏 | 原能力不回归；帧选择与展开键盘可达；320/768/1024/1440px 无页面横向溢出 |
