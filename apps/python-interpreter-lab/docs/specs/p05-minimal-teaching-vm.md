# P5 规格：最小教学 VM

对应整体计划：[P5 最小教学 VM](../implementation-plan.md)。本规格定义 P5 v1 的实施基线；实现遵循下列语言子集、值语义和资源预算。扩展范围或改变站点壳、语言状态、依赖及执行隔离时，先更新文档并取得确认。

## 1. 目标

在现有纯前端应用中增加一个明确标注的 **Teaching VM v1**。用户输入同一段源码后，可在教学模式查看该模式自己的 AST 和教学指令，并逐条执行、观察值栈、变量、输出及历史快照。现有 CPython 真实编译与运行视图继续独立可用；教学指令不称为 CPython 字节码，也不声称与 CPython 指令逐条对应。

完成标准是用户能从源码走通 `Lexer → Parser → AST → Compiler → 教学指令 → VM`，并能验证 `x = 1 + 2 * 3`、下一行 `print(x)` 的优先级、栈变化和输出 `7`。

## 2. 首版范围

| 范围 | P5 v1 提案 |
| --- | --- |
| 程序 | 多行顶层语句；空行和 `#` 行尾注释可忽略；无代码块和缩进语义 |
| 语句 | 单名字赋值 `name = expression`；`print(expression, ...)`，允许零个或多个位置参数 |
| 值 | 十进制任意精度整数、单引号或双引号字符串 |
| 运算 | 整数与字符串同类型 `+`；整数 `-`、`*`；一元整数负号；括号；乘法优先于加减；同级左结合 |
| 名字 | ASCII 标识符；赋值创建或覆盖模块教学环境中的名字；未赋值读取报 `NameError` |
| 打印 | 字符串输出原文、整数输出十进制；参数以空格分隔，每次调用末尾添加换行 |
| 控制 | 编译、单条指令、运行、暂停、复位；可浏览有界历史并返回执行头 |
| 暂不支持 | 浮点、除法、布尔值、`None`、比较/逻辑、列表/字典、`if`/循环、函数/作用域、`input`、`try/except`、关键字参数和 f-string |

## 3. 语法与值语义

首版语法为：

```ebnf
program       ::= (NEWLINE | statement NEWLINE)* statement? EOF
statement     ::= NAME "=" expression
                | "print" "(" [expression ("," expression)*] ")"
expression    ::= additive
additive      ::= multiplicative (("+" | "-") multiplicative)*
multiplicative ::= unary ("*" unary)*
unary         ::= "-" unary | primary
primary       ::= INTEGER | STRING | NAME | "(" expression ")"
```

词法器忽略空格、制表符和 `#` 到行尾的注释。每条语句必须在单个逻辑行内闭合；不支持分号、续行、三引号和块缩进。字符串仅支持 `\\`、`\n`、`\t`、`\'`、`\"` 转义；其他转义在编译期报错。标识符和关键字规则以本表为准，不能落入 JavaScript 求值。

运行时只包含 `int` 与 `str`：

- `int` 使用 TypeScript `bigint`，显示十进制精确值。`+`、`-`、`*` 只接受两个 `int`。
- `str + str` 执行拼接；混合类型运算抛出教学 `TypeError`。
- 表达式按 Python 子集定义的优先级和从左到右顺序求值；不使用 JavaScript `eval`、`Function` 或隐式类型转换。
- `print()` 输出一个换行；`print(a, b)` 先计算参数，再按原顺序以一个空格连接，最后添加一个换行。首版不提供 `sep`、`end` 等关键字参数。
- 单个整数结果最多 4096 bits，字符串最多 4096 Unicode 码点；超限产生明确运行期资源错误，不截成另一个值继续执行。

词法和语法错误在执行前返回 1-based 行/列诊断。源码范围使用 UTF-16 code unit 的 `[start, end)` 偏移，列号也按 UTF-16 code unit 计数，以便与浏览器编辑区选区直接对应；CRLF 作为一个换行处理。该坐标约定属于编辑器位置，不等于 CPython AST 的 UTF-8 byte column。运行期错误保留发生错误的教学指令位置；二元运算失败时不先弹出操作数，保证错误快照显示失败前的栈。

## 4. 教学指令与执行状态

指令集版本固定为 `mini-vm-v1`。指令序号是教学程序中的数组索引，不是 CPython 的 byte offset。

| 指令 | 栈效果与行为 |
| --- | --- |
| `LOAD_CONST index` | 将常量池中的整数或字符串压栈 |
| `LOAD_NAME name` | 读取已绑定名字并压栈；未定义时报错 |
| `STORE_NAME name` | 弹出一个值并绑定到名字 |
| `UNARY_NEGATIVE` | 将栈顶整数取负；非整数报错 |
| `BINARY_ADD` | 两个整数相加或两个字符串拼接 |
| `BINARY_SUBTRACT` | 两个整数相减 |
| `BINARY_MULTIPLY` | 两个整数相乘 |
| `PRINT count` | 按源码参数顺序消费栈顶 `count` 个值并追加输出 |
| `HALT` | 标记程序完成 |

编译结果包含教学 AST、带常量池的有序指令、每条指令的源码范围和 `mini-vm-v1` 标识。`x = 1 + 2 * 3` 应编译为 `LOAD_CONST 1`、`LOAD_CONST 2`、`LOAD_CONST 3`、`BINARY_MULTIPLY`、`BINARY_ADD`、`STORE_NAME x`；下一行再编译 `LOAD_NAME x`、`PRINT 1`，程序末尾为 `HALT`。实际常量用常量池索引呈现。

VM 内部状态由 Worker 独占，包括 `pc`、值栈、名字绑定、输出和错误。主线程只消费有版本号的普通数据 DTO。每个快照说明 `lastExecutedInstructionIndex`、`nextInstructionIndex` 和阶段：编译后的初始快照表示“尚未执行，下一条指令”；单步后的快照表示“刚执行完成”，展示执行后栈和名字变化。UI 分开标示刚执行指令与下一条待执行指令。

历史保存有界的不可变展示 DTO，不保存可变 VM 对象，也不提供从旧快照恢复或分叉执行。回看旧步骤时继续/单步不可用，必须先选择“回到执行头”。复位会清空输出、错误和历史，并从当前已编译程序初始状态重新开始。

## 5. Worker 与会话

- 教学 VM 放在单独的应用 module Worker 中，与现有 Pyodide Worker 的运行时和消息协议隔离；不添加后端、Cloudflare Worker 或新依赖。
- Worker 接受带 `sessionId` 与 `sourceRevision` 的编译、单步、运行、暂停和复位请求；所有响应带相同身份。换模式、编辑源码、复位或新建会话后，旧响应不能覆盖新状态。
- 连续运行按最多 32 条指令分批，让出 Worker 事件循环以处理暂停；只在暂停确认后显示“已暂停”。单步始终恰好执行一条指令。
- 编译最多生成 2,000 条教学指令；每个程序最多 200 个不同名字；每个值及历史项均受下列预算约束。越界必须给出可见诊断，不能无提示丢弃状态。

| 资源 | 上限提案 |
| --- | ---: |
| 源码 | 沿用现有 20,000 UTF-16 code units 限制 |
| Token 数 | 5,000 |
| Parser 嵌套深度 | 100 |
| 教学指令 | 2,000 |
| 名字绑定 | 200 |
| 整数位数 | 4,096 bits |
| 字符串 | 4,096 Unicode 码点 |
| 历史快照 | 最近 500 项，超出时明确提示最早历史已丢弃 |

## 6. 界面与模式边界

- 在现有单页中增加“真实 CPython / 教学 VM”引擎选择，不添加路由、第二套语言存储或 UI 依赖；文案接入共享 `@wishflow/site-shell` 语言状态。
- 源码编辑区可共用。切换引擎从新会话开始，清除旧引擎执行历史；教学模式只运行 Mini VM，不调用 Python 或 Pyodide 执行相同源码。
- 教学模式至少呈现引擎/指令集标签、教学 AST、教学指令和源码位置、执行控制、当前指令、值栈、变量、输出、有限历史及编译/运行诊断。
- 输出、源码和用户提供字符串均以文本安全渲染。`print` 不执行浏览器 API、不访问网络、不访问全局 JS 对象。
- 控件可键盘操作并有可见焦点和本地化名称；320/768/1024/1440px 视口不产生页面横向溢出。

## 7. 测试与验收

### 单元测试

- Tokenizer 覆盖位置、注释、行尾、字符串转义、非法字符和边界预算。
- Parser 覆盖语法表、括号、优先级树、左结合及带位置的错误。
- Compiler 覆盖指令顺序、常量池、源码映射和指令上限。
- VM 每步使用独立预期核对 `pc`、栈、变量、输出和不可变历史；覆盖 4096-bit、字符串/整数边界、未定义名字和类型错误。
- Worker 控制测试覆盖编译新会话、逐步、分批运行、暂停响应、历史截断、复位及旧会话响应过滤。

### 浏览器回归

- Playwright 使用真实页面与 Worker，逐步运行 `x = 1 + 2 * 3` 和 `print(x)`，对照指令、源码行、每一步栈和最终输出 `7`。
- 运行字符串拼接和多参数 `print` 样例；编译非法语法和运行类型错误，核对错误类别与源码位置。
- 验证暂停/继续、复位、浏览历史返回执行头，以及切换引擎/编辑源码不会混入旧快照。
- 验证中英文文案、键盘操作和 320/768/1024/1440px 布局；现有 Pyodide 分析/执行和 catalog 合同不回归。

执行命令遵循当前应用 `package.json`：`pnpm run test:unit`、目标 Playwright、`pnpm run test:ci`，并运行根 `pnpm run test:catalog` 与 `pnpm run build:site`。发布和线上验收在实现经确认并完成上述验证后执行。

## 8. 文件边界与依赖

拟新增 `src/teaching-vm/` 下的小型 tokenizer、parser、compiler、VM 和显式类型模块，新增独立 `src/worker/teaching-vm.worker.ts`，在现有 React 页面与组件层接入教学模式，并为纯逻辑和浏览器流程增加单测与 Playwright。最终文件以实现前代码检查为准；按现有单应用模块模式组织，不抽通用编译器框架，不添加第三方依赖。

## 9. 回滚

移除教学模式入口、专属 Worker 和 Mini VM 模块即可回到已发布的 CPython 真实视图。共享源码编辑器或结果容器若被扩展，回滚前须确认真实视图仍使用原有分析与执行流程。

## 10. 范围变更

P5 v1 仅承诺本规格列出的最小语言，不代表完整 Python 兼容。浮点、除法、控制流、函数、容器和异常捕获进入后续独立阶段。实现中若发现必须改变语法、运算语义、资源预算、Worker 协议或共享前端契约，应先更新本规格与任务拆分并确认影响，再继续对应改动。
