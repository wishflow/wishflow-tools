# V2 规格：统一观察位置、源码步进分组与变化说明

## 1. 目标与依据

本阶段依据[体验实施计划 V2](../visual-execution-plan.md#v2统一观察位置语句分组与变化说明)，在 V1 静态工作台上把逐指令历史组织成可浏览的源码步进记录，并让当前动作、源码、帧、栈、变量、堆和输出共同显示所选记录对应的快照。用户可以展开一条源码步进查看其已记录指令，并依据真实前后快照读取净变化。

成功标准：用户选中任一已记录历史位置时，能确认自己正在看哪一条源码步进、哪些指令构成该步、哪些绑定/对象/输出发生净变化，以及当前位置是否为执行头、部分步骤、控制暂停或失败。

本规格得到用户对 V0–V6 体验路线与“每阶段先补详细 spec/tasks，再实现并走发布验收”的授权。阶段方向与验收继承 ADR-0002 和体验计划；以下规则细化当前已确认的 V2，不引入新依赖或执行协议。

## 2. 用户行为

### 2.1 统一观察位置

- 教学 VM 的源码定位、当前/下一/失败指令、活动帧、其他帧、操作数栈、变量、堆和输出继续消费同一个 `TeachingVmSnapshot`。
- 历史导航以源码步进组为主要刻度；选中某一组时，默认观察该组最后一个已记录快照。执行中的未完成组也可观察。
- 在“本步指令”中选中某条已记录指令后，观察位置精确切到该指令后的快照；所有运行现场面板同步更新。选中、展开和收起只读历史，不调用 Worker、不推进执行、不改变活动帧或输出。
- 指令选择后的摘要和变化按组首个前态到该指令后快照计算，明确表示“本步截至此处”；不会继续展示整组末尾状态的差异。
- 未编译、历史为空、历史只有一个位置、当前正在运行、失败及已结束状态均保留明确反馈；禁止通过缺失数据推断成功执行。

### 2.2 源码步进组

- 组的边界沿用现有 Step Over 的源码行与动态帧语义：从某个可用的执行前快照开始，以当时活动帧 ID 和下一条指令源码行作为起点；该动态帧仍在活动时，下一条指令进入不同源码行即完成此组。若调用深入其他帧，组保留到回到起始帧并离开起始行；这与既有 Step Over 一致，不表示函数调用动画。
- 同一行内的多个已执行指令归入同一组。循环再次执行相同行时，由中间实际执行的控制流指令和后续记录分隔为新的组；递归或同名函数使用不同帧 ID，不合并为一次调用。
- 运行结束、运行失败、断点命中或用户暂停可提前结束当前组。记录标明正常完成、部分步骤、断点前暂停、用户暂停、失败或历史前态不可用等实际状态。
- 断点前停住的指令显示为“未执行的暂停位置”，不能混入已执行指令数或变化解释。
- 单指令/Step Into 后若仍位于该组的源码行中，组显示部分步骤；再次执行会继续填充该组。Step Over 到下一源码行后，组完成。
- 历史按 `stepIndex` 保持原顺序。受 500 个快照上限裁剪后，首个保留快照没有可用前态；仍可查看它及之后的状态，但本步变化标记为不可用。若观察到索引间断，间断两侧不得合并成完整组。

### 2.3 本步说明与前后变化

绑定、对象和输出对组首个可用前态与所选观察快照做结构化比较，描述净变化；不重放指令、不重新求值表达式，也不声称组内从未持久化的中间值。函数帧进入/退出通过本组相邻的已记录快照识别，以免一次完整调用在组末净差中消失。状态和差异取自教学 VM 已记录的快照。

| 数据 | 比较规则 |
| --- | --- |
| 名字绑定 | 使用动态帧 ID 与变量名作为身份。标量按类型和值比较；列表/字典引用按 `objectId` 比较。相同值但不同容器身份仍是不同绑定；新增别名不误报原变量变化 |
| 对象堆 | 按对象 ID 比较同一对象的列表项或字典条目。容器原位修改显示为对象内容变化；重新绑定到不同 ID 与对象内容变化分开显示 |
| 调用帧 | 按帧 ID 标记本步新增或退出的帧；同名递归帧仍视为不同实例 |
| 输出 | 只显示前态之后新增且仍保留的输出行；输出未变化时不构造新输出 |
| 控制流与停止 | 显示快照已有的分支/循环/短路结果、实际断点、暂停、结束或诊断；不补造 VM 未记录的解释 |

- 每组提供一句短说明；有结构变化时概括最显著的绑定、对象、帧、输出或停止结果。没有可观察净变化时明确写明；缺少前态时明确说明无法比较，不得显示“无变化”。
- 变化列表按稳定顺序展示，最多显示 6 条，其余数量使用可访问文本注明。超长用户值保持文本安全呈现，并服从既有 UI 容器滚动/换行规则。
- 错误组说明执行失败及其实际指令和诊断；不能把失败当作成功写入。断点组说明停在下一条指令之前，差异反映该暂停前真实已有状态。

### 2.4 历史与执行头

- 历史观察只读，不创建历史分支。运行控制在历史位置执行时先回到最新执行头，再按现有 VM 语义继续；单步与 Step Into/Over/Out 仍遵守现有可执行状态限制。
- 编辑源码、重新编译或 Reset 后，旧分组、说明、指令选择和观察游标一并清理；旧 Worker 响应不能回填到新源码。
- Continue、Pause、Reset、断点、Run 速度、指令和语言切换的既有语义不变。

## 3. 数据与实现边界

- 分组和差异由纯函数消费 `TeachingCompileResult`、有界 `TeachingVmHistory` 与当前观察游标，属于派生 UI 数据；不得改写快照。
- `TeachingVmSnapshot` 仍是一条教学指令后的状态；不增加 Worker DTO、VM 字节码、执行预算或新持久化状态。
- 组边界使用实际快照的执行计数、`stepIndex`、帧 ID、源码行、停止状态和指令索引，不得仅凭历史数组位置或 `stepIndex` 认定语句成功。
- 结构比较仅读取 DTO 字段，不触发教学程序或 CPython 代码。所有分组、变化和控件状态都绑定当前编译会话；取消、Reset、源码编辑和重新编译后清理。
- 不改变 P9 的断点绑定和跳过规则，不改变 `useTeachingVm` 的执行头/历史游标唯一性，也不引入第二个可写游标。
- 计算复杂度受现有 500 个快照及容器记录预算约束；不扩大历史或堆预算。摘要列表最多渲染 6 条差异。

## 4. 无障碍、双语与布局

- 历史滑块以源码步进组为单位，名称、当前值和文本说明包含步数、源码行及必要的部分/暂停状态。
- 每组指令使用原生 `<details>/<summary>` 或等价的语义结构，默认折叠；指令选择由有名称的按钮提供，键盘可达并有可见焦点。
- 状态不能只靠颜色表示。成功/部分/暂停/失败/前态缺失均有文本。屏幕阅读器可获取本步摘要、前后变化及截断提示。
- 所有新增文案进入共享 `registerMessages` 双语词条；继续使用站点外壳的语言状态，不增加语言存储或切换控件。
- 320、768、1024、1440 CSS px 下无页面级横向滚动；说明、列表和指令只在各自面板内换行或滚动。遵守减少动态效果偏好，不新增动画。

## 5. 非目标与禁止事项

- 不实现 V3 栈/堆动画、V4 函数调用动画、V5 控制流动画或 V6 CPython 对照。
- 不新增 Worker 消息、VM 执行效果 DTO、前后快照持久化协议、全局状态库、动画/布局依赖或 Python 支持语法。
- 不根据一条教学指令推断真实 CPython 的执行状态，不把 Mini VM 变化说明称为 CPython 内部行为。
- 不扩大输出、快照、对象、代码或活动帧预算；不在 UI 重算源码表达式。
- 不改变真实 CPython 页、Pyodide 版本/加载策略、共享站点外壳、路由或发布配置。

## 6. 验收与验证

1. **分组边界**：同一源码行多个指令归组；Step Over 跨越嵌套调用并在原帧离开源码行时完成；Step Into/单指令处于行内时显示部分组；循环重复行和递归帧不合并。
2. **停止语义**：断点组不计为已执行；Pause、正常结束和错误分别准确分类；失败指令不显示成功差异。
3. **净变化**：测试新增/更新/删除绑定、同值绑定、别名、等值不同对象、同对象容器修改、帧进入/返回与新增输出；前态被裁剪时不得生成差异。
4. **同步观察**：切换组与组内指令后，当前动作、源码联动、栈、变量、堆、帧和输出全部来自同一快照；观察行为不增加执行计数、不改变程序。
5. **历史控制**：历史位置可回到执行头；运行从执行头继续；Reset、编辑、重新编译后旧记录不回流。验证至少 500 快照截断边界。
6. **产品验收**：键盘操作、中英文切换、减少动态效果、320/768/1024/1440px 响应式、既有 P9 断点/暂停/Continue 回归通过。
7. **命令**：

   ```sh
   pnpm --dir apps/python-interpreter-lab run typecheck
   pnpm --dir apps/python-interpreter-lab run test:unit
   pnpm --dir apps/python-interpreter-lab run build
   pnpm --dir apps/python-interpreter-lab run test:e2e
   pnpm test:catalog
   pnpm build:site
   ```

8. **发布验收**：提交并合并 `master`、推送后等待相关 GitHub Actions 成功；使用 Codex 内置浏览器在线验证默认教学入口、分组/差异、历史回到执行头和真实 CPython 路径。只记录实际验证的结果与问题，不以本地预览代替线上验收。

## 7. 回滚

回滚 V2 展示层和派生 helper，恢复 V1 的逐指令历史滑块与静态现场；保留 P5–P9 VM、快照、Worker 协议、断点、执行预算及 V1 布局。
