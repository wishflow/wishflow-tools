# V0 规格：双语使用说明入口

## 1. 目标与状态

为当前 Python 解释器实验室提供可发现、可直接打开的中英文使用说明。帮助页说明当前已发布的 `mini-vm-v5` 与双引擎行为，不提前描述 V1 之后的界面或能力。

本规格对应[体验实施计划 V0](../visual-execution-plan.md#v0双语说明与可点击入口)。V0 实现与本地验证已完成，等待 CI/CD 和线上验收。

## 2. 用户行为

### 2.1 实验室入口

- 实验室页眉显示“使用说明 / User guide”入口，以及“在新标签页打开 / opens in a new tab”的可见提示。
- 入口指向同一应用目录下的 `help.html`，使用 `target="_blank"` 和 `rel="noopener noreferrer"`。
- 入口使用应用已有的中英文词条与共享语言状态，不增加本地语言按钮或存储键。
- 打开帮助不提交源码、不触发编译/运行/暂停/重置、不切换引擎，也不导航或卸载原实验页。用户可在原标签页继续当前会话。

### 2.2 帮助页

- `help.html` 是独立静态页面，包含共享站点外壳、共享项目菜单、应用本地导航和语言切换。实验室页与帮助页均通过 `data-local-nav` 提供双语页面入口，侧栏初始收起。
- 页面提供“打开实验室 / Open the lab”链接，指向当前应用根路径；它进入一个新的实验页面，不恢复其他标签页的会话。
- 正文分别来自 `docs/guide/usage.zh-CN.md` 和 `docs/guide/usage.en.md`，同页保留两种语言，通过 `data-locale` 与共享语言状态显示当前语言。
- 页面没有实验室 React 入口，不初始化 Pyodide 或教学 VM Worker，不执行示例，也不读取/传递另一个标签页的源码或运行状态。
- 页面可通过 `/python-interpreter-lab/help.html` 直接访问和刷新。应用内引用、模块、CSS 和导航链接使用兼容 `base: './'` 的相对路径。

## 3. Markdown 转换合同

构建时将两份 Markdown 转换为静态 HTML。不得在帮助页运行时解析 Markdown，也不增加 Markdown 运行时库或其他新依赖。

当前正文所需的有限 Markdown 子集如下：

| 结构 | 输出要求 |
| --- | --- |
| 标题 | 生成语义正确的 `h2`–`h4`；文档首个 `h1` 由帮助页标题替代 |
| 段落 | 保持段落边界；同一段内连续源码行按普通 Markdown 空格连接 |
| 有序/无序列表 | 生成 `ol`/`ul` 与 `li`，不丢失项目顺序或文案 |
| 表格 | 生成 `table`、`thead`、`tbody` 和表头；外层容器允许窄屏横向滚动 |
| 围栏代码 | 保留语言类名及代码原文；所有代码字符按文本转义 |
| 行内代码、粗体和链接 | 生成相应语义标签；先转义文本和属性，再输出有限的受信链接 |

公开帮助正文不显示 Markdown 顶部的仓库导航行，不输出指向 `.md` 文件的公开链接。文档正文中的应用 README 链接转换为帮助页内的“实验室入口”；最终的独立“打开实验室”行动链接由页面壳明确提供。

该转换器只承诺支持这两份指南现有且经测试的 Markdown 结构，不定位为通用 Markdown 实现。出现新结构时，必须补充转换规则与测试；未知 HTML/原始标签不得直接透传。源码与转换结果的对应关系由构建测试及浏览器测试验证。

## 4. 构建与站点集成

- 使用 Vite 多页面构建，让应用首页与 `help.html` 都进入应用 `dist/`。
- 两个页面各自导入共享 `@wishflow/site-shell`；帮助页只导入站点外壳和帮助样式，不导入 `App.tsx`、React 应用入口或 Worker 模块。
- 根 `scripts/build-site.mjs` 将继续从 `apps/catalog.json` 获取项目数据，并把项目导航注入应用产物中所有包含 `<wishflow-site-shell>` 的 HTML 页面；不把项目清单写进帮助页或额外应用配置。
- 共享站点的二级 HTML 扫描需递归处理；没有站点外壳的 HTML 资源不应被改写。应用 `index.html` 仍是必需页面。
- 帮助页不默认注入项目以外的应用目录数据，不引入新 Worker、后端或发布资源。

## 5. 无障碍与布局

- 入口为原生链接，可通过 Tab 聚焦和 Enter 打开；键盘焦点清晰可见。
- 帮助正文使用标题层级、列表、表格和代码语义标签。代码块单独滚动；窄屏下表格在自身容器滚动，不使整页横向溢出。
- 英文与中文 DOM 同时可读，但仅由共享语言样式显示对应语言。帮助页不实现自己的语言切换。

## 6. 验证策略

1. **渲染单测**：覆盖当前两份指南；校验主要段落、列表、表格、围栏代码、中英文标记、导航过滤、代码转义和 `.md` 链接消除。
2. **共享构建回归**：在临时站点目录建立主页面、嵌套帮助页与不含站点外壳的 HTML 文件，验证仅站点外壳页被注入 catalog 项目数据，嵌套页同样得到共享导航。
3. **应用浏览器测试**：从实验室入口打开新标签；检查语言切换、页面内容、相对路径、静态帮助页没有解释器资源请求，并确认原标签的源码、引擎和教学程序状态保持不变。
4. **构建验证**：运行应用 `typecheck`、单元测试、Vite build、应用 Playwright、根目录 `test:catalog` 与共享站点 build；检查 `_site/python-interpreter-lab/help.html` 的壳导航与资源路径。

## 7. 约束、取舍与回滚

- 不新增依赖、应用路由器、帮助页 React 挂载、Worker 或浏览器消息协议。
- 指南是正文唯一来源。转换器负责静态呈现，不再复制维护另一份正文 HTML。
- 回滚时移除页眉入口、帮助页产物与辅助转换/站点扫描；保留现有两个 Markdown 指南，不改变任何解释器行为。
- V0 不改变默认引擎、运行布局、VM 指令、执行预算、断点或会话存储。
