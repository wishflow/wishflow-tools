# SceneSpec：小屋拆解观察台

> 本文根据用户确认的方案执行，是建模与页面验收合同。确认日期：2026-10-13。

## 视觉目标

- **场景主题：** 一座紧凑、单层、木结构小屋的建筑拆解模型。
- **视觉关键词：** 温暖、清楚、模型展示。
- **公开纹理：** [Grey Roof 01](https://polyhaven.com/a/grey_roof_01) 的 1K 漫反射图用于屋面并调成森林绿；[Wooden Planks](https://polyhaven.com/a/wooden_planks) 的 1K 漫反射图用于地板。两者均为 CC0，详情见 `assets/manifest.json`。
- **画面层级：** 房屋整体轮廓优先；其次是屋顶分层、墙体框架、门窗和室内简化陈设。
- **风格假设：** 象牙白墙面、浅色木框架、深森林绿双坡瓦屋顶；材质哑光，边缘清晰。屋面以 Poly Haven Grey Roof 01 CC0 纹理着色为绿，地板使用 Wooden Planks CC0 纹理。

## 尺度和坐标

- **Blender 单位：** 米制，1 Blender unit = 1 m。
- **主体预计尺寸：** 宽 6 m（X 轴）× 深 5 m（Y 轴）× 高约 4.2 m（Z 轴）。基础宽、深各多出约 0.1 m。
- **地面：** 水平地面，Z = 0；基础顶部约 Z = 0.2 m。
- **轴向：** Z 向上；房屋正面朝 +Y；屋脊沿 Y 轴延伸。
- **空间布局：** 单一开放式室内，不做额外隔墙；家具仅用于提示尺度。

## 构图、相机和灯光

- **页面默认镜头：** 三分之二视角的中远景，房屋占画布高度约 65%–80%，完整留出屋顶和地面边界。
- **相机方位：** 位于正面 +Y 与右侧 +X 之间，俯视约 20°–30°；焦点略高于地板。
- **背景：** 浅暖灰纯色背景，地面与背景低对比衔接。
- **灯光：** 左上方大面积暖白主光，辅以柔和环境光；阴影柔和且方向稳定。
- **反射：** 不使用镜面地面；玻璃只做低反射、略带冷色的简化效果。

## 材质与细节

- **主要材质：** 暖白墙板、浅蜂蜜色木框架、深森林绿屋顶、浅灰基础、透明度克制的淡蓝窗玻璃。
- **必须表现：** 屋脊与椽条、墙体框架、门窗框、基础与地板层次；墙板拆开后仍能看清室内地板和家具。
- **细节策略：** 倒角只用于外露边缘；螺钉、密集木纹、室内装饰品不作为首期重点；公开纹理仅使用 1K 漫反射图，其他材质使用纯色。
- **应避免：** 过度写实、过多装饰、玻璃遮挡室内、爆炸后部件互相穿插、极暗背景和粒子特效。

## 网页交互

| 输入 | 作用 | 边界/重置方式 |
| --- | --- | --- |
| 鼠标左键拖动 / 单指拖动 | 绕房屋旋转 | 限制俯仰角，避免翻转；“复位”恢复默认观察角 |
| 滚轮 / 双指捏合 | 缩放 | 限制最近/最远距离，不能穿过模型 |
| 鼠标右键拖动 / 双指平移 | 平移观察中心 | 设置场景边界；“复位”清除平移 |
| 爆炸滑杆 0%–100% | 屋顶覆盖上移、屋架上移、墙板按方向外移 | 0% 为组装状态；100% 为构件完全分离；连续可逆 |
| 构件组复选框 | 显示/隐藏屋顶、结构、墙板、门窗、室内陈设 | “显示全部”恢复所有组 |
| 单击/触屏点按部件 | 高亮部件并显示名称、作用、材质 | 单击空白处清除选择；说明面板提供键盘可达控件 |
| 复位按钮 | 恢复镜头、拆解进度和全部可见组 | 保留页面当前的模型加载状态 |

## 禁止项和实施约束

- **不得出现：** 未记录来源的外部模型或贴图、需要登录的运行时 API、浏览器密钥、超预算的网格/文件、爆炸视图中无法复位的对象状态。
- **可接受的近似：** 非施工级比例表达；室内结构与门窗五金采用低多边形简化；墙板以独立面片表达而非真实墙体层构造。
- **已确认规格：** 单层木结构小屋、约 6 m × 5 m × 4.2 m、暖白墙/浅木框/深绿屋顶、滑杆爆炸拆解、上述设备与性能预算，并尽量使用公开素材。
