# 城市通勤自行车对象规格

## 1. 目标与边界

新增一个可拆解、可检查、可操作的城市通勤自行车 3D 对象。模块使用 Three.js 在浏览器内构建模型，不引入后端、外部模型运行时或新依赖。自行车模型由参数化几何组成；金属表面使用随模块打包的本地贴图。

交互包含两个模式：

| 模式 | 目标 | 能力 |
| --- | --- | --- |
| 检视 | 了解总成和部件关系 | 轨道相机、点选部件、拆解滑块、总成显隐、装回与显示全部 |
| 操作 | 观察通勤骑行机构 | 加速、踏动、8 速变速、转向、前后刹车、停车脚撑、放倒与扶起 |

骑行使用封闭路线和简化运动学状态，不求解刚体动力学、地面附着、碰撞或真实道路交通。它用于说明部件和操控关系，不用于工程设计、尺寸放样或骑行安全验证。

## 2. 坐标与主要尺寸

模型坐标以米为单位：`x` 轴从后轮指向前轮，`y` 轴向上，`z` 轴沿车轴方向。车架参考点设在后轮轴心；车体侧面位于 `x-y` 平面。

| 尺寸 | 目标值 | 模型实现依据 |
| --- | ---: | --- |
| 轮径规格 | 700C | 轮圈半径 311 mm，轮胎外半径约 349 mm，外径约 698 mm |
| 轴距 | 1,080 mm | 后轴 `x=0`，前轴 `x=1.08` |
| 车把宽 | 680 mm | 横把左右各延伸约 340 mm |
| 曲柄长度 | 170 mm | 中轴至踏板轴心 |
| 牙盘 | 42 齿 | 链节节距 12.7 mm，齿圈半径按节圆计算 |
| 后飞轮 | 8 片，11–32 齿 | 32、28、24、21、18、15、13、11 齿 |
| 辐条 | 每轮 32 根 | 每侧 16 根，交叉编排并通过实例化网格绘制 |

这些值用于明确交互模型的比例和机构关系。当前模型的表面、管件截面和配件为展示用途的程序化几何，不等同于某一真实厂牌或可制造的车架图纸。

## 3. 总成与可拆解结构

模型由可独立显隐和拆解的 8 个总成组成。拆解量为 0–100%，每个总成沿局部方向移开；装回将拆解量归零。

| 总成 | 主要部件 |
| --- | --- |
| 车架 | 上管、下管、座管、链 stay、座 stay、头管、中轴壳、后叉端 |
| 转向 | 前叉、碗组、把立、平把、把套、刹把 |
| 前轮 | 外胎、胎纹、轮圈、32 根辐条、花鼓、反光片 |
| 后轮 | 外胎、胎纹、轮圈、32 根辐条、花鼓、反光片 |
| 传动 | 牙盘、曲柄、脚踏、链条、8 片飞轮、后拨与导轮 |
| 前刹车 | 刹车夹器、刹车皮、刹车线、前碟片 |
| 后刹车 | 刹车夹器、刹车皮、刹车线、后碟片 |
| 座椅与配件 | 座管、座垫、前后挡泥板、后货架、车灯和反光片、侧撑 |

总成之外，界面还允许按部件选择和查看名称、材质、关联部件及简要功能。总成隐藏后，部件不可点选；“显示全部”恢复所有总成。拆解和总成显隐仅在检视模式生效。

## 4. 操作与状态

### 检视

- 拖动空白区域旋转视角，滚轮缩放，右键拖动平移；提供放大、缩小和复位视角控件。
- 点选部件后显示高亮框、名称、材质、关联部件和说明。
- 拆解滑块按总成展示结构间距；提供“装回”和“显示全部”。
- 切换到操作模式时，总成回到装配状态并展示封闭骑行路线。

### 操作

- 页面控件支持按钮式加速/踏动、前后刹车、变速、转向、骑行/停车、侧撑和放倒/扶起。
- 画布聚焦后支持键盘操作：`W`/`↑` 加速，`S`/`↓` 刹车，`A`/`←` 和 `D`/`→` 转向，`[`/`]` 换挡，`P` 骑行或停车，`L` 放倒或扶起，`R` 复位。
- 拖动前轮、后轮、曲柄、链条、车把或刹把可直接观察对应机构的反馈；鼠标操作期间保留轨道相机的基础旋转与缩放能力。
- 骑行速度、挡位、转向角、刹车压力、路线位置和脚撑/倒地状态通过页面状态展示。高速放倒会先停车；速度降到阈值后才可放倒或扶起。

运动关系使用简化模型：踩踏通过当前齿比驱动后轮和链条；骑行期间两轮按行进距离滚动，曲柄按齿比同步；刹车减速并移动刹车把与刹车皮；转向使前叉转动并影响车体姿态。该模型不模拟部件受力或真实制动距离。

## 5. 材质、资源与加载

- 车架采用青绿色涂装，胎面使用深色橡胶，座垫和把套使用棕色材质，传动和金属部件采用钢/铝色调。
- 金属色、法线和粗糙度贴图来自 ambientCG 的 `Metal012`，按 CC0 1.0 许可随对象本地分发。来源和每个文件的处理记录见 [`resource-research.md`](./resource-research.md) 与 `assets/manifest.json`。
- 缩略图为模块内绘制的 SVG，不依赖远程图片。
- 贴图加载、模型构建和 WebGL 初始化分别报告状态；贴图失败时可重试，WebGL 初始化失败时重载页面再初始化。

## 6. 性能与验收边界

使用实例化网格绘制辐条、胎纹、牙盘齿、碟片孔和链节，减少重复几何的场景对象开销。全部贴图随应用打包；模型不请求外部服务。

验收关注：模块被对象目录自动发现；中英文内容随站点语言切换；模型可加载、旋转、缩放、点选和拆解；总成显隐和装回有效；骑行操控使车轮、曲柄、链条、转向、刹车、脚撑和倒地状态产生可见反馈；窄屏控件可访问；资源来源和许可可追溯。
