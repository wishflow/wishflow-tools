# 自行车零件技术规格补齐记录

调研日期：2026-10-14。对应 [bicycle-spec.md](./bicycle-spec.md) 的 Giant Escape Disc 4（2025，美国版，M 码）展示模型。本记录只补建模依据，尚未生成模型、采用外部 CAD 或证明实物配件兼容性。

## 1. 证据使用规则

公开的型号页、维修爆炸图和接口规格可以补充很多遗漏，但不同资料回答的问题不同：型号页确认功能和少量尺寸；爆炸图确认组成与连接顺序；接口规格确认连接边界。无尺寸标注的爆炸图不是等比例工程图，不能从图上直接读出整个零件的精确尺寸。

| 标记 | 数据性质 | 允许的用法 |
| --- | --- | --- |
| F | 原车或原车明确型号的制造商事实 | 用于本车尺寸、数量或配置合同 |
| P | 制造商公布的通用接口、同系列或代理零件数据 | 可以定义通用展示件；不得标为原车实测或原厂完整型号 |
| C | 根据已注明输入计算的数值 | 记录公式与输入；计算精度不等于实物精度 |
| D | 为使展示模型完整而明确选择的设计值 | 可用于可复现建模；不得反过来引用为厂方事实 |
| U | 本次公开调研未确认的项目 | 实施时选择并记录 D，或继续寻找图纸/实测；不得由 Agent 无说明地猜值 |

以下尺寸均以 **mm** 记录，进入 Blender 或 Three.js 时统一除以 `1000` 转换为 m。直径、节距、销长、轴向间距和零件外包尺寸必须分字段保存，不能统称为“宽度”。

## 3. 飞轮、牙盘与链条

### 3.1 原车飞轮齿数与装配结构

Shimano 的 CS-HG200-8 `br-group` 维修页明确列出 8 个齿数。图中的最小片为带内置垫隔的 `12T` 齿片，另有锁环；建模时不能把最小片、锁环和全部垫隔一起画成无区别的实体圆锥。[官方爆炸图](https://si.shimano.com/en/pdfs/ev/CS-HG200-8-3749/EV-CS-HG200-8-3749.pdf)

| 字段 | 输入值 | 测量基准 | 证据性质 |
| --- | ---: | --- | --- |
| 片数 | 8 | 可见独立齿片数量 | F，CS-HG200-8 官方 EV |
| 小片 → 大片齿数 | `12, 14, 16, 18, 21, 24, 28, 32` | 每片完整一圈实际齿尖数量 | F，同上 |
| 40T 单牙盘 | 40 | 完整一圈齿尖数量 | F，[Giant 原车规格](https://www.giant-bicycles.com/us/escape-disc-4-2025) |
| 相邻片中面轴向距离 | 尚未确认 | 沿后轮轴，从一片齿片中面至下一片中面 | U，CS-HG200-8 EV 没有尺寸标注 |
| 飞轮齿片厚度 | 尚未确认 | 齿片实体两侧面法向距离 | U；与垫隔厚度分开记录 |
| 8 片中面间距建模候选 | `4.8` | 等间距展示件中面 | D，不宣称 Shimano 对本型号公布此值 |
| 齿片厚度建模候选 | `1.8` | 薄片总厚度 | D，与候选 `3.0` 垫隔共同构成 `4.8` 中面距离 |

候选 `3.0` 垫隔有另一款 Shimano 8 速产品的官方零件表可作量级参照：[CS-HG70-C8ah，EV-1476A](https://si.shimano.com/en/pdfs/ev/CS-HG70-C8ah-1476/EV-CS-HG70-C8ah-1476A.pdf) 明列 `t=3.0 mm`。该旧款与 CS-HG200-8 不能据此视为零件互换，也不能据此确认本车所有片间距。D 设计候选须在具体模型参数表中批准后再使用。

### 3.2 节圆计算

链节的相邻销心距离为 `p=12.7 mm`。为了让链节销心在链轮上形成正确的等边多边形，建模使用：

```text
链轮节圆半径 r(N) = p / (2 × sin(π / N))
N 为齿数，p 为相邻销心距离。
```

这是 C 计算，不是 Shimano 的齿顶、齿根或变速导角工程图。齿尖外径、齿根圆角、换挡斜坡和每齿轴向修形仍需独立处理；不能把下表半径直接当作网格外半径。

| 齿数 N | 节圆半径 r（mm，显示到 0.001） | 用途 |
| ---: | ---: | --- |
| 12 | 24.535 | 原车最小飞轮片 |
| 14 | 28.537 | 原车飞轮片 |
| 16 | 32.549 | 原车飞轮片 |
| 18 | 36.568 | 原车飞轮片 |
| 21 | 42.605 | 原车飞轮片 |
| 24 | 48.649 | 原车飞轮片 |
| 28 | 56.714 | 原车飞轮片 |
| 32 | 64.785 | 原车最大飞轮片 |
| 40 | 80.934 | 原车单牙盘 |
| 13 | 26.534 | RD-TX800 代理导轮 |

计算来自上述公式、KMC 链节节距、Giant 牙盘齿数及 Shimano 飞轮/导轮齿数。小数位只为复现计算，不能用作这些零件达到微米精度的声明。

### 3.3 链节输入及不能从包装得到的参数

| 字段 | 值 | 测量基准 | 来源与边界 |
| --- | ---: | --- | --- |
| 相邻销心节距 | `12.7` | 单节两个销心的中心距离 | F/C，`1/2 in×25.4`；[KMC Z8.3](https://www.kmcchain.com/en/product/bicycle-chain-z83-8-speed) |
| 链条名义内宽 | `2.38125` | `3/32 in×25.4` 对应的名义内宽；不等于外板之间总宽 | F/C，同上；实物净宽和公差未公布 |
| 链销总长 | `7.3` | 沿链销轴，从销一端至另一端 | F，[KMC 2024–2025 Dealer Catalog，印刷页 32](https://www.kmcchain.com/att/download/en/70/2024-2025%20Dealer%20Catalog-en.pdf) |
| 包装链节数 | `116` | 美国商品包装供应长度 | F，[KMC USA Z8.3](https://kmcchain.us/products/z8-3)；**不是本车最终链节数** |
| 内外板厚、板高、滚子外径、销径 | 尚未确认 | 各零件实体尺寸 | U，公开商品表与上述目录未给加工尺寸 |
| 装车链节数 | 按最终闭合路径求解并取合适的偶数 | 经 40T、当前飞轮片和上下导轮的闭合销心路径 | D；不能把包装 `116` 节直接环绕到任意路径 |

滚子外径、板厚和板高的 D 设计值由 [blender-modeling-spec.md](./blender-modeling-spec.md) 的传动表统一管理，在闭合路径、片间净空和视觉审核中修订。这些值没有被本次制造商资料确证，不得写为 KMC 的正式尺寸。销长 `7.3` 不应被误用为两片外板内面的间距。

链条必须表现交替内链节/外链节、销轴、滚子和一个闭合接头；每节销心距离保持 `12.7`。换挡时改变的是链条在飞轮侧的轴向位置与后拨姿态，不能只把一根圆管整体平移而宣称完成了真实链条建模。

## 4. Tourney TX 后拨代理件

原车只列 `Shimano Tourney TX`，没有 `RD-TX800` 完整代码。下列资料用于创建“通用 Tourney TX 机构展示件”；其尺寸/形态只能按 P 或 D 管理。

[Shimano RD-TX800 官方页](https://bike.shimano.com/en-AU/products/components/pdp.P-RD-TX800.html)确认 7/8 速系列、双伺服平行四边形机构、两只 `13T` 导轮和 `43T` 总容量。[EV-RD-TX800-3745](https://si.shimano.com/en/pdfs/ev/RD-TX800-3745/EV-RD-TX800-3745.pdf)可核对限位螺钉、B 轴与垫片、B 张力螺钉、上下导轮和内导板的拆装关系。

| 参数 | 值 | 建模基准 | 数据性质 |
| --- | ---: | --- | --- |
| 上导轮 / 张紧导轮 | `13T / 13T` | 每轮完整齿数 | P，RD-TX800 官方页 |
| 导轮节圆半径 | `26.534` | 链销心包络节圆 | C，按 `12.7/(2sin(π/13))` |
| 限位调节螺钉 | `M4×19.3` | 名义直径和螺钉长度 | P，RD-TX800 EV |
| B 张力调节螺钉 | `M4×17.5` | 名义直径和长度 | P，同上 |
| 上导轮轴螺钉 | `M5×15.2` | 沿导轮轴 | P，同上 |
| 张紧导轮轴螺钉 | `M5×13.35` | 沿导轮轴 | P，同上 |
| 常规尾钩接口 | `M10×1.0` | 后拨与尾钩螺纹连接 | P，[Park Tool TAP-10 制造商说明](https://www.parktool.com/en-int/product/frame-tap-tap-10)；不是 Escape 的尾钩外形图 |
| 上下导轮轴心距、笼板轮廓、四连杆轴距 | 尚未确认 | 三维轴心与实体轮廓 | U；EV 没有标注这些尺寸，不能按印刷比例缩放 |

如无法获得实物/工程图，代理件使用补充规格中统一选择的 D 导轮轴心距，并在后轮、最大32T飞轮、链条闭合路径和地面净空中校正，不成为 TX800 的官方验收值。导轮旋转、笼板绕其张紧铰点转动、四连杆横向移动三个动作需有独立节点。尾钩原点与导轮原点不可合并，否则换挡会把整个后拨移离车架。

## 5. 机械碟刹、安装位与拉线

### 5.1 可直接用于代理件的尺寸

[Tektro MD-M280 官方页](https://www.tektro.com/mtb/product/41)确认拉线机械结构、适用 linear pull 刹把、两片式铝/钢卡钳体和 `1.8 mm` 转子厚度；原车卡钳型号和 Giant MPH 的厚度没有确认。6 孔转子的 `6×M5` 与 `44 mm PCD` 来自 [Hope Rotor Tech Book 2023，印刷页 009](https://www.hopetech.com/webtop/modules/_repository/1/documents/Rotor_Tech_Book_2023%281%29.pdf)。这些能锁定一个可信通用机械碟刹组合，不能证明是原车全部原厂件。

| 字段 | 值 | 测量基准 | 状态 |
| --- | ---: | --- | --- |
| 前 / 后转子外径 | `160 / 160` | 轴心至完整圆周外缘的直径 | F，[Giant 原车规格](https://www.giant-bicycles.com/us/escape-disc-4-2025) |
| 转子厚度 | `1.8` | 碟片两磨擦面的法向距离 | P，Tektro MD-M280 代理输入 |
| 转子安装孔数 | `6` | 环绕花鼓轴均匀排列 | P，Hope 标准 6 孔接口 |
| 孔中心圆直径 | `44` | 安装孔中心形成的圆 | P，同上；孔中心半径为 C：`22` |
| 转子安装螺钉 | `6×M5` | 轴向固定于花鼓 | P，同上；原车转子尚未确认采用该接口 |
| Post Mount 安装孔轴心距 | `74` | 两安装螺栓孔中心间距离 | P，[SRAM 公开安装规格](https://www.sram.com/globalassets/document-hierarchy/frame-fit-specifications/aftermarket/disc-brake-caliper-mounting-specifications-for-road-and-mtb.pdf)，前叉接口识别图 |
| IS 安装孔轴心距 | `51` | 两安装孔中心间距离 | P，同上；不能直接等同 Post Mount |

通用展示组合建议采用 `160×1.8` 转子、6 孔 `44 PCD` 与 PM `74` 卡钳连接边界，整体标 P/D。原车前叉/车架实际采用 PM 还是 IS、是否需要转接座，本次未确证；固定连接方案时必须明确选择，不能同一网格把两套孔位画在一起。卡钳应位于转子制动环上，两侧来令片夹住转子；完整卡钳体外包尺寸、来令片轮廓、转子磨擦环内径和开孔形状仍 U。`160` 只规定转子外径，不能推出这些细项。

转子与轮子共同绕花鼓轴旋转；卡钳根节点属于车架或转向总成，不能随轮转。拉线外管用有连续弯曲半径的曲线连接刹把出口、车架固定点和卡钳调节座；线端压帽和卡钳夹线螺钉独立可识别。

## 6. 曲柄、五通、座杆与座垫

### 6.1 五通与曲柄接口

原车的五通只写 `cartridge`，牙盘组只写锻造铝合金 `40T`，没有轴长、方轴/OCTALINK 等完整安装信息。封装轴承本身不足以确认接口。可以选一个与简化学习目标一致的通用卡式方轴代理结构，但不能宣称该结构已被 Giant 对本车确认。

| 项目 | 候选输入 | 基准、来源与状态 |
| --- | --- | --- |
| 曲柄长度 | `170` | F，[Giant M 码原车表](https://www.giant-bicycles.com/us/escape-disc-4-2025)，中轴心至脚踏轴心 |
| 中轴代理类型 | 卡式方轴，BB-UN300 结构参考 | P，[Shimano BB-UN300](https://bike.shimano.com/en-NA/products/components/pdp.P-BB-UN300.html) |
| 五通壳轴向长度 | D 选择 `68` | 只定义通用展示壳；原车宽度 U。Shimano 的通用 BB-UN300 存在 68 规格，见下方官方规格手册 |
| 英式五通接口标称 | `B.C.1.37"×24T` | P，[EV-BB-UN300-4708](https://si.shimano.com/en/pdfs/ev/BB-UN300-4708/EV-BB-UN300-4708.pdf) 的左适配杯标记；完整螺纹公差/旋向仍需适用标准或完整图纸 |

| 脚踏轴通用接口 | `B.C.9/16"×20 TPI` | P，[Shimano PD-M9200 官方 EV](https://si.shimano.com/ru/pdfs/ev/PD-M9200-5098/EV-PD-M9200-5098.pdf)；不同脚踏型号仅作接口事实来源 |
| 脚踏螺纹显示节距 | C：`25.4/20=1.27` | 由上述 TPI 转換，不代表真实牙型公差 |
| 中轴全轴长、左右凸出量、牙盘安装孔/铆钉、Q-factor、链线 | U | 不由 `170 mm` 曲柄长或 `40T` 推出；应结合最终通用代理件选择并记录 |

可参考 [Shimano 2024–2025 Specification Handbook v032](https://productinfo.shimano.com/pdfs/product/archive/2024-2025_Specifications_v032_en.pdf) 的 BB-UN300 规格（物理 PDF 第 221 页）与 [2026–2027 兼容表，印刷页 34](https://productinfo.shimano.com/pdfs/product/thisyear/2026-2027_Compatibility_v022_en.pdf) 的曲柄—五通—链线配对。后者明确不同曲柄组合有不同链线，因此不能“选了一根轴长，就自动把链线判成精确”。原车单牙盘没有型号，不能将 FC-TX801 三牙盘组件直接写为原车。

若当前展示模型需要一个确定轴长，可用 `122.5` 作为 D 代理候选；Shimano [2025 Genuine Parts，轴长选项表](https://si.shimano.com/en/pdfs/sm/CY25_GENUINE_PARTS/CY25_GENUINE_PARTS_O.pdf)列有这一供应规格。轴肩、方锥尺寸、装入深度、Q-factor 和牙盘平面仍按代理件装配定义，不能只以总轴长平均分成左右两段。中轴沿模型 `z` 轴；左右曲柄相位相差 `180°`；脚踏相对曲柄各有自己的旋转轴。

### 6.2 座杆和座垫

| 项目 | 可用值 | 测量基准与来源 | 状态 |
| --- | ---: | --- | --- |
| M 码座杆长度 | `350` | Giant D-Fuse 合金座杆名义长度，[本车规格 PDF](https://static.giant-bicycles.com/pdf/giant-escape-disc-4-en-us-3878.pdf) | F；不等于全部露出长度 |
| 座杆截面方向 | 前圆后平的 D 形 | [Giant 官方技术说明](https://www.giant-bicycles.com/tw/technology) | F，轮廓类型；截面宽、深、后平面位置仍 U |
| 座垫长 / 宽 | `260 / 150` | [Giant 加拿大 Ergo Contact 2023 商品规格](https://www.giant-bicycles.com/ca/ergo-contact-2023)，最大外包长度/宽度 | P，同名系列代理；原车 SKU 未确认 |
| 座垫 Stack | `53` | 同上厂家字段 `Stack Height` | P；官网未定义该尺寸端点，不能直接当作泡棉厚度或总网格高度 |
| 座垫导轨直径 | `7` | 同上 `Rail Size`，钢轨 | P；导轨轨距、弯曲坐标与夹持长度仍 U |

原车 D-Fuse 座杆不能为了方便而改成圆形 `27.2`、`30.9` 或 `31.6` 常规座杆，再称尺寸精确。若缺乏截面图，应定义 D 形参数化截面并标 D，保留“前圆后平”的证据约束。座垫外包尺寸可帮助定义轮廓比例，无法自动补出靠近座杆的导轨弯曲路径。

同名零件存在版本差异：Giant 日本的 [Ergo Contact Saddle 页面](https://www.giant-bicycles.com/jp/ergocontact-saddle-2023)当前描述 `2027` 起 Escape 配用的 `Uniclip Pro` 版本，不能把该页面与加拿大 `Uniclip` 规格混为同一个原车零件。使用图片辅助造型时，也必须记录实际页面、版本和查看日期。

## 7. 通用花鼓的官方数据线索

轮组详细建模参数由主规格统一管理；此处只保留可查证的代理件入口，避免把“不知道 Giant 花鼓尺寸”等同于“没有任何可用尺寸”。

[Shimano 2024–2025 Specification Handbook v032](https://productinfo.shimano.com/pdfs/product/archive/2024-2025_Specifications_v032_en.pdf)物理 PDF 第 58 / 62 页分别给 HB-M475 与 FH-M475 的数据：

| 代理件 | OLD | 孔数选项 | 法兰间距 | Offset | 辐条孔 PCD 左/右 | 法兰外径 | 安装 |
| --- | ---: | --- | ---: | ---: | --- | ---: | --- |
| HB-M475 | `100` | `32 / 36` | `59.2` | `5.5` | `61 / 61` | `70.6` | QR、6 孔碟片 |
| FH-M475 | `135` | `32 / 36` | `57.1` | `6.8` | `61 / 61` | `70.6` | QR、6 孔碟片、HG spline M |

全部为 P。OLD 是两端锁母外侧接触面的距离，法兰间距是左右法兰对应平面的距离，PCD 是辐条孔中心形成的圆直径；三者不可混用。左右法兰的实际 `z` 坐标需要结合 offset 定义及碟片/飞轮左右关系统一确定。Giant 仅明列合金 `32h`，未公布花鼓型号、端距和轴型；M475 是选择通用代理方案的资料，不是证明原车花鼓身份。

## 9. 数据和素材许可边界

本次没有下载并采用制造商 3D 资产，没有把制造商图片、工程图截图、商标或 PDF 原件复制到应用资源。文档使用少量规格事实、数学换算和链接，建模文件应自行生成。

Shimano 的上述 Specification Handbook 虽由官方 URL 公开提供，封面仍注明供产品开发人员使用，并禁止复印；因此保留链接和必要的尺寸事实，不分发原 PDF 或页面图。维修 EV 也保留 Shimano 版权信息，不能因可以在线阅读就把它视为 CC0 素材。其他制造商商品页同样没有授予模型/图片的开放再分发许可。社区 CAD 如果后续选用，必须单独核对作品页、作者、文件内许可和模型身份；“免费下载”与“可随公开网站再分发”是不同条件。

本页 P/D 表用于支撑完整、可信、可操作的通用展示件；F 项用于原车规格合同。外观、接口、动画层级仍须在最终装配上进行尺寸与视角审核。爆炸图的连接关系能够补齐组件层级，但不能单独支持“所有零件都与现实原车一一精确对应”的结论。
