# 自行车零件技术规格补齐记录

调研日期：2026-10-14。对应 [bicycle-spec.md](./bicycle-spec.md) 的 Giant Escape Disc 4（2025，美国版，M 码）展示模型。本记录补充建模依据；当前实现使用自制 Blender 几何，没有采用外部 CAD。D/P 值支持展示模型和装配检查，不证明实物配件兼容性。

## 1. 证据使用规则

公开的型号页、维修爆炸图和接口规格可以补充很多遗漏，但不同资料回答的问题不同：型号页确认功能和少量尺寸；爆炸图确认组成与连接顺序；接口规格确认连接边界。无尺寸标注的爆炸图不是等比例工程图，不能从图上直接读出整个零件的精确尺寸。

| 标记 | 数据性质 | 允许的用法 |
| --- | --- | --- |
| F | 原车或原车明确型号的制造商事实 | 用于本车尺寸、数量或配置合同 |
| P | 制造商公布的通用接口、同系列或代理零件数据 | 可以定义通用展示件；不得标为原车实测或原厂完整型号 |
| C | 根据已注明输入计算的数值 | 记录公式与输入；计算精度不等于实物精度 |
| D | 为使展示模型完整而明确选择的设计值 | 可用于可复现建模；不得反过来引用为厂方事实 |
| U | 本次公开调研未确认的项目 | 实施时选择并记录 D，或继续寻找图纸/实测；不得由 Agent 无说明地猜值 |

以下尺寸均以 **mm** 记录，进入 Blender 或 Three.js 时统一除以 `1000` 转换为 m。直径、节距、销长、轴向间距和零件外包尺寸必须分字段保存，不能统称为“宽度”。

## 3. 飞轮、牙盘与链条

### 3.1 原车飞轮齿数与装配结构

Shimano 的 CS-HG200-8 `br-group` 维修页明确列出 8 个齿数。图中的最小片为带内置垫隔的 `12T` 齿片，另有锁环；建模时不能把最小片、锁环和全部垫隔一起画成无区别的实体圆锥。[官方爆炸图](https://si.shimano.com/en/pdfs/ev/CS-HG200-8-3749/EV-CS-HG200-8-3749.pdf)

| 小片 → 大片齿数 | `12, 14, 16, 18, 21, 24, 28, 32` | 每片完整一圈实际齿尖数量 | F，同上 |

| 飞轮齿片厚度 | 尚未确认 | 齿片实体两侧面法向距离 | U；与垫隔厚度分开记录 |

候选 `3.0` 垫隔有另一款 Shimano 8 速产品的官方零件表可作量级参照：[CS-HG70-C8ah，EV-1476A](https://si.shimano.com/en/pdfs/ev/CS-HG70-C8ah-1476/EV-CS-HG70-C8ah-1476A.pdf) 明列 `t=3.0 mm`。该旧款与 CS-HG200-8 不能据此视为零件互换，也不能据此确认本车所有片间距。D 设计候选须在具体模型参数表中批准后再使用。

### 3.2 节圆计算

链节的相邻销心距离为 `p=12.7 mm`。为了让链节销心在链轮上形成正确的等边多边形，建模使用：

```text
链轮节圆半径 r(N) = p / (2 × sin(π / N))
N 为齿数，p 为相邻销心距离。
```

这是 C 计算，不是 Shimano 的齿顶、齿根或变速导角工程图。齿尖外径、齿根圆角、换挡斜坡和每齿轴向修形仍需独立处理；不能把下表半径直接当作网格外半径。

| 齿数 N | 节圆半径 r（mm，显示到 0.001） | 用途 |
| ---: | ---: | --- |
| 12 | 24.535 | 原车最小飞轮片 |
| 14 | 28.537 | 原车飞轮片 |
| 16 | 32.549 | 原车飞轮片 |
| 18 | 36.568 | 原车飞轮片 |
| 21 | 42.605 | 原车飞轮片 |
| 24 | 48.649 | 原车飞轮片 |
| 28 | 56.714 | 原车飞轮片 |
| 32 | 64.785 | 原车最大飞轮片 |
| 40 | 80.934 | 原车单牙盘 |
| 13 | 26.534 | RD-TX800 代理导轮 |

计算来自上述公式、KMC 链节节距、Giant 牙盘齿数及 Shimano 飞轮/导轮齿数。小数位只为复现计算，不能用作这些零件达到微米精度的声明。

### 3.3 链节输入及不能从包装得到的参数

| 字段 | 值 | 测量基准 | 来源与边界 |
| --- | ---: | --- | --- |
| 相邻销心节距 | `12.7` | 单节两个销心的中心距离 | F/C，`1/2 in×25.4`；[KMC Z8.3](https://www.kmcchain.com/en/product/bicycle-chain-z83-8-speed)。当前展示链路保持曲线弧长采样间距，不约束弯曲处相邻销的欧氏弦长 |
| 链条名义内宽 | `2.38125` | `3/32 in×25.4` 对应的名义内宽；不等于外板之间总宽 | F/C，同上；实物净宽和公差未公布 |
| 链销总长 | `7.3` | 沿链销轴，从销一端至另一端 | F，[KMC 2024–2025 Dealer Catalog，印刷页 32](https://www.kmcchain.com/att/download/en/70/2024-2025%20Dealer%20Catalog-en.pdf) |
| 包装链节数 | `116` | 美国商品包装供应长度 | F，[KMC USA Z8.3](https://kmcchain.us/products/z8-3)；**不是本车最终链节数** |
| 内外板厚、板高、滚子外径、销径 | 尚未确认 | 各零件实体尺寸 | U，公开商品表与上述目录未给加工尺寸 |
| 装车链节数 | 按最终闭合路径求解并取合适的偶数 | 经 40T、当前飞轮片和上下导轮的闭合销心路径 | D；不能把包装 `116` 节直接环绕到任意路径 |

滚子外径、板厚和板高的 D 设计值由 [blender-modeling-spec.md](./blender-modeling-spec.md) 的传动表统一管理，在闭合路径、片间净空和视觉审核中修订。这些值没有被本次制造商资料确证，不得写为 KMC 的正式尺寸。销长 `7.3` 不应被误用为两片外板内面的间距。

链条必须表现交替内链节/外链节、销轴、滚子和一个闭合接头；每节销心距离保持 `12.7`。换挡时改变的是链条在飞轮侧的轴向位置与后拨姿态，不能只把一根圆管整体平移而宣称完成了真实链条建模。

## 5. 机械碟刹、安装位与拉线

### 5.1 可直接用于代理件的尺寸

[Tektro MD-M280 官方页](https://www.tektro.com/mtb/product/41)确认拉线机械结构、适用 linear pull 刹把、两片式铝/钢卡钳体和 `1.8 mm` 转子厚度；原车卡钳型号和 Giant MPH 的厚度没有确认。6 孔转子的 `6×M5` 与 `44 mm PCD` 来自 [Hope Rotor Tech Book 2023，印刷页 009](https://www.hopetech.com/webtop/modules/_repository/1/documents/Rotor_Tech_Book_2023%281%29.pdf)。这些能锁定一个可信通用机械碟刹组合，不能证明是原车全部原厂件。

| 字段 | 值 | 测量基准 | 状态 |
| --- | ---: | --- | --- |
| 前 / 后转子外径 | `160 / 160` | 轴心至完整圆周外缘的直径 | F，[Giant 原车规格](https://www.giant-bicycles.com/us/escape-disc-4-2025) |
| 转子厚度 | `1.8` | 碟片两磨擦面的法向距离 | P，Tektro MD-M280 代理输入 |
| 转子安装孔数 | `6` | 环绕花鼓轴均匀排列 | P，Hope 标准 6 孔接口 |
| 孔中心圆直径 | `44` | 安装孔中心形成的圆 | P，同上；孔中心半径为 C：`22` |
| 转子安装螺钉 | `6×M5` | 轴向固定于花鼓 | P，同上；原车转子尚未确认采用该接口 |
| Post Mount 安装孔轴心距 | `74` | 两安装螺栓孔中心间距离 | P，[SRAM 公开安装规格](https://www.sram.com/globalassets/document-hierarchy/frame-fit-specifications/aftermarket/disc-brake-caliper-mounting-specifications-for-road-and-mtb.pdf)，前叉接口识别图 |
| IS 安装孔轴心距 | `51` | 两安装孔中心间距离 | P，同上；不能直接等同 Post Mount |
| 代理来令片总厚度 | `4` | 单片背板与摩擦材料的合计轴向厚度 | P，[Tektro MD-M280 中文页](https://tektro.com/zh-Hant/product/41)与 [E10.11 官方页](https://www.tektro.com/zh-Hant/product/136)；厂方没有分别给两层厚度 |

通用展示组合建议采用 `160×1.8` 转子、6 孔 `44 PCD` 与 PM `74` 卡钳连接边界，整体标 P/D。原车前叉/车架实际采用 PM 还是 IS、是否需要转接座，本次未确证；固定连接方案时必须明确选择，不能同一网格把两套孔位画在一起。卡钳应位于转子制动环上，两侧来令片夹住转子；完整卡钳体外包尺寸、来令片轮廓、转子磨擦环内径和开孔形状仍 U。`160` 只规定转子外径，不能推出这些细项。

转子与轮子共同绕花鼓轴旋转；卡钳根节点属于车架或转向总成，不能随轮转。拉线外管用有连续弯曲半径的曲线连接刹把出口、车架固定点和卡钳调节座；线端压帽和卡钳夹线螺钉独立可识别。

## 6. 曲柄、五通、座杆与座垫

## 10. 第二轮补齐：同类零件约束与可复现设计值

本节将前文原车U项转为可以执行的P/C/D模型输入，并不改变原车资料未知的状态。前文旧外观候选（如五通外径40）已由本节及同类车资料更新；最终执行值统一见 [blender-modeling-spec.md](./blender-modeling-spec.md)。研究范围仅说明推测依据，修改推荐值须同步主规格。

本轮依据用户要求，对尚不能核实的尺寸给出一组**推荐建模值**。本节的 D 数字已经完成资料比对与装配推演，可作为补充规格的输入；括号内的范围是建模调整范围，不是厂家公差，也不要求 Agent 每次随机选取。保留 F/P/C/D 区分，是为了让模型能够重建并在新证据到来时准确替换字段。

原车真实尺寸未知与展示输入未定义是两种不同问题：后者在本节关闭；前者仍需要特定 SKU 工程图或实物测量。源文件若随后下载、测量出更可靠的数据，按 `F → P → C → D` 的适用边界更新，不把同类件自动提升为原车事实。

### 10.1 链条：从 082 通用链与 Z8.3 的已知外包约束推断

[RÖDER Sonderketten 官方目录，印刷页 14、物理 PDF 第 12 页](https://antriebstechnik-roeder.com/wp-content/uploads/sonderketten_webkatalog.pdf)的 DIN 8187/ISO 606 `082` 行给出 `p=12.7`、内板净宽最小 `2.38`、滚子直径最大 `7.75`、销径最大 `3.66`、板高最大 `9.9`、销长最大 `8.2`。这是一种同节距/内宽的通用滚子链，提供截面量级；现代变速自行车链的板廓、空心套结构和外宽不同，不能整体照搬。KMC Z8.3 的 `7.3` 销长仍优先于该代理销长。

| 参数/测量基准 | 推荐值 | 调整范围 | 等级、推断方法与不确定性 |
| --- | ---: | --- | --- |
| 滚子外径 | `7.75` | `7.60–7.75` | D；以 082 的 P 最大径作保守包络。KMC 原件未公开径值；若近照或已获许可模型显示更小滚子，可在范围内统一修改齿谷接触 |
| 销杆外径，不含铆头 | `3.60` | `3.50–3.66` | D；取通用 082 的 `3.66` 上限内值，不复制工业链的套筒配合公差 |
| 内/外板名义实体厚 | `0.90 / 0.90` | 各 `0.80–1.10` | D；与 `2.38125` 内宽、`7.3` 销长一起闭合截面。厂家未公布厚度，不能把本值引用为冲压加工数据 |
| 两销附近板体高度 | `8.20` | `8.00–9.90` | D；保留现有较窄变速链外观值，`9.9` 是通用代理量级上边界。未按工业链板高度直接复制 |
| 中部收腰高度 | `6.00` | `5.50–6.50` | D；腰部半高3.0，两销处半高4.1，连接圆顺曲线；避免每块板都变成实体长方形 |
| 内板之间名义净宽 | `2.38125` | 固定名义值 | F/C；仍由 KMC `3/32 inch` 计算，不等于滚子长度或链销长 |
| 滚子轴向长度 | `2.28` | `2.20–2.33` | D；在名义内宽内保留两端合计约 `0.10` 的可见间隙 |
| 内外板邻接面的轴向间隙 | `0.10` | `0.05–0.15` | D；用于避免求值网格共面闪烁并表现独立铰接，不是装配精度声明 |
| 半套/滚子内孔外观 | 套外径 `5.20`、套内孔 `3.70` | 外径 `5.0–5.4`、内孔 `3.65–3.80` | D；以 `3.6` 销径加径向0.05间隙，滚子壁厚约1.275。现代自行车内板的成形半套不能画成一根贯通外板的厚管 |
| 铆头直径/厚度 | `4.20 / 0.30` | `4.0–4.5 / 0.2–0.4` | D；铆头计入原有7.3销长，两端不再额外加长 |

以单个链销轴为局部 `w`，两内板中面位于 `w=±1.640625`，两外板中面位于 `w=±2.640625`；于是板体总外宽为 C：`2.38125+4×0.9+2×0.1=6.18125`，每端销在板体外的余量为 C：`(7.3−6.18125)/2=0.559375`。这组截面既保留原车销长，也不会把板体塞进滚子。变更板厚时同步重算中面、总外宽和销头余量，不能只改网格厚度。

板廓从两销心 `u=±6.35` 构建，销周围采用半径4.1的端部圆弧、中心腰部采用半高3.0的圆顺过渡，得到板体最大长度约 C：`12.7+8.2=20.9`。这是无品牌代理板；不仿制未取得尺寸的 KMC 冲压商标、斜槽或表面刻字。链节节距与首尾闭合仍由建模规格的离散销心合同验收。

飞轮各片需要真实数量的齿。通用齿形可先按已知滚子布置，以每齿的节圆销心为基准生成滚子口袋，再形成两口袋间的齿；不使用三角形尖刺代替滚子啮合。每片理想齿谷半径按 `r_pitch−3.875` 计算，为12/14/16/18/21/24/28/32T依次 `20.660 / 24.662 / 28.674 / 32.693 / 38.730 / 44.774 / 52.839 / 60.910`。齿顶外形建议按通用近似 `r_tip=12.7×(0.6+cot(π/N))/2`，对应 `27.509 / 31.631 / 35.734 / 39.823 / 45.939 / 52.043 / 60.168 / 68.283`（D/C）。该式在40T得到84.494，与上述SKF量级相符；这只是本模型选用的齿顶包络，不是 HG200 的变速齿廓标准。齿谷口袋、齿侧过渡与0.2倒角在滚子及内板净空下复核；专有换挡坡道采用可见浅凹槽D，不伪称工程复制。

### 10.3 后拨：展示模型的闭合链路实现

再次核对 [RD-TX800产品页](https://bike.shimano.com/en-AU/products/components/pdp.P-RD-TX800.html)及其 [EV拆装关系图](https://si.shimano.com/en/pdfs/ev/RD-TX800-3745/EV-RD-TX800-3745.pdf)，仍只有13T导轮、43T容量及螺钉事实，没有导板轴距工程图。当前展示模型采用D级简化结构：尾钩固定，上导轮轴心固定，导板绕上导轮轴心转动，下导轮随笼角移动；不声称复刻 TX800 的平行四边形和弹簧。每挡按牙盘、目标飞轮、两只导轮构成的闭合曲线求解笼角。

两片初始内面各距碟片0.25；固定片不动、动片最大轴向行程0.50、转子摩擦环展示形变0.25的原合同保留。拉线3.486与动片0.50用明确D传递比约0.1434同步，凸轮外观与该传递关系一致；这只是可见运动示例，不声明真实制动力和弹性。

### 10.6 本轮推断的验收方式

每个D字段有一个推荐值；实施中的修改应写回统一参数表。链条展示路径、齿谷滚子、卡钳片面和座轨夹头应分别保留可测对象，而不是为外观合并成不可识别的表面。需重点量测：

1. 链销总长7.3、链路名义总长1473.2、各挡链条对两只导轮的径向接触；展示件沿闭合曲线弧长均匀分布，不把链节弧长误差解释为曲率上的欧氏销心节距精度。当前检查不证明滚子落入每个齿槽或链板无碰撞。
2. 8片飞轮各中面固定在选定z坐标，塔基与片组不把长度34.90和直径34.90混淆；换挡只移动链条/后拨机构。
3. 上导轮轴心固定、尾钩固定；八个挡位均采用同一116节链路长度，导板绕上导轮轴心变化并保持下导轮与链路相接。
4. PM74孔轴同轴、耳面/凸台实际接触、4mm片厚、摩擦面真实位于60–78环带；主体外包与含耳外包分开报告。
5. 座轨夹持区中心距43、直径7，41夹块落在70直段内；Q178量两脚踏安装面，平台中心距另列279。

本节的合理范围不替代展示模型本身的测量容差。生成后仍按主规格的1/2mm基准容差以及链条/刹车细项容差核验；D值没有实现就不能报告该问题已修复。以上输入补全允许继续制作通用精细展示件，原车专有型面的准确性仍与证据等级一起展示。
