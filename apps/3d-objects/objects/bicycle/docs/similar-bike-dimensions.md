# 同类车资料与车架细节建模选值

> 研究日期：2026-10-14。本文补充 [Blender 建模规格](./blender-modeling-spec.md)，给原车未公开的车架、前叉和 D-Fuse 接口锁定可执行的默认值。当前只补资料与规格，尚未制作模型。

## 1. 选值原则与本轮发现

沿用 F/P/C/D/U 分级：F 为指定原车事实，P 为其他真实产品的代理资料，C 为计算结果，D 为本模型固定选值，U 为原车仍未知。以下推荐值全部属于 P、C 或 D，不宣称它们是 Giant Escape Disc 4 的实测工程尺寸。未另注的单位均为 mm。

保持原车 M 码的轴距、头管长、角度、Stack、Reach、叉偏移、后下叉长等 F 基准；同类车的完整几何不能整套替换这些基准。合理范围是研究时的筛选区间；[Blender 建模规格](./blender-modeling-spec.md) 是最终选值入口，Agent 实作采用其确定值，不能在范围内自行随机选尺寸。修改D值须同步主规格与本表。

本轮最有价值的新证据与修正如下：

主车架TIG焊缝默认宽2.5、起伏高0.6、纹理节距2.0，沿真实管交线连续，局部允许宽2–4、高0.4–1.0。原参数保留为D。公开管材图不提供焊缝工艺尺寸，不能用标准管壁推导焊道。端口切斜/焊接处按实体交线裁切，外形倒圆2–4；车架制造强度、残余应力和载荷没有在此选值中验证。

管壁只在开放的装配口、拆解截面与必要结构处建立，隐藏内部可使用轻量封闭网格；不因设了壁厚就增加全车螺纹/内部铸件。每个D值仍作为确定的建模输入，不保留“由Agent决定”字段。

## 4. 头管、碗组、舵管与把立的闭合尺寸链

Giant指定车型页展示OverDrive技术，其通用说明给上1⅛、道路下1¼系列；页面没有该钢叉的完整接口尺寸。为了与已有48量级下头管、刚性前叉和合理的冠轴尺度相容，本模型选 `ZS44/28.6 + EC44/33`。这是D装配决策，Cane Creek只能证明对应P件存在；没有厂商BOM时仍不声明原车一定用该碗组。

| --- | --- | --- |
| 头管长度/轴线 | F：J→H，130，71° | 保持F，不能通过改头管长度解决其他部件干涉 |
| 头管外径 t=0/0.5/1 | D：`50.8 / 48 / 50.8` | 端部48–52；Fairing有50.8 OD/43.5 ID铝头管毛坯，尺寸量级P。端部孔44，上下端有效壁厚3.4；中段孔36，内部与舵管至少2间隙 |
| 上下碗组插入孔 | P接口44；D实体44.0孔，插入段长12 | 孔径接口锁44；不通过缩碗组适配旧44外径。模型插入筒43.9，0.05径向展示间隙不是真实压入配合公差 |

| 把立/车把中心 | 保持F臂长90、标称15°；D水平安装角34° | `K=(838.565,880.930,0)`；把夹中心 `K+90(cos34°,sin34°,0)≈(913.179,931.258,0)`。这是C/D坐标，替换未闭合堆叠的旧坐标；把宽640及25.4夹径不变 |

下碗组的冠座点 `Cr≈(897.167,710.736,0)`，叉体近冠几何基准仍 `Cb=J+20d≈(899.772,703.172,0)`。冠座与叉体基准之间8轴向距离为D连接实体。保留F前轴 `B=(1075,349,0)`，则：

- 冠座至轴中心**三维直距** `|B−Cr|≈403.085`（C）；转向轴方向投影 `(B−Cr)·d≈399.925`（C）；两者不要都命名为400冠轴长。
- 相对转向轴的偏移约50.374（C），0.374差来自整车F几何字段取整，按主规格闭合修正合同处理；不要强行同时锁死四舍五入的所有字段。
- Surly400与Trek410仅说明这一冠轴尺度合理；网页测量定义未逐一证实相同，因此不拿403.085与某代理400做毫米级精度断言。

## 5. 前叉路径、轮胎与挡泥板净隙

叉腿中心路径先锁以下D控制点，浏览器坐标 `(x前,y上,z传动侧)`，左右按z镜像。两条相接三次Bezier在连接处保持C¹连续；截面按第3节变化并沿正交框架扫掠。

| 第一段控制点 | 第二段控制点 |
| --- | --- |
| `(899.772,703.172,±41)` | `(980,535,±46)` |
| `(926,655,±43)` | `(1003,472,±48)` |
| `(957,598,±44)` | `(1059,382,±50)` |
| `(980,535,±46)` | `(1075,349,±50)` |

两腿近冠左右中心距82，20横向截面得到62名义内净宽，55外宽挡泥板在这一截面有3.5/侧余量。原中心距50配20截面只有30名义净宽，不能作为已证明适配38胎与55挡泥板的输入。实际开口还要按路径与椭圆方向逐段检查；62只证明冠侧横向量级，不能替代整叉扫掠体的碰撞检查。

叉冠为联通舵管与左右叉腿的钢制拱形壳，D外包宽102、侧面厚14、钢壁1.5，中央下凹避让区域由挡泥板外表面向外法向偏移3形成。总冠体外包仅作初始造型，内部开口优先满足实际净隙；不得把102×14矩形块跨接到挡泥板里。

轮胎表面到叉腿/冠最小静态净隙取D=6，挡泥板外面到叉腿/冠取D=3，挡泥板内面到胎面仍按主规格8。筛选区间分别6–10、3–5、8–12。Giant另款悬挂叉手册提出至少6轮胎间隙，本模型只将其作为保守的P量级参考，不把悬挂叉要求当此钢硬叉的原厂证据。[Giant Crest SL 手册](https://static.giant-bicycles.com/Manuals/MY22CRESTSLusermanualEN_1649415497.pdf)

前轮最高点位于x1075；叉冠约x900。检查高度时必须在同一横向截面、相应x/y位置比较两者的实际网格距离。不能以“轮胎最高y698、冠y703”两数直接证明穿模或间隙。若最终网格达不到净隙，优先调整D冠开口/叉腿局部截面与路径，保持B/H/J、1075轴距、71°和50名义偏移。

以下30.4名义系列、同系列长度端点与约11.45后移有P依据；完整外形和装配仍是D。将杆底到导轨夹持中心350、插入250、外露100保持为本模型端点合同，其材质依原车F合金。

## 8. 能锁定与仍无法证明的边界

公开资料已经足够为每个可见接口和管段提供一组稳定的D默认值，Agent可以开始按同一输入建模，并按实际网格做避让修正。需要修正的D参数必须记录改动和原因；任何修正不能偷偷覆盖F整体几何。

仍无法证明的是指定2025地区车型的逐管CAD、真实单抽端的位置、D-Fuse准确平面/夹头/壁厚、钢叉冠内部成形、勾爪与安装孔完整图。制造商产品页只给型号类别与总体几何；公开同类件可支持尺寸量级与标准接口，无法证明本车型隐藏曲面和装配公差。照片也不足以反推出内壁、内藏楔块与加工配合。
