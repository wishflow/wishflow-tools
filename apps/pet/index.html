ChatGPT desktop · macOS / WindowsChatGPT 桌面端 · macOS / Windows

  1. Install Usagi on this computer with the command for your system.按当前系统运行对应命令，将 Usagi 安装到这台电脑。

    macOS

    curl -fsSL "https://raw.githubusercontent.com/wishflow/wishflow-tools/master/apps/pet/install.sh" | sh

    Windows PowerShell

    irm "https://raw.githubusercontent.com/wishflow/wishflow-tools/master/apps/pet/install.ps1" | iex
  2. Open Settings → Pets, refresh the list, then select Usagi.打开 Settings → Pets，刷新列表，然后选择 Usagi。
  3. Show it with /pet or the app's Show pet control. Right-click Usagi or choose Hide pet to hide it.输入 /pet 或使用应用里的 Show pet 控件显示宠物；右键点击 Usagi 或选择 Hide pet 可隐藏。

The installer verifies both files before copying and stops if existing content conflicts. Desktop pets stay on this computer and do not automatically sync to the web.安装器会在复制前校验两个文件；若现有内容冲突会停止。桌面宠物保存在这台电脑，不会自动同步到网页端。

ChatGPT on the webChatGPT 网页端

  1. Download the original sprite sheet.下载原始精灵图集。
    Download spritesheet.webp下载 spritesheet.webp↓
  2. Open Settings → Personalization → Pet.打开 Settings → Personalization → Pet。
  3. Choose Upload pet, select the downloaded WebP file, then choose Usagi in the pet picker.选择 Upload pet 并上传刚下载的 WebP 文件，然后在宠物选择器中选择 Usagi。

Web selection is separate from installing files for the desktop app.网页端选择与桌面端安装文件相互独立。

Interactive Codex CLI交互式 Codex CLI

  1. Install using the command for your shell.按当前 shell 运行对应安装命令。

    macOS / Linux shell

    curl -fsSL "https://raw.githubusercontent.com/wishflow/wishflow-tools/master/apps/pet/install.sh" | sh

    Windows PowerShell

    irm "https://raw.githubusercontent.com/wishflow/wishflow-tools/master/apps/pet/install.ps1" | iex
  2. In an interactive Codex CLI session, enter:在 Codex CLI 交互会话中输入：
    /pets uu-usagi

Use a terminal that supports Kitty graphics or Sixel. Pets are unavailable inside tmux and Zellij.终端需要支持 Kitty 图形协议或 Sixel；tmux 和 Zellij 内不可用。

Linux terminalLinux 终端

  1. Run this command in a shell:在 shell 中运行：
    curl -fsSL "https://raw.githubusercontent.com/wishflow/wishflow-tools/master/apps/pet/install.sh" | sh
  2. Start an interactive Codex CLI session and enter:启动 Codex CLI 交互会话并输入：
    /pets uu-usagi

The terminal must support Kitty graphics or Sixel. Pets do not work inside tmux or Zellij. This installs a CLI pet and does not provide a floating desktop pet.终端需支持 Kitty 图形协议或 Sixel；tmux 和 Zellij 内不可用。此方式安装的是 CLI 宠物，不提供桌面浮动宠物。

Platform steps follow the official Pets guide.平台操作步骤以 Pets 官方说明为准。

Remove the installed files删除已安装文件

Quit the app or CLI first. Remove only the uu-usagi folder; check CODEX_HOME first if you set a custom location.先退出正在使用宠物的应用或 CLI。只删除 uu-usagi 目录；若设置了自定义 CODEX_HOME，请先确认路径。

macOS / Linux

codex_home="$CODEX_HOME"
if [ -z "$codex_home" ]; then codex_home="$HOME/.codex"; fi
rm -r "$codex_home/pets/uu-usagi"

Windows PowerShell

$codexHome = if ([string]::IsNullOrWhiteSpace($env:CODEX_HOME)) { Join-Path $env:USERPROFILE '.codex' } else { $env:CODEX_HOME }
Remove-Item -LiteralPath (Join-Path (Join-Path $codexHome 'pets') 'uu-usagi') -Recurse

Do not remove the whole .codex or pets directory.不要删除整个 .codex 或 pets 目录。
