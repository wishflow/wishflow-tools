INSTALL

安装到本机

运行对应命令后，安装器会校验文件，再复制到你的 Codex 宠物目录。

macOS / Linux

curl -fsSL "https://raw.githubusercontent.com/wishflow/wishflow-tools/master/apps/pet/install.sh" | sh

Linux 仅保证文件安装。CLI 显示依赖支持 Kitty 图形协议或 Sixel 的终端；不承诺桌面浮动宠物功能。

Windows PowerShell

irm "https://raw.githubusercontent.com/wishflow/wishflow-tools/master/apps/pet/install.ps1" | iex

无需管理员权限。PowerShell 会在输出中显示安装路径和后续操作。

AFTER INSTALL

安装后如何选择

  1. 在 ChatGPT / Codex 的 Pets 设置中刷新列表，然后手动选择 Usagi。
  2. CLI 中可以运行 /pets uu-usagi 选择。

桌面端宠物保存在本机，不会自动同步到网页。Linux CLI 的显示能力取决于终端图形协议；tmux、Zellij 等环境可能无法显示。

REMOVE

卸载

退出正在使用宠物的界面后，只删除本包目录。使用自定义 CODEX_HOME 时，请先确认变量值。

rm -r "${CODEX_HOME:-$HOME/.codex}/pets/uu-usagi"
Pets 官方说明 素材原样保存，未重绘、转换或重排。
