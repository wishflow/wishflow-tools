Desktop files, web uploads, and terminal pets are set up separately. Follow the matching steps below.桌面端文件、网页端上传和终端宠物分别设置，请按对应场景操作。

01

MACOS / WINDOWSMACOS / WINDOWS

ChatGPT desktop appChatGPT 桌面端

Install the pet files on this computer. Use the command for your operating system.将宠物文件安装到当前电脑，并按操作系统运行对应命令。

macOS

curl -fsSL "https://raw.githubusercontent.com/wishflow/wishflow-tools/master/apps/pet/install.sh" | sh

Windows PowerShell

irm "https://raw.githubusercontent.com/wishflow/wishflow-tools/master/apps/pet/install.ps1" | iex

The installer checks both files before copying. It stops and keeps existing files if the target has conflicting content.安装器会先校验文件再复制。目标目录存在冲突时会停止并保留现有内容。

BROWSER浏览器

ChatGPT on the webChatGPT 网页端

Upload the sprite sheet in web settings. This is separate from installing a pet on the desktop app.在网页设置中上传精灵图集。网页端选择与桌面端本机安装相互独立。

Download the original sprite sheet下载原始精灵图集↓
  1. Open Settings → Personalization → Pet.打开 Settings → Personalization → Pet。
  2. Choose Upload pet and select the downloaded WebP file.选择 Upload pet，并上传刚下载的 WebP 文件。
  3. Select Usagi in the pet picker.在宠物选择器中选择 Usagi。

LINUX

Linux terminalLinux 终端

AFTER INSTALL安装后操作

Select and show Usagi安装后选择并显示 Usagi

Installation only adds files. Choose Usagi in the interface you want to use.安装过程只复制文件。请在你实际使用的界面中选择 Usagi。

ChatGPT desktop · macOS / WindowsChatGPT 桌面端 · macOS / Windows

  1. Open the profile menu and choose Pets, or open Settings → Pets.打开个人资料菜单并选择 Pets，或进入 Settings → Pets。
  2. Select Refresh, then choose Usagi.选择 Refresh，然后选择 Usagi。
  3. To show the pet, enter /pet or choose Show pet from the command menu. Right-click the pet or choose Hide pet to hide it.输入 /pet 或在命令菜单中选择 Show pet 来显示宠物；右键点击宠物或选择 Hide pet 可隐藏。

Desktop pets are stored on this computer and do not automatically sync to the web.桌面宠物保存在当前电脑，不会自动同步到网页端。

ChatGPT on the webChatGPT 网页端

  1. Open Settings → Personalization → Pet.打开 Settings → Personalization → Pet。
  2. Choose Usagi from Select pet. If you have not uploaded it yet, choose Upload pet and add the original sprite sheet first.在 Select pet 中选择 Usagi。若还未上传，先选择 Upload pet 并添加原始精灵图集。

Web selection is separate from the desktop pet files.网页端选择与桌面端宠物文件相互独立。

Interactive Codex CLI交互式 Codex CLI

Enter this command in the CLI session:在 CLI 交互会话中输入：

/pets uu-usagi

Use iTerm2 3.6 or later, or a terminal with Kitty graphics or Sixel support. Pets are unavailable inside tmux and Zellij.使用 iTerm2 3.6 或更高版本，或支持 Kitty 图形协议 / Sixel 的终端；tmux 和 Zellij 内不可用。

Platform steps follow the official Pets guide.平台操作步骤以 Pets 官方说明为准。

Remove the installed files删除已安装文件

Quit the app or CLI first. Remove only the uu-usagi folder; check CODEX_HOME first if you set a custom location.先退出正在使用宠物的应用或 CLI。只删除 uu-usagi 目录；若设置了自定义 CODEX_HOME，请先确认路径。

macOS / Linux

codex_home="$CODEX_HOME"
if [ -z "$codex_home" ]; then codex_home="$HOME/.codex"; fi
rm -r "$codex_home/pets/uu-usagi"

Windows PowerShell

$codexHome = if ([string]::IsNullOrWhiteSpace($env:CODEX_HOME)) { Join-Path $env:USERPROFILE '.codex' } else { $env:CODEX_HOME }
Remove-Item -LiteralPath (Join-Path (Join-Path $codexHome 'pets') 'uu-usagi') -Recurse

Do not remove the whole .codex or pets directory.不要删除整个 .codex 或 pets 目录。
