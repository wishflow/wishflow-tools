# Usagi 动画预览与安装指南：实现规格

## 1. 目标与范围

本文记录 WishFlow Tools 中 slug 为 pet 的静态应用实现。该应用在 /pet/ 提供 Usagi 精灵动画预览、按使用场景拆分的安装与选择指南，以及可复制给 Codex 的安装提示词。

导航页和详情页以英文作为首次访问默认语言，用户切换后记住偏好。导航目录仍由 apps/catalog.json 单一维护。详情页使用原生 HTML、CSS 和少量 JavaScript；不增加框架、服务端、API、账号或同步功能。

## 2. 素材完整性

原始宠物素材位于 pets/uu-usagi/。元数据和图集不得编辑、重绘、重编码、压缩或替换。详情页和导航图标都直接使用原始图集，通过 CSS 背景定位显示帧；不生成或保存裁切后的图像文件。

| 宠物 ID | uu-usagi |
| 显示名称 | Usagi |

| 图集尺寸 | 1536 × 1872 |
| 图集格式 | WebP |

原始 pet.json、spritesheet.webp、SHA256SUMS 及两个安装器中的哈希保持一致。构建复制素材时应保持原始字节。

安装器只校验并复制文件，不更改当前选择，不调用宠物服务，不操作其他宠物目录。现有校验和、目录冲突处理及安装目标保持不变。

## 4. 导航页目录与语言

每个 apps/catalog.json 项目需提供英文和中文名称、英文和中文描述，以及图标来源。图标可以是 emoji，也可以是项目内相对路径。相对图片路径必须安全且指向应用中的真实文件。

pet 项目的导航图标使用原始图集文件，不使用兔子 emoji。默认循环播放第 0 行第 0–5 列的待机动画；鼠标悬停或键盘聚焦项目卡片时，切换为第 1 行第 0–7 列的跑步动画。减少动态效果设置下显示静帧。生成 HTML 时名称、说明、slug、图标路径均需转义；目录验证需拒绝绝对路径和路径穿越。

site/index.html 使用英文默认文案；site/site.js 与 apps/pet/app.js 共用 localStorage 键 wishflow-tools-language。仅接受 en / zh 值，存储不可用时仍允许本页切换。当前页面只保存语言偏好，不向其他站点发送信息。

## 5. 详情页信息结构

页面提供顶部工具导航，宠物页可返回首页并跳转到其他工具，其他详情页可返回导航首页。页面主体按以下顺序组织：

1. Codex 安装提示词和复制/手动复制操作。
2. 页内锚点导航、Usagi 介绍、精灵图动画预览和模拟对话。
3. 按 ChatGPT 桌面端、ChatGPT 网页端、Codex CLI、Linux CLI 分成 ARIA 子标签；每个标签都包含安装和安装后选择步骤。
4. 素材声明和卸载方式。

所有用户可见说明、按钮、导航卡片和动态提示均提供中英双语。安装子标签支持点击以及左右方向键、Home、End 切换；原生按钮提供 Enter/Space 激活和可见焦点样式。

## 6. 精灵图预览

### 6.1 网格与定位

原始 WebP 尺寸为 1536 × 1872。当前图集按 8 列 × 9 行显示，每帧为 192 × 208。预览精灵以原始图集作为 CSS 背景，背景尺寸为 800% × 900%，CSS keyframes 和 `steps()` 以约 100 毫秒/帧的节奏更新背景位置；JavaScript 只切换预览状态，不用慢速定时器逐帧更新；不得导出裁切后的资源。

代表性预览帧位置（行列从 0 开始）：

| 预览状态 | 帧序列 |
| --- | --- |
| Idle / 待机 | 第 0 行，列 0–5 |
| Working / 工作中 | 第 3 行，列 0–3 |
| Running / 运行中 | 第 1 行，列 0–7 |
| Needs input / 等待确认 | 第 0 行第 4 列静帧 |
| Complete / 已完成 | 第 4 行，列 0–4 |

这些帧映射用于展示图集内容，不代表官方客户端内部动画状态与具体帧的绑定关系。模拟状态只更新当前页面的精灵显示。

### 6.2 减少动态效果

使用 prefers-reduced-motion 媒体查询。启用减少动态效果时，CSS 停止精灵动画，每个状态显示对应的静帧；CSS 同时减少过渡和其他动画。用户仍可通过键盘操作状态按钮、安装子标签和对话演示。预览舞台背景透明，不绘制棋盘格或独立色块。

## 7. 对话演示

状态选择按钮可直接显示待机、工作、运行、等待输入和完成的代表帧。模拟对话依次显示请求、运行状态、待确认状态和完成状态；确认按钮用于完成演示。

页面需清楚说明模拟内容不连接真实 Codex 会话，不读取或修改文件，也不代表宠物实际运行结果。演示不得访问服务端或产品私有 API。

## 8. 安装步骤与官方能力

安装和选择步骤放在同一子标签中，并按界面说明：

- ChatGPT 桌面端（macOS / Windows）：运行对应校验安装器；在 Settings → Pets 刷新并选择 Usagi；通过 /pet 或应用命令显示，使用 Hide pet 隐藏。
- ChatGPT 网页端：下载 spritesheet.webp；进入 Settings → Personalization → Pet，上传 WebP 并选择 Usagi。网页选择与桌面端文件安装相互独立。
- Codex CLI：安装后在交互式会话输入 /pets uu-usagi。终端需要支持 Kitty 图形协议 / Sixel；tmux 和 Zellij 不支持。以当前官方文档的兼容说明为准，不将说明绑定到某个终端版本。
- Linux CLI：使用 POSIX shell 安装；CLI 显示需要支持 Kitty 图形协议或 Sixel 的终端；tmux 和 Zellij 不支持。不要描述为桌面浮动宠物。

详情页将提示词快捷操作放在正文顶部；其后的安装标签只显示当前选中的场景，减少页面纵向长度。Web 场景独立提供原始 spritesheet.webp 下载，不要求本机文件安装。

界面名称、图像规格、选择方式和平台能力依 [Pets 官方文档](https://learn.chatgpt.com/docs/pets) 更新，页面不绑定具体产品版本号。

## 9. Codex 安装提示词

详情页提供双语提示词和复制按钮。提示词要求 Codex：

1. 识别系统以及当前表面，并选择对应安装器。
2. 只运行本仓库现有安装器，保留 SHA-256 校验，不绕过验证。
3. 发生目录冲突时立即停止，报告路径并保留现有文件；不覆盖或删除其他宠物。
4. 安装成功后，仅在当前界面存在明确受支持的选择控件时选择 uu-usagi；不调用私有 API，不编辑应用或账号内部状态，不虚报成功。
5. 不支持自动选择时，给出当前界面的 Settings、网页上传或 CLI 命令步骤。网页端需独立上传图集。

复制失败时展开只读文本框并聚焦、选中文字，供用户手动复制。剪贴板状态和提示语言跟随当前语言设置。

## 10. 素材声明与卸载

页面在独立区域说明素材非原创、仅用于非商业备份和分享，原作者与原始许可暂无法追溯；不声称作者身份，也不代替作者授予许可。找到来源后补充署名、原许可并依其要求调整分发。

卸载说明只删除 pets/uu-usagi。代码示例需分别支持 macOS/Linux 与 Windows PowerShell，并提醒使用自定义 CODEX_HOME 时先核实路径。不能提供删除整个 .codex、pets 或其他宠物的命令。

## 11. 验收

- 导航页和详情页首次访问为英文，切换中英后刷新或跨页面访问仍保持选择。
- 导航的每个项目卡片都有中英名称、说明和打开动作；Usagi 卡片使用原图集播放待机动画，悬停/键盘聚焦时播放跑步动画。
- 所有详情页可返回首页；Usagi 详情页顶部提供首页和其他应用链接。
- 页面顶部可复制 Codex 安装提示词；剪贴板不可用时显示手动复制文本框。
- 详情页提供 4 个可用鼠标和键盘切换的安装场景标签；每个面板包含安装与选择步骤。
- 精灵背景透明；CSS 以约 100 毫秒/帧切换图集，不再使用 360 毫秒定时器。
- 待机、工作、运行、等待确认、完成均可由键盘操作的按钮预览。
- 模拟对话有明确的“演示、不连接真实 Codex”说明，等待确认和完成可以交互。
- 系统减少动态效果时，预览和导航图标均显示静帧。
- 标签支持点击、左右方向键、Home、End；提示词复制可用，剪贴板拒绝时可手动选择文本。
- macOS、Windows、网页、Codex CLI 和 Linux CLI 步骤与官方 Pets 文档一致。
- 原始 pet.json 和 spritesheet.webp 的 SHA-256 未变，dist/ 副本哈希一致。
- 执行应用 test:ci、根目录 test:catalog 和 build:site；用内置浏览器检查首页和详情页；再执行 git diff --check。
- Markdown 文档完成后复制到 /tmp/var/wishflow-tools/apps/pet/。

- 不接入账号、私有 API、服务端或真实对话。
