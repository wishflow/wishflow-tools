# Usagi 动画预览与安装指南：实现规格

## 1. 目标与范围

本文记录 WishFlow Tools 中 slug 为 pet 的静态应用实现。该应用在 /pet/ 提供 Usagi 精灵动画预览、按使用场景拆分的安装与选择指南，以及可复制给 Codex 的安装提示词。

导航页和详情页以英文作为首次访问默认语言，用户切换后记住偏好。导航目录仍由 apps/catalog.json 单一维护。所有公开页面复用 `@wishflow/site-shell` 的页眉、项目侧栏、页脚和语言状态；宠物详情页的内容仍使用原生 HTML、CSS 和少量 JavaScript，不增加应用框架、服务端、API、账号或同步功能。

## 2. 素材完整性

原始宠物素材位于 pets/uu-usagi/。元数据和图集不得编辑、重绘、重编码、压缩或替换。详情页和导航图标都直接使用原始图集，通过 CSS 背景定位显示帧；不生成或保存裁切后的图像文件。

| 显示名称 | Usagi |

原始 pet.json、spritesheet.webp、SHA256SUMS 及两个安装器中的哈希保持一致。构建复制素材时应保持原始字节。

## 4. 导航页目录与语言

每个 apps/catalog.json 项目需提供英文和中文名称、英文和中文描述，以及图标来源。图标可以是 emoji，也可以是项目内相对路径。相对图片路径必须安全且指向应用中的真实文件。

pet 项目的导航图标使用原始图集文件，不使用兔子 emoji。默认循环播放第 0 行第 0–5 列的待机动画；鼠标悬停或键盘聚焦项目卡片时，循环播放第 4 行的 Jump 动画。减少动态效果设置下显示对应状态的首帧。生成 HTML 时名称、说明、slug、图标路径均需转义；目录验证需拒绝绝对路径和路径穿越。

`@wishflow/site-shell` 使用英文默认文案，并统一负责 `wishflow-tools-language` 的读取、持久化和切换；`site/site.js` 与 `apps/pet/app.js` 通过公共接口获取或订阅语言状态。仅接受 en / zh 值，存储不可用时仍允许本页切换。当前页面只保存语言偏好，不向其他站点发送信息。

### 4.1 全站悬浮宠物

共享站点在首页和 apps/catalog.json 登记的每个应用详情页注入 site/usagi-widget.css 与 site/usagi-widget.js。构建器向组件提供相对路径，使所有页面直接读取 /pet/pets/uu-usagi/spritesheet.webp；不复制或修改图集。

- 默认显示原图集的待机动画；悬停宠物或键盘聚焦宠物链接时，循环播放第 4 行 Jump，同时显示工具栏。动作选择器可循环预览全部九种状态；手动选择优先于悬停和模拟活动状态，“跟随状态”恢复活动状态控制。左右拖动或按左右方向键移动时临时播放对应方向的跑动行；交互结束后恢复手动动作或活动状态动画。工具栏提供快速聊天、动作选择器、语音和活动铃铛；活动托盘顶部的上箭头收起线程。支持 prefers-reduced-motion 静帧。
- 在 Usagi 详情页外点击宠物会打开 /pet/；在详情页点击会打开 Usagi / Mini 选择器。右键会打开 Hide pet 菜单，键盘聚焦后也可按 Shift+F10 打开；隐藏后提供恢复入口。拖动、方向键移动和位置记忆由网页组件实现，只在当前浏览器视口中有效。
- Usagi / Mini 显示选择与拖动位置保存在当前浏览器 localStorage 中。快速聊天创建仅存在内存中的本地示例线程，并显示 Running、Needs input、Ready 状态；活动托盘按 Needs input、Blocked、Ready、Running 优先级显示线程，点击线程打开其本地对话预览。线程状态不提供手动切换按钮。
- 语音入口显示桌面端语音能力说明，不模拟真实通话、不请求麦克风。页面详情预览与全站悬浮宠物彼此独立，不同步状态。网页组件不读取真实会话数据，不能浮在其他应用窗口上，也不能响应系统级快捷键。
- 鼠标或触屏拖动可移动宠物；拖动方向改变时同步切换第 1 行（向右）或第 2 行（向左）的跑动动画。聚焦宠物后按方向键移动；按左/右时也播放对应跑动动画，按 Esc 回到默认位置。位置保存在当前浏览器的 localStorage 中，并在窗口尺寸变化时限制在可见范围内。
- 控件提供中英文无障碍名称和焦点样式。触屏环境没有悬停时，控制栏保持可见。

全站组件由根目录 scripts/build-site.mjs 在构建时注入各页，不依赖应用间代码导入，不增加框架、服务端或 API。

## 5. 详情页信息结构

页面提供顶部工具导航，宠物页可返回首页并跳转到其他工具，其他详情页可返回导航首页。页面主体按以下顺序组织：

1. Codex 安装提示词和复制/手动复制操作。
2. 页内锚点导航、Usagi 介绍、精灵图动画预览和模拟对话。
3. 按 ChatGPT 桌面端、ChatGPT 网页端、Codex CLI、Linux CLI 分成 ARIA 子标签；每个标签都包含安装和安装后选择步骤。
4. 素材声明和卸载方式。

所有用户可见说明、按钮、导航卡片和动态提示均提供中英双语。安装子标签支持点击以及左右方向键、Home、End 切换；原生按钮提供 Enter/Space 激活和可见焦点样式。

## 6. 精灵图预览

### 6.1 网格与定位

原始 WebP 尺寸为 1536 × 1872。当前图集按 8 列 × 9 行显示，每帧为 192 × 208。预览精灵以原始图集作为 CSS 背景，背景尺寸为 800% × 900%；CSS 动画直接定位原图帧，JavaScript 只切换预览状态，不用慢速定时器逐帧更新；不得导出裁切后的资源。详情页固定预览只显示当前选定状态，悬停或聚焦不改变动作；左右拖动悬浮宠物或按左右方向键时播放对应跑动行。悬浮宠物在自动跟随状态时悬停播放第 4 行 Jump；手动选择后优先保持所选动作。Jump 按钮持续循环，直到选择其他状态。

原图集标准动画行位置（行列从 0 开始）：

| 动画语义 | 行和帧数 |
| --- | --- |
| Idle / 待机 | 第 0 行，列 0–5 |
| Running-right / 向右移动 | 第 1 行，列 0–7 |
| Running-left / 向左移动 | 第 2 行，列 0–7 |
| Waving / 挥舞金箍棒 | 第 3 行，列 0–3 |
| Jumping / 跳跃 | 第 4 行，列 0–4 |
| Failed / 失败或阻塞 | 第 5 行，列 0–7 |
| Waiting / 等待输入 | 第 6 行，列 0–5 |
| Running / 任务运行中 | 第 7 行，列 0–5 |
| Review / 已就绪并检查结果 | 第 8 行，列 0–5 |

悬浮宠物和详情页预览都按这组行语义显示状态：Running 使用第 7 行，而第 1、2 行表示角色向右或向左移动；挥舞预览按钮播放第 3 行原始四帧，Jump 使用第 4 行。导航卡片和悬浮宠物悬停时播放 Jump；详情页固定预览不响应悬停，只跟随当前选定状态。ChatGPT 桌面端的任务状态名为 Running、Needs input、Ready 和 Blocked；页面只在本地演示对应动画，不会接收真实客户端状态。

### 6.2 减少动态效果

使用 prefers-reduced-motion 媒体查询。启用减少动态效果时，CSS 停止精灵动画，每个状态显示对应的静帧；CSS 同时减少过渡和其他动画。用户仍可通过键盘操作状态按钮、安装子标签和对话演示。预览舞台背景透明，不绘制棋盘格或独立色块。

### 6.3 与桌面 Pet 的实现边界

现存 Usagi 资源包只有 `pet.json` 和 `spritesheet.webp`，不包含桌面客户端的渲染器、事件状态机或 v1 图集逐帧时长。网页沿用同一份原始图集，并按标准行语义映射待机、左右跑动、挥棒、跳跃和任务状态；导航卡片及悬浮宠物悬停播放第 4 行 Jump，详情页固定预览只响应其当前状态。网页交互由本项目的 CSS/JavaScript 实现，因此能对齐原始帧和状态语义，但不宣称复用了桌面客户端代码，也不保证原生事件时序、缓动或拖动手感逐像素一致。

## 7. 对话演示

详情页状态按钮和悬浮宠物动作选择器可预览待机、向右跑动、向左跑动、挥舞金箍棒、跳跃、失败、等待输入、任务运行中和检查完成。挥舞预览使用图集第 3 行原始四帧；Jump 使用第 4 行。详情页固定预览悬停时不改变状态，Jump 持续循环直到选择其他动作。悬浮宠物动作选择器支持“跟随状态”及手动选择；手动选择优先于悬停和模拟任务状态。任务状态只保留一个 Running 动画（第 7 行）；方向跑动（第 1、2 行）是宠物移动动作，不代表任务状态。模拟对话依次显示请求、Running、Needs input 和 Ready；确认按钮用于完成演示。

页面需清楚说明模拟内容不连接真实 Codex 会话，不读取或修改文件，也不代表宠物实际运行结果。演示不得访问服务端或产品私有 API。

## 8. 安装步骤与官方能力

安装和选择步骤放在同一子标签中，并按界面说明：

- ChatGPT 桌面端（macOS / Windows）：运行对应校验安装器；在 Settings → Pets 刷新并选择 Usagi；通过 /pet 或应用命令显示，使用 Hide pet 隐藏。
- ChatGPT 网页端：下载 spritesheet.webp；进入 Settings → Personalization → Pet，上传 WebP 并选择 Usagi。网页选择与桌面端文件安装相互独立。
- Codex CLI：安装后在交互式会话输入 /pets uu-usagi。终端需要支持 Kitty 图形协议 / Sixel；tmux 和 Zellij 不支持。以当前官方文档的兼容说明为准，不将说明绑定到某个终端版本。
- Linux CLI：使用 POSIX shell 安装；CLI 显示需要支持 Kitty 图形协议或 Sixel 的终端；tmux 和 Zellij 不支持。不要描述为桌面浮动宠物。

详情页将提示词快捷操作放在正文顶部；其后的安装标签只显示当前选中的场景，减少页面纵向长度。Web 场景独立提供原始 spritesheet.webp 下载，不要求本机文件安装。

界面名称、图像规格、选择方式和平台能力依 [Pets 官方文档](https://learn.chatgpt.com/docs/pets) 更新，页面不绑定具体产品版本号。

## 9. Codex 安装提示词

详情页提供双语提示词和复制按钮。提示词要求 Codex：

1. 识别系统以及当前表面，并选择对应安装器。
2. 只运行本仓库现有安装器，保留 SHA-256 校验，不绕过验证。
3. 发生目录冲突时立即停止，报告路径并保留现有文件；不覆盖或删除其他宠物。
4. 安装成功后，仅在当前界面存在明确受支持的选择控件时选择 uu-usagi；不调用私有 API，不编辑应用或账号内部状态，不虚报成功。
5. 不支持自动选择时，给出当前界面的 Settings、网页上传或 CLI 命令步骤。网页端需独立上传图集。

复制失败时展开只读文本框并聚焦、选中文字，供用户手动复制。剪贴板状态和提示语言跟随当前语言设置。
