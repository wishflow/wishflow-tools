## 非功能需求

| 维度 | 目标/预算 | 验收方式 |
| --- | --- | --- |
| 模型体积 | 默认不超过 20 MiB；按项目确认 | Blender 检查 GLB 大小 |
| 几何复杂度 | 默认不超过 250,000 三角面；按项目确认 | Blender 场景检查 |
| 纹理 | 默认最长边不超过 2,048 像素；按项目确认 | Blender 场景检查 |
| 页面脚本 | 默认总 gzip 不超过 256 KiB；按项目确认 | 构建后的 JavaScript 预算检查 |
| 兼容性 | 目标桌面与移动端现代浏览器 | 页面加载与浏览器冒烟测试 |
| 安全/隐私 | 不依赖密钥、账号后端或浏览器端 API key | 代码和构建检查 |
