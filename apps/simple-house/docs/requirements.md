# 项目需求与验收条件：小屋拆解观察台

## 用户与目标

- **目标用户：** 普通网页访客；不要求 3D 建模经验。
- **核心目标：** 通过可旋转、可缩放和可拆解的房屋模型观察外部构件与内部空间。
- **不在范围内：** 施工级建筑表达、精确材料用量、在线资产搜索、模型编辑器和服务端功能。

## 功能需求

| 编号 | 用户行为/系统行为 | 优先级 | 验收条件 |
| --- | --- | --- | --- |
| R-01 | 页面加载一座完整的单层小屋 | 必须 | 默认画面中能辨认屋顶、四面墙、门窗、基础和地面；模型与相机取景不裁切主体 |
| R-02 | 旋转、缩放和平移模型 | 必须 | 鼠标拖动/触屏拖动可绕模型观察；滚轮/双指可缩放；右键拖动或双指平移可移动视点；按钮可复位 |
| R-03 | 展开和合拢房屋构件 | 必须 | 拆解滑杆从 0% 连续移动至 100%；屋顶饰面、屋架、四面墙板沿明确方向分离；反向拖动可恢复 |
| R-04 | 单独显示或隐藏构件组 | 必须 | 屋顶、墙体、门窗、结构和室内物件可独立显隐；“显示全部”可恢复 |
| R-05 | 查看构件说明 | 必须 | 点击模型部件后高亮对应部件，并显示名称、作用和材质；未选中时有默认说明 |
| R-06 | 使用页面控件 | 必须 | 控件有可见文字或可访问名称，支持键盘聚焦与操作；窄屏下控件可滚动或折叠，不遮住全部模型 |
| R-07 | 反馈加载状态和错误 | 必须 | 有加载中、加载完成状态；GLB 或 WebGL 加载失败时显示原因类别及重试入口，不显示空白画布 |
| R-08 | 离线静态托管 | 必须 | Three.js、GLB、页面和样式随应用构建；运行时不请求密钥保护的 API 或外部模型 CDN |

## 场景和页面需求

- **默认视角：** 从房屋正面偏右、略高处观察，完整显示屋顶、门窗与地面。
- **核心操作：** 旋转、缩放、平移、复位、拖动爆炸滑杆、构件组显隐、点击部件看说明。
- **移动端行为：** 触摸旋转与双指缩放/平移；3D 画布与控件适配 360 px 起的窄屏。
- **页面状态：** 加载中、加载完成、加载失败；可通过重试恢复加载。

## 非功能需求

| 维度 | 目标/预算 | 验收方式 |
| --- | --- | --- |
| 模型体积 | GLB ≤ 8 MiB | Blender 场景检查 |
| 几何复杂度 | ≤ 100,000 三角面 | Blender 场景检查 |
| 纹理 | 程序化材质优先；若需要贴图，最长边 ≤ 1,024 px | Blender 场景检查 |
| 页面脚本 | JavaScript gzip 总体积 ≤ 256 KiB | 构建产物检查 |
| 兼容性 | 现代桌面浏览器和常见移动浏览器 | 网页构建及浏览器冒烟检查 |
| 安全/隐私 | 无密钥、账号后端或浏览器端 API key | 素材清单和构建检查 |

## 素材与再分发

- **允许的来源：** 本项目 Blender Python 生成的几何体；Poly Haven 官方发布、CC0 授权的公开贴图。
- **外部素材：** 使用 `Grey Roof 01` 的漫反射图作为绿色屋瓦的细节底图，使用 `Wooden Planks` 的漫反射图表现木地板；均下载 1K 分辨率并随项目静态托管。
- **许可与署名：** Poly Haven 将其资产标为 CC0，可公开静态托管和再分发；无需署名，但网页保留来源致谢链接。完整来源、作者和本地路径见 `assets/manifest.json`。
- **替代方案：** 下载源不可用时，本地纹理仍可重建模型；后续替换素材时先核实许可并更新清单。
