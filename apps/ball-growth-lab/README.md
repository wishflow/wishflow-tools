# 球群生长实验室

一个纯前端物理实验台，用来观察球在圆形场地里的运动、碰撞、繁殖和离场。设置与模拟画面分别占一屏；实验参数、随机种子和运行记录都留在当前页面，不上传到服务端。

## 本地开发

```bash
./scripts/install.sh
pnpm run dev
```

`pnpm run build` 会先检查类型，再把应用构建到本目录的 `dist/`。在仓库根目录运行 `pnpm run build:site` 会构建登记的应用并将本应用复制到 `_site/ball-growth-lab/`。共享站说明见根目录 [README](../../README.md)。

## 实验流程

设置页可随时切换「场地 / 发射 / 规则」页签，开始按钮固定在底部。运行开始后参数锁定。

| 状态 | 可用操作 |
| --- | --- |
| 设置 | 开始实验、导出当前参数 |
| 运行 | 1×/2×/4×/6×速度切换、暂停、导出本轮复现信息、请求结束 |
| 暂停 | 调整下一段运行倍率、继续、导出本轮复现信息、请求结束 |
| 结束 | 同条件重跑、修改设置、导出本轮结果 |
| 模拟失败 | 使用当前参数重试、返回设置 |

手动结束会先暂停并要求确认；取消时回到确认前的运行或暂停状态。人口达到目标、只剩一球、场内没有球时会直接结束并说明原因。修改设置会保留上一轮结果；同条件重跑复用配置和种子，并重新开始统计。

## 模拟规则

- 场地为可调直径的圆形，0–8 个缺口沿圆周均匀分布，并让一个缺口对齐正上方。缺口宽度按球径倍数设置。
- 无缺口时，同尺寸圆球按种子在上方随机生成且不重叠；有缺口时从顶部缺口内侧附近生成。初始球数、球速大小、随机速度扩散、发射方向和角度扩散都可调。
- 默认实验从 10 球开始，初速度 1.2 m/s、速度扩散 ±30%、重力 0.02 m/s²、球球恢复系数 100%、球径为场地直径的 2.8%、人口上限 40；球墙反弹固定为 100%。在种子 `BALL-0426` 下，1×约 44.3 秒达到目标，20、36 球检查点分别约在 27.5、43.9 秒；10→20 与 20→36 球的分段人均增长率相差约 42%，平均速度相对初始值变化约 −1.4%。这些数值用于描述这一组可复现参数，不代表其他种子；更换种子可能显著改变碰撞时间和总时长。
- 只有球对正在接近时才记为碰撞面；同一球对在一个物理步内至多触发一次，持续接触也不重复计数。初始球碰撞计数为 1，新生球为 0；每次新的碰撞面会让双方计数加 1，若其中一方碰撞前为 0，该面仍计算并反弹，但不繁殖。不同球对形成的独立碰撞面各自最多产生一个繁殖尝试。繁殖概率可调，默认 100%，不随人口缩放；单球冷却和同一球对冷却均可调，默认 0；成功判定后还需要安全出生空位。人口上限也可调。子球速率平方在碰后父球速率平方之间均匀抽样，父球速度不变；出生规则不做动量和能量守恒重分配，子球会贡献自身动量与动能（两父球都静止时子球也静止）。
- 运行中可切换 1×、2×、4×、6×演进速度。倍率只改变墙钟时间与模拟时间的换算，物理求解仍使用 1/240 秒固定步长。
- 球穿过真实缺口离场后会移除并计数。人口目标是结束条件；达到目标后冻结模拟，不再继续繁殖。
- 设置页可导出参数；运行页可导出当前复现信息，结束页可导出结果记录。导出 JSON 包含参数、种子、结束原因、统计、浏览器和视口信息。

## 代码结构

| 路径 | 职责 |
| --- | --- |
| `src/App.tsx`、`src/components/` | 实验流程、设置、统计 HUD 与数量图表 |
| `src/physics/` | CircleBatch 等半径球求解器、繁殖规则与 Web Worker |
| `src/rendering/` | PixiJS 场地、球体粒子和 FPS 统计 |
| `src/arena.ts`、`src/random.ts` | 场地几何与可复现随机数 |
| `tests/`、`e2e/` | 几何、物理规则和浏览器交互验证 |
| `scripts/benchmark.ts` | Planck、Rapier 与圆球批量算法基准对比 |
| `scripts/diagnose-growth.ts` | 重力、球群分布和密集场景续跑诊断 |
| `scripts/experimental/` | 仅用于对比的 Planck 求解器 |

React 不逐帧维护球的位置。物理在 Worker 以固定 1/240 秒步长运行，Worker 最多每秒发送 60 次画面快照；PixiJS 使用共享纹理与 ParticleContainer 绘制球群。

## 验证与已知边界

```bash
pnpm run test:ci
pnpm run build
pnpm run benchmark
pnpm run benchmark:gaps
pnpm run diagnose:growth
```

截至 2026-10-03 的 Rapier、Planck 和 CircleBatch 本地物理基准记录在 [`docs/benchmark-v2-2026-10-03.md`](docs/benchmark-v2-2026-10-03.md)。测试发现 Rapier 在高密度接触中存在显著数值能量损失，因此生产 Worker 已改用经过碰撞、离场、繁殖和结束条件测试的 CircleBatch。Node 基准不包含浏览器绘制和 Worker 通信；手机视口仿真也不能代替真实手机性能测试。
