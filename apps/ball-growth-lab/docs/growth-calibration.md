# 增长预测与离线校准

## 默认条件与可调参数

默认场景使用 2 个初始球、1000 球人口上限、恢复系数 1、繁殖概率 100%、单球繁殖冷却 8 秒和同一球对冷却 0.70 秒。繁殖概率可调，默认 100%；单球冷却和人口上限也可调。校准、搜索和增长曲线测试均以 100% 繁殖概率为基线。场地直径、球径比例、初速度与随机扩散、发射方向与扩散、重力、缺口数和缺口宽度是其他环境参数。

繁殖仍由碰撞触发。每次通过同球对冷却和单球繁殖冷却的碰撞，直接使用设置中的繁殖概率，不按当前人口缩放。默认 100% 时，每次符合条件的碰撞都通过概率判定；成功繁殖的两颗球在可调冷却时间内不能再次繁殖，以限制单位模拟时间内可参与繁殖的球数。空位限制和离场仍会改变实际曲线。用户可调低繁殖概率，或调长单球冷却来放慢增长。运行时的 1×、2×、4×、6×倍率只改变墙钟时间与模拟时间的换算，不改变模拟秒内的物理规则。

## 物理场景采样

`src/scenario.ts` 通过生产求解器的公开构造、`step`、结束状态与统计快照接口运行整个物理场景。增长校准每 0.05 秒保存人口及累计遥测；统计快照只遍历速度并聚合计数，不为每个球分配显示对象。每个点包含球速和碰撞、冷却、概率抽样、空位繁殖、离场计数。遥测只读，不增加随机数调用，也不改变繁殖决策。复用历史结果时，缓存键同时校验参数、种子、采样间隔和观察窗，避免把 0.5 秒旧数据混进高分辨率回归。

首繁殖基线专门运行到首次成功出生或 180 秒观察窗结束。观察窗只负责识别右删失样本，不限制游戏总时长。基线以 Kaplan–Meier 生存估计计算首繁殖时间分位数；未繁殖样本作为删失记录保留。

## 回归模型

碰撞暴露从二维硬盘近似开始。模型 v3 还用装填率的三次、四次项描述高密度空位率骤降，并加入重力、缺口与装填率交互项：

```text
λ₀(N) = N(N−1) × 球径 × √2 × 平均球速 ÷ 圆形场地面积
λ碰撞 = λ₀ × 接触聚集修正
P繁殖 = 设置中的繁殖概率（默认 1）
λ机会 = λ碰撞 × 冷却可用率 × P繁殖
λ出生 = λ机会 × 出生空位率
λ离场 = 球数 × 单球离场率
```

单球冷却通过率是碰撞是否具备繁殖资格的一部分，减少同一颗球短时间内重复参与繁殖的机会；繁殖概率只决定符合资格的碰撞是否通过随机判定，不受人口影响。生产求解器记录每段时间内实际发生的接近碰撞、法向闭合速度、球对冷却通过/拒绝、随机繁殖通过、出生空位尝试/成功与离场。候选模型 v3 和已存校准报告属于旧规则（繁殖概率 0.35、没有单球冷却），不能用于当前规则的预测；新规则的增长预测尚未重新校准，仍保持未验证并禁用。零事件区间也进入碰撞率拟合，使用半事件平滑，避免只按发生过碰撞的区间训练而造成选择偏差。

预测阶段先用生产物理引擎按每条预测轨迹的种子模拟最初 1 秒，以保留初始发射、首轮碰撞和缺口离场的相关性；之后按回归率运行随机出生–离场过程，采样 240 条人口轨迹并显示 P10、P50、P90。速度回归同时使用模拟时间和人口占据率，以拟合繁殖造成的速度分布变化。模型范围来自训练和完整留出配置的参数范围；范围外仍可计算灰色预测带，但会标记未验证。模型只有在完整留出参数组合上同时达到 `T10–90` 中位相对误差 ≤10%、80% 区间覆盖率 75–85% 后，才会写入界面实际使用的模型文件。未达标的候选只写入校准报告，不能被 UI 当作已验证模型。

## 并发实验与复现

共享包位于 `packages/simulation-testkit`，版本为 `1.0.0`。每个任务包含完整配置、随机种子和采样选项；固定大小的长驻 Node Worker 线程池会为超额任务排队。结果按提交顺序返回，失败结果保留任务配置、种子与错误，不自动重试。场景适配器负责每次调用创建并释放独立模拟状态。

```sh
pnpm run baseline:first-birth
pnpm run calibrate:growth
export FIRST_BIRTH_CAP_SECONDS # 填入你选定的首繁殖等待上限（秒）
pnpm run search:growth
```

可用 `SIMULATION_WORKERS` 指定 Worker 数量，`FIRST_BIRTH_SEEDS` 指定首繁殖样本数，`CALIBRATION_SEEDS` 指定每个参数组合的配对种子数（默认 24），`CALIBRATION_SAMPLE_INTERVAL_SECONDS` 指定校准采样间隔（默认 0.05 秒）。校准默认以 300 秒作为统计观察窗；达到观察窗但仍未终止的场景会作为右删失数据保留，不会改变游戏本身的终止规则。设置 `CALIBRATION_OBSERVATION_CEILING_SECONDS=0` 可要求物理场景运行到终止，但有可能遇到永久停滞场景。

参数扫描要求先把基线结果中的首繁殖 P90 上限填入 `FIRST_BIRTH_CAP_SECONDS`。脚本对每种非繁殖参数的边界/中间水平做单因素筛查，并加预先声明的交互组合；所有配置使用相同种子。只对首繁殖 P90 未超过上限的候选继续运行完整增长场景。P10–P90、T10–90、四个人口阶段斜率、种子间差异、提前结束率与右删失率会一并导出。Pareto 表按“增长区间更长、阶段斜率更低、首繁殖等待更短、种子差异更小、提前结束更少”比较候选，不输出自动胜者。

报告默认写入 `reports/`：首繁殖和增长校准的完整逐种子结果以 gzip JSON 保存；另生成便于阅读的摘要 JSON 和 CSV。增长摘要保留训练与留出参数组合、失败数、模型版本和误差指标；压缩原始报告保留所有配置、种子和时间序列，便于复现。

截至 2026-10-04，模型 v3 使用 10 个训练参数组合（240 个种子）和 2 个留出组合（48 个种子），采样间隔为 0.05 秒。候选仍未通过验收：留出参数组合的 `T10–90` 中位相对误差为 13.51%（目标 ≤10%），80% 预测带覆盖率为 87.05%（目标 75–85%），因此界面不会加载预测曲线。逐配置看，无缺口高密度组合实测/预测为 35.258/35.350 秒；重力缺口组合为 0.592/0.750 秒，后者仍偏慢 26.76%。此外，训练内的两个重力缺口近邻场景也分别偏慢约 30–34%，说明当前的全局统计回归还没有充分描述该类状态转移。高密度训练数据还显示，装填率约 0.784 时实际空位繁殖率约 0.25%，模型仍估为约 6.08%；空间聚集状态可能需要额外状态特征，不能只靠全局球数。报告位于 `reports/growth-calibration-v2-summary.json` 和压缩原始报告；早期 0.5 秒采样报告保留为 `growth-calibration-v1.*`。候选模型未通过验证，不应用于选择实验参数。

## 历史记录：2026-10-04 固定繁殖概率扫描

以下结果来自旧版配置（繁殖概率固定为 0.35、没有单球繁殖冷却），只供复现历史扫描，不代表当前规则或 100% 基线。

### 90 秒首繁殖上限扫描

本轮按用户选择将首繁殖时间 P90 上限设为 90 秒。基线 P90 为 166.9 秒，因此默认配置不符合本轮筛选门槛。扫描 52 组环境配置，使用 24 个相同配对种子；14 组通过首繁殖门槛并继续跑完整增长场景。增长观察窗为 300 秒，画面时间序列每 0.5 秒采样一次；`T10–90` 使用物理场景逐步记录的精确阈值时间，阶段斜率只作 0.5 秒采样诊断，不参与 Pareto 排序。

固定条件仍为初始 2 球、1000 球目标、恢复系数 1、繁殖概率 0.35、球对冷却 0.70 秒。下表选出较慢或能说明失败模式的组合。平均斜率按 `800 / T10–90` 精确计算；P90 斜率按各配对种子的平均斜率分布计算。

| 配置 | 首繁殖 P90 | T10–90 中位数（P10–P90） | 10%–90% 平均斜率（中位数 / P90） | 到达 900 球 | 目标完成 | 观察窗末人口中位数 |
|---|---:|---:|---:|---:|---:|---:|
| 重力 5 | 76.2 秒 | 0.671 秒（0.442–0.850） | 1,193 / 1,811 球/秒 | 24/24 | 23/24 | 1000 |
| 2 个缺口，宽度比 1.05 | 89.1 秒 | 0.637 秒（0.504–0.996） | 1,239 / 1,587 球/秒 | 24/24 | 24/24 | 1000 |
| 2 个缺口，宽度比 1.5 | 78.9 秒 | 0.737 秒（0.579–0.929） | 1,085 / 1,381 球/秒 | 19/24 | 19/24 | 1000 |
| 8 个缺口 | 63.6 秒 | 0.775 秒（0.713–1.304） | 747 / 1,123 球/秒 | 12/24 | 12/24 | 1 |

结果显示，最平缓的几组仍会在到达 100 球后不到 1 秒内穿过 900 球；可靠性较好的重力 5 和缺口宽度比 1.05 组合分别有 23/24、24/24 个种子达到目标。8 个缺口虽然慢一些，但 12/24 个种子只剩 1 球，不能把灭绝造成的“慢”当作合格增长。

另有两组在 300 秒内始终无法达到 900 球：球径比例 0.032 的场景末人口 P10/P50/P90 为 710/718/722；小场地、紧密且快速的组合为 571/573/577。24 个种子都以观察窗结束。球径比例 0.032 的代表种子在零重力、无缺口时仍有约 13 的平均球速和约 3100 万次碰撞；26.3 万次繁殖空位检查中，约 26.2 万次失败，且没有球离场。这说明类似 780 球的平台不能简单归因于重力把球压在底部或球停止运动；在这个参数组合中，主要限制是高装填率下找不到安全出生位置。它不是平缓地继续增长；Pareto 排序会同时奖励阈值完成率和目标完成率，避免优先推荐这类平台配置。

这份旧规则扫描中的陡增符合繁殖事件的初始近似：均匀混合时可碰撞球对数随 `N(N−1)` 增长，碰撞机会近似为

```text
λ碰撞 ∝ N(N−1) × 球径 × 平均相对速度 ÷ 场地面积
λ出生 ≈ λ碰撞 × 繁殖概率 × 冷却可用率 × 空位可用率
```

在空间尚宽裕时，第一项接近 `N²`，增长可以比指数模型更陡；接近拥挤后，空位率快速下降，曲线又会转成平台。该式是用于解释和建模的近似，不是已验证的精确预测器。本轮结果说明：**保持繁殖概率和冷却规则不变、同时把首繁殖 P90 限在 90 秒内，仅调本轮已扫描的环境参数，仍无法得到真正平缓的 10%–90% 增长。**若要继续压低斜率，需要再评估放宽首繁殖上限，或允许重新讨论繁殖机会率；本轮没有擅自改动这两项规则。

完整复现数据（配置、种子、逐种子时间序列、终止原因）位于 `reports/growth-pareto-search-90s.json.gz`；摘要和表格分别为 `reports/growth-pareto-search-90s-summary.json` 与 `.csv`。模型 v3 仍未通过留出集验收，而且基于旧繁殖规则；这次历史扫描只用于经验参数比较，不代表当前预测模型已校准，也不改变 UI 对预测曲线的禁用状态。
