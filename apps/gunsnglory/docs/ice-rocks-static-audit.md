# Dakota 第 6 关：Ice Rocks 静态审计

## 关卡身份与证据边界

Ice Rocks 是 Dakota 第 6 关、global level 36。APK 读取 `res/raw/td_map_39.tdm`；标题和简介使用 `T_LEVEL_NAME_39`、`T_LEVEL_INFO_39`，九段波次对白使用 `T_CAMPAIGN_36_01..09`。GameDesignData 使用零基 index 35，`GameDesignData.<clinit>` 中 `array_92c` 由父级 `aput-object` 写入 index `0x23`。`GameDesignWaves.setWaves()` 以 one-based `i == 36` 配置本关。

证据来自用户提供的 Guns’n’Glory FREE 1.8.6 APK 的原始 ZIP 条目、REA/JADX 静态分析视图和 Smali 数据数组，以及已验证的 Dakota 地形/路线转换规则。REA 的 JADX Java 伪代码不是原始源码；数组序号按父级写入位置确定。原版没有被启动，本报告不声称观察了 Android 运行画面。

## 地形绘制与敌方路线

从 TDM 与已验证的 Dakota 背景/街道转换规则派生，背景层为768条一格绘制命令；街道层为105条命令：路径贴图68条、竖桥21条、横桥6条、桥墩左右各5条。路线和桥层需一起核对；桥贴图外延不能作为碰撞范围。

出生点按行优先顺序映射为网页 `spawnPointId`：

| APK action ID | 原始 marker | 坐标 | 网页 spawnPointId | 默认入场方向 |
| ---: | ---: | --- | ---: | --- |
| 2 | 42 | `(31,4)` | 0 | west |
| 1 | 41 | `(31,18)` | 1 | west |
| 0 | 40 | `(31,19)` | 2 | west |

使用的方向 marker 中，52/53/54/55 分别表示 north/south/west/east，56 表示 north+west，61 表示 east+south。方向是从 marker 离开的方向。地图包含3个唯一出生点、2个出口、8条完整 spawn-to-exit 路线和53条唯一有向控制边（50条由转向 marker 给出，3条从出生点出发）。主要分岔如下：

- 上方入口 `(31,4)` 与中部入口 `(31,18)` 都通向 `(0,17)`，各在 `(13,18)` 分为东行/南行两条路径。
- 下方入口 `(31,19)` 有四条路线：在 `(22,10)` 选择 north 或 west，随后经 action 9 的 `(14,11)` 及 `(13,18)` 等 marker 分流，最终到 `(0,17)` 或 `(0,18)`。
- 逐路线展开的460次中间格访问全部落在原始 raw32、raw80 或 raw88；没有路径穿过地面、raw36 墙或水域。此项是基于原始TDM的静态格网检查，不是 Android 运行画面观察。

网页场景必须逐项核对背景/街道贴图、控制节点和碰撞格，不得只画直线或只检查路线端点。背景随机纹理由 APK 的时间种子驱动；网页固定种子只用于稳定测试，不能声称逐次匹配 Android 随机结果。

## 接入边界

- 正式入口要求 Dakota 第5关 Ghost Town 完成；Free Play 可独立选择 Ice Rocks 和任意支持难度。
- 关卡地图预览、战场渲染和路线必须来自 TDM 文件39，不从相邻地图复制。
- 资源存在或参数字段存在，不单独证明该资源/对象在本关被创建。
- APK 时间随机造成的贴图变化不要求逐启动复现；验证固定种子的合法贴图候选、裁切边界和图层顺序。
- 代码检查、独立 TDM 期望和短 `GameSession` 是主要验收证据；无需完整战役或 Android 实测。音乐只核对选择和文件，不试听。
