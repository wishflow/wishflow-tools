# 存储与内容访问契约

本文件定义 Progress、Experiments 与内部 Content 所有的持久化和内容读取边界。公共调用者使用三个 Module 的 Interface，不直接调用下述 Repository/Source。模块职责见[架构](architecture.md)，游戏参数与档案范围见[产品规格](spec.md)。实时战局始终在内存中推进；存储不参与每帧规则。

## 所有权与统一语义

| 内部 Seam | 所属者 | 数据 |
| --- | --- | --- |
| `ProfileRepository` | Progress | 正式档案的完整记录 |
| `ExperimentRepository` | Experiments | 不可变方案、运行索引、比较记录和产物 |
| `ContentSource` | 内部 Content | 版本清单、关卡定义及资源字节 |

所有 I/O 契约返回 Promise，但不使规则步进异步。错误含业务对象标识、可读说明、是否可重试；写入还标识提交状态 `not-committed`/`unknown`。提交状态未知时所属 Module 先读取并核对，不盲目重复业务操作。

| 情况 | 统一错误/结果 | 处理要求 |
| --- | --- | --- |
| 可选档案/记录不存在 | `null` | 所属者提供默认值或缺失状态 |
| 必需版本、资源或产物缺失 | `not-found` | 阻止依赖该项的开局/重放并指出标识 |
| 损坏/格式不合法/未知较新版本 | `corrupt-data` / `unsupported-version` | 保留原数据，拒绝覆盖并提供恢复/导出 |
| 非法输入/幂等键载荷冲突 | `invalid-input` | 不重试 |
| 版本已被他人更新 | `conflict` | 所属者重读并按业务规则合并或要求用户处理 |
| 空间不足 | `quota-exceeded` | 保留旧记录，提示清理/导出 |
| 无权/未认证 | `unauthorized` / `forbidden` | 返回身份恢复或权限状态 |
| 介质/网络暂不可用 | `unavailable` | 保留待保存状态，有限重试 |
| 调用取消 | `cancelled` | 区分未提交与提交未知 |

公共 Module 把这些结果转换为已保存、保存中、尚未保存、冲突或需要恢复；UI 不接触事务、revision、数据库类型或内部操作 ID。容量、离线队列和后台同步需有单独用例，不默认承诺。

## 正式档案

Progress 维护一个小型聚合：schemaVersion、六区进度/解锁所需状态、声音等游戏设置、每关高分/姓名及结算去重标识。站点语言状态由 `@wishflow/site-shell` 管理。档案不含未完成战局、实体坐标、运行时随机状态或实验数据；失败关卡重开，不续玩。

内部最小操作为 `readProfile() -> {data, revision} | null` 和 `writeProfile({data, expectedRevision, operationId}) -> revision`。一次写入原子替换完整档案；`expectedRevision=null` 仅用于创建。revision 不透明，只做相等比较。重试保持相同操作 ID、内容和预期 revision；同 ID 同摘要幂等返回，载荷不同拒绝，revision 变化报冲突。

设置冲突保留本页临时选择并让玩家重新加载后决定。结算在提交前读取最新档案，按 Progress 规则合并完成状态和高分；同一 settlement ID 只应用一次。只接受本次 Game 运行模式为正式的终局，replay/实验/调试结果即使源自正式记录也不能结算。

保存失败保留待保存状态，不显示成功、不静默切换到内存 Adapter。损坏档案可先导出原始 JSON；用户确认后才条件重置。替换或重置不得覆盖更新的其他标签页记录。关闭页面可能丢失未保存变更，不能只靠退出回调保存。

当前浏览器正式档案使用 IndexedDB `gunsnglory-profile` / `profiles` / `default`；格式 `schemaVersion: 2` 含设置、已完成场景、高分、已应用结算 ID、revision及最近保存操作摘要，当前设置含倍速与难度。schemaVersion 1 读取时补默认场景进度与revision 0，首次成功写入才升级；缺失倍速默认为1×，范围0.25×–4×、步进0.25×，缺失难度默认为easy。对象仓库版本保持1。损坏记录可先导出快照，再在同一事务确认仍为同一损坏记录后重置；更新记录返回冲突。未知较新格式只能导出，不能重置或覆盖。

IndexedDB Adapter 在单个读写事务中读取、比较并替换档案；事务完成后才报告成功。事务失败不得留下半份记录。localStorage 的 `getItem`+`setItem` 不是原子 CAS，只有已验证的同源锁覆盖所有合作写入者时才可实现此契约，否则初始化失败。HTTP Adapter 需在服务端事务/条件写入中校验版本；对象存储 ETag 仅在对应介质条件语义经过验证后转换成不透明 revision。

## 内容读取

内容清单与资源绑定不可变版本、ID、摘要和兼容的规则版本。读取流程：校验清单及引用 → 加载本关必需字节 → 校验摘要、格式和跨文件关系 → 构造不可变定义 → 成功后才能开局。缺地图、波次、数值或必需图片须失败并提供恢复入口；音频可按规格静音。缓存键为版本+资源 ID，坏缓存不进入游戏；规则步进不懒加载网络内容。图片解码、音频缓冲和 Canvas 对象不属于内容定义。

原版资源迁入后归游戏自有目录；构建和运行不访问研究树或 REA。稳定 ID 不等于路径，发布前缀、签名 URL 或对象键由 Adapter 解析；凭据不写进内容、回放或实验记录。修复内容生成新版本，不原地改写运行中版本。

## 实验记录与产物

Experiments 区分三类数据：草稿/不可变方案版本、运行状态记录、不可变运行产物。启动实验时冻结配置、完整数值、场景、策略、样本、预算和各 `PreparedSetup`；之后记录每次 Game 实际 `StartRecord`。后续改草稿不能影响已提交运行。

单次 IndexedDB 事务保存比较摘要索引和完整报告；打开时检查规范 JSON 摘要及方案引用。当前浏览器库为 `gunsnglory-experiments`，仓库为 `schemes`、`comparisons`、`artifacts`；摘要稳定倒序分页，每页最多50条。T15 当前能力仅覆盖不可变方案和比较记录的保存/打开，不代表单次运行中断续算或批次任务持久化。

跨 DB/对象存储不承诺全局事务。产物按不可变逻辑 ID 和摘要写入，之后条件提交终态和完整索引；仅完整索引提交后才对外显示完整结果。相同 ID+摘要幂等，相同 ID+不同内容冲突。运行有 `activeAttemptId`；迟到的旧尝试不得提交新终态。取消不是即时停止；未实现检查点时重启应从冻结输入重跑新尝试，不能拼接轨迹。

## 迁移与验证

迁移由数据所有者维护：先校验、导出可恢复副本、导入目标、回读核对 ID/计数/摘要/引用，再切换 Adapter 并保留回退。迁移不删除源。账号合并需显式处理进度/高分与设置冲突；profile ID 不能作为跨身份访问凭证。更换 Adapter 不自动带来多设备同步或离线队列。

验证分层：公共行为由 Progress/Experiments 测；内存和 IndexedDB 共用 Repository 契约；浏览器实际事务、多标签冲突、容量与恢复需真实介质集成测试。内容检查覆盖缺失版本/资源、摘要错误、坏缓存和同名资源跨版本隔离。Repository 不计算胜率、不做业务合并、不定义失败类别。文档不保存逐次验证日志，任务提交说明记录实际运行命令与结果。
