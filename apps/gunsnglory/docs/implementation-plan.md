## 稳定交付门槛

- 每个切片运行针对性测试并本地提交；批次收尾再运行完整应用检查及相关共享检查。
- 默认在窗口模式、静音状态测试；仅在对应验收需要时使用全屏或声音。无需手动完成整场战役。
- 发布前按最新已验收实现切片和公开发布次数复核比例，目标不高于 20%；不为美化比例拆分或延后已验收工作。
- 每个已复现并关闭的问题更新[经验记录](experience-log.md)，说明证据、修复和适用边界。
- 修改 Markdown 后检查链接和 `git diff --check`，并按相对路径复制到 `/tmp/var/wishflow-tools/`。文档更新本身不触发公开发布。
