## 当前实施状态

当前进行视觉资源和路线贴合复核。地图雇佣对话框已恢复 APK 的角色名、角色台词、肖像、价格及余额不足专属台词。APK 的 Cannon projectile 使用独立 `sfx_cannon_ball` 图像；网页尚未加载该资源。覆盖马车由 wagon 与 horse 两个对象组成，网页数据和原图文件已有对应项，尚需以实际画面确认缺马表现。现有路线测试核对 TDM 转向图与中心路线，不等于验证角色绘制锚点和整个精灵范围与峡谷边缘的贴合。

## 本轮待处理批次：角色与路线视觉核对

按以下切片顺序实施；每一项先以 APK 原始资源/DEX 与当前真实消费点确认为基准，再写定向验收，避免只补表面素材。

1. **接入 APK Cannon projectile 图像**
   - APK `GameObjectShot.draw` 的 damageStyle 4 使用 `sfx_cannon_ball` 飞行、命中后改用爆炸序列；原 APK 有 mdpi 12×12 与 hdpi 18×18 资源。
   - 网页 damageStyle 4 未设置 projectile asset，渲染器落入普通深红色小矩形回退；该回退只适用于普通子弹，不适用于 Cannon。
   - 迁入与 APK 字节一致的 cannonball 原图，接通离线预载、ShotView 类型和 damageStyle 4 绘制尺寸/锚点；不改变伤害、抛物线、随机或爆炸规则。
   - 验收：renderer 定向测试确认飞行弹丸使用原图及正确帧区域和比例、命中后使用原爆炸图；普通 damageStyle 0 继续绘制原普通子弹。资源预载测试确认文件在正式资产映射内。

2. **复现并核对马车/马组合绘制**
   - APK 映射 type 4 为 `wagon`、type 8 为 `horse_wagon`/`horse_wagon_white`，两者独立移动碰撞对象、共同组成一组；网页当前波次构造器也生成 type 8 马与 type 4 车，并沿路径方向错开一格。网页 mdpi/hdpi 资源与 APK 原图摘要一致。
   - 以 Cow Gulch Wave 3 和其他含 covered-wagon 请求的正式关卡，分别追踪波次请求 → 两个敌方实体 → 资源预载 → 图集帧 → draw order；实际截图核对马与车在直行及拐弯时均可见。
   - 若两实体都存在但画面缺马，按实际命中顺序和坐标修正绘制/图层；若生成数据缺 type 8，则修正请求映射。禁止改动已经与 APK 一致的源图片。
   - 验收：至少覆盖一个真实 Cow Gulch 关卡的短会话和一个另一地区关卡；检查直行及转弯帧马车空间关系、颜色变体、路线同步，不推进完整战役。

3. **逐关检查敌人绘制范围与峡谷边缘**
   - 从正式关卡目录提取实际 spawn、所有 TDM redirect/出口和路网；比较 APK 的格心坐标、网页 `positionFine`、`drawingOffsetFine`、脚底锚点、敌人精灵矩形、地形/道路图层与 `drawOrder`。
   - 检查所有已实现关卡中各出生方向和完整分支；区分逻辑中心线错误、道路/地形绘制错误、单位组偏移和单纯精灵上半身越出道路。地图未被原版路线数据支持时，不得为了视觉观感手动挪路线点。
   - 只修证据确认的映射或坐标差异，并加入从原始 TDM/独立路线期望出发的定向回归；如果路径中心完全匹配而精灵外形与原版重叠方式相同，记录为原版表现，不擅自改玩法。
   - 验收：所有当前正式关卡的完整路线中心及分支可达；路线中心不进入墙/水等禁止地形；边缘路段的脚底锚点落在预期道路/桥层，单位实际绘制范围与 APK 的对象锚点关系一致；以内置浏览器检查最容易出现边缘重叠的关卡截图。

4. **批次完整验收与发布**
   - 完成各切片定向测试后执行 `pnpm run test:ci` 及相关共享检查；失败修复后重跑失败项与最终完整检查。
   - 浏览器默认窗口模式、静音；检查地图雇佣介绍、Cannon 弹丸、covered-wagon 组合和路线边缘样例。无需启动 Android；只有静态分析无法判定的特定差异才另定一次最小运行观察。
   - 验收通过后按应用流程将整批 squash 集成并发布，核对 Actions 和公开构建来源 SHA，再用内置浏览器检查部署版。发布次数按完整修复批次计，不按单个切片发布。

## 批次执行约束

- 每个切片运行相关定向测试并本地提交；一组计划步骤全部结束后运行一次 `test:ci` 和适用的共享检查。失败在当前批次内修复，并重跑失败项及最终完整检查。
- 公开发布按完整功能批次进行，不为单关或单切片单独发布。通过 CI 后核对 Pages 来源 SHA，再以内置浏览器验证该批代表性菜单入口和开局流程。
- 默认窗口模式、静音；只有对应验收需要时才进入全屏或启用音效。只在静态证据不能回答具体问题时，设计最小 Android 定点观察；不完整游玩或通关。
- 新增正式关卡时，除新关自身外，还需搜索并更新正式阶段数组、Progress 投影、关卡总数、地区可玩数、Free Play 边界、回放工厂、E2E 历史 fixture 和启动资源收集器。
