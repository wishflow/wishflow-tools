- **动态实体：**只有存在时才验收；部件/组、锚点、轨迹与路线分支符合对应 TDM/车辆组代码。
- **总门槛：**41/41 场景均列入矩阵；六类均为已核对、自动化闭合或带依据的不适用，所有“待补”均转成有边界的任务或明确阻塞。生产截图/叠图必须可追溯到对应场景及渲染入口。Level 42–60 不在本批范围。

- **车马画面：**182组正式马车分叉短会话验证车体、马匹同组跟随，但不验证绘制资源、脚底锚点、图层排序或浏览器画面中是否分离。用户报告的“分叉后有马车没有马”仍待 M3-D 使用代表性实际 `drawGame()` 画面核对；前车双轴位移及已知 Wave 3 落后状态不重复检查，除非发现可复现的新轨迹差异。当前没有 Android 原版同轨迹运行帧对照，不将网页渲染测试描述为 APK 画面验收。
