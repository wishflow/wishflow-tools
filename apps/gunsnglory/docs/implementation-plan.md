# 实施计划

本文只保留当前进度和未完成任务。规则见[产品规格](spec.md)，模块边界见[架构](architecture.md)，存档及模拟契约见[存储契约](storage-contracts.md)和[模拟与自动化契约](simulation-and-automation.md)。每轮开始先核对代码、测试和提交，再细化后续步骤；每完成一个切片就更新本文并关闭已完成项。

## 当前状态

- 正式战役已完成 **4/60** 关：Cow Gulch、Apache Valley、Fort Kaboom、Tech Town。
- Tech Town 已登记为 New Mexico 第 4 关，接入原图、四条路线、八波、初态、玩家池动作、双语对白、正式进度和结算路径。关卡首次开放时只出现 type 1–4 普通单位；重玩时按档案里程碑开放已解锁的特殊地图单位，Gambler 与 Casino 同步出现或隐藏。
- 显示修复代码已完成：游戏窗口按可用视口适配并保持画面比例，普通页面中的 Usagi 覆盖游戏窗口，全屏时隐藏。内置浏览器拒绝原生全屏请求；原生全屏覆盖屏幕仍无实测证据。除专门验收全屏外，保持窗口模式。
- 浏览器测试默认静音；除专门验收音效外，不开启声音。REA/APK 静态材料优先；仅当具体问题无法从静态证据判断时，才安排一次 Android 定点观察，不重复启动或检查已证实行为。
- 显示修复、Gold Transport、玩家池多槽动作和 Tech Town 共 4 个实现切片均已完成针对性检查。本批最终验证通过：`pnpm run typecheck`、391 项单测、`pnpm run build`、97 项 Playwright E2E；E2E 需允许本地服务绑定 `127.0.0.1:4173`。构建仍提示主 JS chunk 超过 500KB，但不影响构建或测试通过。当前基线更新为 5 次成功发布 / 31 个已验收实现切片（16.1%）；若本批发布，则为 6/31（19.4%）。
- 本批 4 个实现切片的本地最终检查通过：类型检查、391 项单测、构建及 97 项 E2E。首次 GitHub Actions 运行中，97 项 E2E 有 96 项通过；唯一失败是手机竖屏工具栏的主要控件超出滚动区域。将断言改为有界等待后，第二次 CI 仍在 5 秒后失败，确认这是持续的布局问题而非读取时机。本机 Chrome 157/macOS 用例通过，CI 的 Chrome 157/Linux 仍失败；平台差异尚未完全定位。下一步先把暂停、战役菜单和清除选择放在手机工具栏可见区前部，次要样例操作保留横向滚动；用 CI 同版 Chrome 157 验证该场景，再运行完整本地套件及 CI。发布只有在 CI 成功后才继续；本批发布后计为 6 次成功发布 / 31 个已验收实现切片（19.4%），并按下列门槛核对 `/_site/build-info.json` 来源 SHA、内置浏览器和 `gunsnglory` 回并。

## 下一批：New Mexico 第 5 关 Billy Hills

### 1. 先完成 map05 静态内容审计

**范围：**只使用 APK/REA 现有静态资料，不实现游戏代码、不启动 Android。以 `td_map_05.tdm`、战役关卡配置第 5 行、`GameDesignWaves` 对应记录及其实际读取点为依据。

**需要明确：**地图尺寸与网格、入口/出口/方向场及路线、静态对象和单位初态、现金/生命/升级上限、全部波次与生成池请求、玩家池/动作、敌人及特殊规则、对白键与双语文本、必需美术和声音资源、进度解锁和结算边界。分别标出直接数据、代码推导、实现假设和未知项；地图文件数量不得当作战役关卡数。

**产物：**在本文更新一份足以实现与独立测试的 map05 参数摘要，并列出已有 Game 规则可直接复用的部分及缺失机制。未知项若影响战斗结果，则先查对应静态消费者或记录阻塞，不猜值、不用完整通关来补证。

**关闭条件：**关卡数据与读取逻辑能够交叉核对；所有会影响 map05 可玩性的未知项已解决，或已明确拆成独立规则任务及所需证据。审计通过后再进入第 2 步。

### 2. 按审计结果接入 map05 正式内容

**实现边界：**若现有 Game 规则覆盖地图与波次行为，只增加正式关卡内容、资源、解锁和对白，并把它登记为 New Mexico 第 5 关；实际数据进入正式会话，不以 fixture 代替内容。若审计发现现有规则不支持必要机制，先拆出可独立验证的规则切片，再接入关卡。

**验收：**独立期望核对原始网格、路线、对象、初态、所有波次/请求、关卡参数、生成池、对白与资源；正式会话检查初始状态、代表性操作、胜败均走唯一 Progress 结算路径；map04 前序行为和 map06 锁定状态不回归。浏览器用窗口模式与静音，仅做选关、入关、一个代表流程和退出检查，不手动通关整关。

### 3. map05 关闭后再审计 New Mexico 第 6 关

先核对 map06 实际代码、APK 数据和 map05 复用结果，形成下一轮可执行内容审计；不预设关卡波数、单位或新机制。依次推进，不把多关的未验证数据一次性写入生产代码。

## 发布门槛

每个切片先跑针对性检查并提交；整批切片全部完成后运行一次应用完整检查与适用共享检查。公开发布按根目录及本应用 `AGENTS.md` 执行：整批验收后 squash 集成，核对 CI、部署来源 SHA，再用内置浏览器验收；普通发布比例目标不高于 20%，按实际成功发布与已验收切片数记录。
