- 自由模式切片定向验证通过：`tests/free-play.test.ts`、Progress 正式结算隔离、难度/回放/战役回归共26项单测通过，类型检查通过；Playwright 菜单回归3项通过，自由模式端到端测试1项通过，覆盖零进度进入 Apache Valley 困难、四关入口状态、Tech Town 首波及档案难度/进度/最高分/revision 保持不变。
- Profile 档案和实验数据档案已实现为两个独立的 v1 JSON 文件。Profile 档案不含 revision，导入前确认并通过 ProfileRepository 条件事务整体替换；实验档案包含所有数值方案及完整比较报告，在单个 IndexedDB 事务中合并方案、比较索引与附件，重复内容跳过、标识冲突保留本地并报告。当前实现已把档案、实验工具、战局回放和唯一的模拟速度控件放在游戏框外的实验工作台；游戏 Options 只保留 Help 与 Sound。数据语义不变，完整测试及发布状态见当前批次。
- 数据档案切片定向验证通过：类型检查通过；Progress、两类档案编解码、实验仓库和实验流程相关单测共44项通过；Playwright `t38-data-archives.spec.ts` 两项通过，覆盖档案下载/替换/取消/未知版本、实验导出导入/重复去重/冲突保留、跨数据库隔离，以及 profile 和实验 IndexedDB 写事务失败后无部分写入。
- Playwright 定向 E2E 使用 `pnpm exec playwright test tests/e2e/<spec>.spec.ts --workers=1`；避免在 `pnpm run test:e2e -- ...` 后追加 spec 参数，该转发形式会误触发全套测试。
- IndexedDB repository 的多个实例共用相同数据库；共享契约在同库上验证幂等导入与冲突，只有需要验证“导入到空库”时才另开浏览器 context。检查弹窗是否留在游戏窗口内应验证 `closest('.game-frame')`，不要要求它是直接子元素，因为 `.game-stage` 是合法的中间容器。

- 上一批的显示修复、Gold Transport、玩家池多槽动作、Tech Town、全屏构图和自由模式共 6 个实现切片已完成。本地完整检查通过：类型检查、391 项单测、构建和 97 项 Playwright E2E；E2E 需允许本地服务绑定 `127.0.0.1:4173`。该批通过 GitHub Actions `42253109012` 发布到 GitHub Pages 与 Cloudflare Pages；两处 `build-info.json` 的来源均为 `6940fcbaa4b2520d8be5f1a81243c9a25815e4e0`。内置浏览器在窗口模式、静音下验证主菜单、地区/关卡选择、进入 Cow Gulch、退出未完成关卡和 Usagi 拖动；未启用全屏或音效。移动端竖屏由 Chrome 157 定向检查和完整 E2E 覆盖；当时的内置浏览器会话未提供移动视口覆写。构建仍提示主 JS chunk 超过 500KB，但不影响构建或测试。
- 手机竖屏 CI 曾连续三次发现清除选择按钮超出可视区：Chrome 157/Linux 测得操作行宽 255.6px，主要按钮与间距约 265px，超出 9.4px。扩大操作行或把摘要移出叠层会遮住地图并导致触屏选择、拖动和缩放回归，均已撤回。最终保持原摘要与操作行布局，将窄屏按钮水平内边距从 0.3rem 缩至 0.18rem，主要按钮总宽减少约 11.5px；定向 CI、全套本地检查和最终发布 CI 均通过。
