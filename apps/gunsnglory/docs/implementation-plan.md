## 本批固定边界

- 不重新解析广告/统计 SDK，不导入研究数据库，不启动 Android，不完整通关；本批以 APK 静态证据、原始 TDM、已有 REA 路线图及 `GameSession` 确定性测试为主。
- 不为地图观感手工画直线路线或偏移坐标；路线期望从 APK TDM 独立生成。背景绘制、道路层、最终地形阻挡、对象碰撞和精灵脚底分别验收。
- 不复制已存在的 map32 预览图、Oregon 通用贴图/音效；必须确认资源被本关 builder 实际引用并进入预载集合。
- 只有在 M30-A 发现当前规则 API 无法表达原版行为时，才提出最小契约扩展，并在实现前说明受影响消费者和测试边界。
