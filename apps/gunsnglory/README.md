# Guns’n’Glory

用于学习、调试和平衡性实验的浏览器游戏项目。

**当前已发布 T01–T04：** Cow Gulch 首个战斗样例支持展示胜负结算并干净重开；高分文件候选值会展示，但正式分数仍未保存。该切片不代表完整波次、关卡或战役。

已确认三个公共深 Module 与纵向切片方式。架构、存储和模拟文档描述同一套契约；实施计划从首个可演示行为逐步扩展，不再保留并行的旧分层方案。

## 本地开发与验证

```bash
./scripts/install.sh
pnpm run dev
pnpm run test:ci
```

地图与单位图像来自反解析得到的原版资源。当前地形采用固定变体以便复测；关卡数据和规则仍按[实施计划](docs/implementation-plan.md)逐步实现。
