# Guns’n’Glory

用于学习、调试及平衡性实验的游戏项目。目标是逐步实现 Guns’n’Glory FREE 1.8.6 的完整离线玩法，并提供可复现的无画面模拟接口。

**当前状态：设计文档阶段。** 本目录尚无可运行网页、应用依赖清单或已发布版本；下面描述的是已确定的方向，不是实现完成声明。

## 产品范围

- 浏览器内进行实时游戏，支持鼠标和触屏，保留英文并提供中文。
- 首版以 Vite、TypeScript、Canvas 2D 和原生 IndexedDB 实现纯前端应用；导航与语言接入仓库共享外壳。
- 游戏规则与浏览器、存储和网络隔离；界面、脚本与批量模拟复用同一个内核。
- 正式档案保存进度、设置和高分；中途关卡重新开始。
- 原版参数保留为基线，实验配置独立保存并能在同一批场景、策略及样本上比较。
- 后续后端提供档案、资源和批量模拟服务；实时战斗仍在浏览器运行。

## 内容边界

关卡、数值、图像、声音和文案是游戏自身的内容资产。研究报告、逆向工具、证据和中间文件不进入应用运行时或发布包；需要迁移素材时，由内容准备阶段确定实际文件集合和引用。

完整战役目标为 6 个区域、60 个关卡；已有 63 个地图文件不能直接解释为 63 个可玩关卡。发布版本只声明实际实现并通过验收的内容。

## 集成边界

应用最终独立维护 pnpm 依赖、锁文件、安装脚本、构建和测试入口，并输出到本目录 `dist/`。达到公开发布门槛后再登记导航；当前文档提交不修改共享站点构建范围。

公开域名统一由[仓库 README](../../README.md)维护；项目通用规则见[根 AGENTS.md](../../AGENTS.md)。
